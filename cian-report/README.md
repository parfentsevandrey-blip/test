# Подборка квартир — центр Москвы (ЦИАН → PDF)

**Результат:** [`Подборка_квартир_центр_Москвы.pdf`](Подборка_квартир_центр_Москвы.pdf) — 49 страниц A4 (альбомная ориентация).

Внутри:

- обложка и обзорная карта всех 10 объектов (Яндекс Карты, номера = номера квартир);
- сравнительная таблица и график цены за м² с ключевыми выводами;
- по каждому из 7 ЖК — страница со справкой: девелопер, архитектор, класс, этажность, число квартир, концепция, инфраструктура, фото;
- по каждой квартире — 3–4 страницы: главное фото, цена и ключевые параметры, метро, планировка, все характеристики из объявления, фото, скриншот Яндекс Карт с точкой и выдержка из описания.

Данные объявлений сняты с ЦИАН 21.10.2026. Справка по ЖК взята из открытых источников (novostroy-m.ru, РБК, Moskvich Mag, bfm.ru и др.); ссылки на источники есть на страницах ЖК.

## Как пересобрать

```bash
python3 -m venv .venv && .venv/bin/pip install "scrapling[fetchers]"   # github.com/D4Vinci/Scrapling
.venv/bin/python scrape.py   # страницы объявлений из listings.txt -> build/raw/
python3 extract.py           # JSON из страниц -> data/listings.json, фото -> build/img/
node maps.js                 # скриншоты Яндекс Карт -> build/maps/
python3 render.py            # HTML-вёрстка -> build/report.html
node pdf.js                  # PDF через headless Chromium (Playwright)
```

Нужны Python 3 (Pillow, Jinja2) и Node.js с Playwright.

## Заметки

- ЦИАН блокирует IP дата-центров и обычные HTTP-клиенты: и `curl`, и headless Chromium получают ответ `cian_waf_block`. Scrapling (curl_cffi с TLS-отпечатком Chrome/Safari) этот блок проходит. Страницы ЖК на ЦИАН после серии запросов отвечали 429, поэтому данные о ЖК берутся из блока `newObject` внутри объявлений и из `data/jk.json`.
- Все данные объявления лежат в странице как JSON в `window._cianConfig['frontend-offer-card']` (ключ `defaultState`), так что HTML-разметку парсить не нужно.
- Карты снимаются через виджет `yandex.ru/map-widget` без его пинов. Номерные маркеры рисуются поверх карты; их позиции считаются в проекции Яндекса (EPSG:3395).
- `pdf.js` сам проверяет вёрстку и пишет в консоль, если какой-то блок вылез за границы страницы.
- Планировка №3 (White Khamovniki) в объявлении не опубликована, в PDF это отмечено.
