# Справка по кварталу «МИГ» на Ленинградском проспекте

Готовый документ: **`Квартал_МИГ_справка.docx`** (17 страниц, A4).

Capital Group застраивает 63,55 гектара бывшей производственной площадки «МиГ»
между Ленинградским проспектом, Боткинскими проездами и улицами
Авиаконструктора Сухого и Маргелова. Участок получен на торгах по комплексному
развитию территории в августе 2023 года, договор — на 26 лет. По документам
Стройкомплекса здесь построят **2,3 млн м²**, из них **1,4 млн м² жилья** —
около 19 тысяч квартир.

**Цен у проекта нет.** На 22 сентября 2026 года брокерские карточки показывают
статус «проектирование» и собирают лист ожидания. Поэтому ценовая часть справки
построена не на прайсе проекта, а на рынке локации.

## Откуда данные

**Параметры проекта.** Площадь территории, объём застройки, благоустройство и
состав социальных объектов — из сообщений Стройкомплекса Москвы о КРТ и
публикации «Московской перспективы» о мастер-плане бюро «Камень». Условия
торгов, победитель и стартовая цена лота — ИРН и «Ведомости». Класс, число
квартир, этажность и площади — из брокерских карточек: в документах о КРТ этих
цифр нет.

**Юрлицо.** ООО СЗ «Энимерози», ИНН 9703150422, зарегистрировано 13 июля
2023 года, уставный капитал 10 000 ₽ — открытые реестры.

**Рынок вокруг — поисковый API Циан**, клиентом из ветки
`claude/cian-apartments-cao-7iqapp` (`tools/cian/cian.js`). Три запроса,
срез 22.09.2026:

| Файл | Запрос | Заявлено | Перечислено |
|---|---|---|---|
| `metro-new.json` | новостройки в 15 минутах пешком от «Динамо» | 298 | 295 |
| `metro-resale.json` | вторичка 2015+ там же | 349 | 219 |
| `begovoy-new.json` | новостройки Бегового района | 190 | 190 |

Циан схлопывает похожие объявления, поэтому вторичку за один проход перечислить
целиком не удалось — разница видна в таблице.

В когорту отобраны лоты в двух километрах от центра контура участка, дома с
тремя и более лотами в продаже: **545 лотов, 12 групп**. Группа — это дом плюс
стадия: в «Прайм Парке» одни корпуса ещё строятся, другие уже перепродаются.

**Координаты.** Адреса проверены геокодером OpenStreetMap: Ленинградский
проспект, 33 — 55.7864 / 37.5603; 1-й Боткинский проезд, 7 — 55.7848 / 37.5581.
Центр контура территории взят по карте: 55.7859 / 37.5510. Расстояния
посчитаны по прямой от него.

**Визуализации** — кадры мастер-плана из публикаций о проекте. Квартал не
построен, поэтому в документе они подписаны как проектные визуализации.

**Рынок Москвы** — данные NF Group за I квартал 2026 года.

## Пересборка

```bash
python3 mg_renders.py    # кропы визуализаций -> assets/*.jpg
python3 mg_data.py       # таблицы и расчёты -> mg_tables.json, mg_pins.json
python3 mg_maps.py       # три карты -> assets/map_*.png
python3 mg_chart.py      # два графика -> assets/chart_*.png
python3 mg_assets.py     # PNG -> JPEG в assets/
cat mg_head.js mg_body.js > mg_build.js && node mg_build.js
```

Выгрузки Циан лежат рядом вместе с запросами в `queries/`; чтобы пересобрать их
с нуля, нужен клиент из ветки `claude/cian-apartments-cao-7iqapp`:

```bash
node tools/cian/cian.js search --query queries/metro-new.json --all --out metro-new.json
node tools/cian/cian.js search --query queries/metro-resale.json --all --out metro-resale.json
node tools/cian/cian.js search --query queries/begovoy-new.json --all --out begovoy-new.json
```

`ymap.py` и `markers.py` — сшивка тайлов Яндекс Карт (EPSG:3395) и отрисовка
пинов с подписями; подписи на картах расставлены вручную, иначе они наезжают
друг на друга. `mg_head.js` — хелперы вёрстки: `statTiles`, `factSheet`,
`dataTable`, `imagePair`, `bullets`.

Папка `photos/` в репозиторий не входит: это исходные кадры визуализаций,
они восстанавливаются ссылками из `mg_renders.py`.
