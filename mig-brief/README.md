# Справка по кварталу «МИГ» на Ленинградском проспекте

Готовый документ: **`Квартал_МИГ_справка.docx`** (22 страницы, A4).

Capital Group застраивает 63,55 гектара бывшей производственной площадки «МиГ»
между Ленинградским проспектом, Боткинскими проездами и улицами
Авиаконструктора Сухого и Маргелова. Участок получен на торгах по комплексному
развитию территории в августе 2023 года, договор на 26 лет. По документам
Стройкомплекса здесь построят **2,3 млн м²**, из них **1,4 млн м² жилья**,
около 19 тысяч квартир.

## Что известно о ценах

Официального прайса у проекта на 22 сентября 2026 года нет. Опорных точек три.

| Источник | Что известно |
|---|---|
| Брокерские карточки (whitewill, mskpremium, sosedi.life) | «ориентировочные цены от 500 000 ₽/м²», старт продаж в 2026 году; на 22.09.2026 страницы сняты и отдают 404, цифра видна в поисковой выдаче |
| Проектная декларация первого дома (Domovka, 24.07.2026) | 311 квартир, 33 479 м², около 80 м, сдача во II кв. 2028, 6,2 млрд ₽; по дополнению к публикации дом строится для реновации |
| Прайс МАСТЕРС, ул. Викторенко, 16 (сайт Capital Group) | 148 квартир, 24,5–102,2 млн ₽, медиана 779 355 ₽/м² со скидкой 10–15 %, 866 200 ₽/м² без скидки, премиум, IV кв. 2029 |

Проверить декларацию в ЕИСЖС напрямую не получилось: наш.дом.рф отвечает
через прокси 403 (WAF). Проекта «МИГ» в каталоге cg-projects.ru нет.

Прайс МАСТЕРС выгружен целиком из открытого каталога сайта застройщика
(`masters-cg.json`):

```bash
curl 'https://cg-projects.ru/api/properties/?deal=sell&limit=50&offset=0&order=price&project=masters&type=flats&with_pagination=true'
```

Оценка справки для первых рыночных корпусов «МИГа» — **0,78–0,87 млн ₽ за м²**:
от медианы МАСТЕРС со скидкой до его прайса без скидки. Стройки в 1,2 км от
участка («Прайм Парк» и С5) идут по медиане 851 400 ₽ и попадают в этот
диапазон.

Циан схлопывает похожие объявления, поэтому по крупным запросам перечислено

без этого ограничения.

## Координаты

Станции метро взяты по геокодеру Яндекса (через `cian.js find`): «Динамо»
55.789735 / 37.558239, «ЦСКА» 55.786597 / 37.533283, «Петровский парк»
55.791922 / 37.557093. Прежние точки OpenStreetMap для «Динамо» и «ЦСКА»
оказались автобусными остановками, из-за этого в первой версии справки
расстояние до «ЦСКА» было занижено (800 м вместо 1110 м), до «Динамо» —
500 м вместо 620 м. Центр контура территории взят по карте: 55.7859 / 37.5510.
Все расстояния по прямой от него.

## Сколько рынок просит за ремонт

Сравнение внутри одного дома, пять готовых домов у «Динамо», 102 карточки
объявлений (поле `repairType` есть только в карточке, Циан отдал 102 из 217
запрошенных). Медиана разницы по домам **+11 %**, от −19 % в Alcon Tower до
+35 % в «Прайм Парке». Готовые дома у «ЦСКА» в этот расчёт не входят: их
карточки не читались.

## Пересборка

```bash
python3 mg_renders.py    # кропы визуализаций -> assets/*.jpg
python3 mg_data.py       # таблицы и расчёты -> mg_tables.json, mg_pins.json, mg_bench.json
python3 mg_maps.py       # четыре карты -> assets/map_*.png
python3 mg_chart.py      # три графика -> assets/chart_*.png
python3 mg_assets.py     # PNG -> JPEG в assets/
cat mg_head.js mg_body.js > mg_build.js && node mg_build.js
```

Все числа в тексте справки, которые зависят от выгрузки, считаются в
`mg_data.py` (блок `STAT`), чтобы формулировки не расходились с таблицами.

Выгрузки Циан пересобираются клиентом из ветки
`claude/cian-apartments-cao-7iqapp`:

```bash
for q in metro-new cska-new begovoy-new khoroshevsky-new aeroport-new savelovsky-new metro-resale cska-resale; do
  node tools/cian/cian.js search --query queries/$q.json --all --out $q.json
done
```

Карточки ремонтов:

```bash
node tools/cian/cian.js card --from resale_ids.json --limit 220 --out resale_cards.json
python3 mg_repair.py          # mg_repair_lots.json + кадры объявлений в photos/
python3 mg_repair.py sheet    # контактные листы для отбора
python3 mg_repair.py cards    # assets/card_*.jpg + mg_repair_cards.json
```

`ymap.py` и `markers.py` — сшивка тайлов Яндекс Карт (EPSG:3395) и пины с
подписями. Папка `photos/` в репозиторий не входит.
