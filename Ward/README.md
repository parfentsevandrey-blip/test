# Ward — браузер, который не даёт следить

Седьмое приложение каталога (см. [манифест](../MANIFESTO.md)). Браузер для Mac, у которого главная задача —
безопасность и приватность: реклама, трекеры, отпечаток браузера, метки в ссылках и опасные сайты
останавливаются ещё до запроса. Swift 6, SwiftUI, Liquid Glass, русский интерфейс.

> **Установка без предупреждений macOS.** Проще всего через [Harbor](../Harbor/) — каталог всех наших приложений.
> Поставьте его одной командой в Терминале
> `curl -fsSL https://github.com/parfentsevandrey-blip/test/releases/download/catalog/install.sh | bash`
> и установите Ward из каталога: обновления будут приходить сами, данные и настройки сохранятся.
> Без Harbor: `curl -fsSL https://github.com/parfentsevandrey-blip/test/releases/download/catalog/install.sh | bash -s -- ward`.

## Почему WebKit, а не Chromium

Ward построен на WebKit — движке Safari, который уже есть в каждой macOS. Это не сторонний код, а системная
библиотека, поэтому правило «всё с нуля» соблюдено. Своё в Ward:
- блокировщик;
- защита от отпечатка;
- очистка ссылок;
- проверка опасных адресов;
- интерфейс.

Почему не Chromium:
- **Лёгкость.** Ward весит несколько мегабайт вместе со списками фильтров. Chromium весит сотни мегабайт и
  собирается часами.
- **Обновления безопасности.** Движок обновляет сама macOS, вместе с Safari. Браузер на своём Chromium без
  команды из десятков человек отстаёт от исправлений уязвимостей.
- **Расширения Chrome Web Store не нужны.** uBlock Origin, Privacy Badger и подобные — это способ
  добавить защиту в чужой браузер. В Ward та же работа встроена в движок и делается правилами WebKit:
  страница не может их обойти или заметить.

## Что делает Ward

### Слежка и реклама

| | |
|---|---|
| **Реклама и трекеры** | 13 списков: EasyList, EasyPrivacy, uBlock Origin (фильтры, приватность, опасные сайты, починка, срочные исправления), RU AdList, Peter Lowe, URLhaus, AdGuard URL Tracking, EasyList Cookie, CNAME-трекеры AdGuard (и по желанию — «Помехи»). Собственный переводчик синтаксиса Adblock/uBlock в правила блокировщика WebKit — около 195 тысяч правил; WebKit применяет их до запроса. |
| **Скриптлеты uBlock Origin** | Своя библиотека из 40 скриптлетов (`set-constant`, `abort-on-property-read`, `abort-current-script`, `json-prune`, `no-fetch-if`, `replace-fetch-response` и другие) исполняет около 7,5 тысячи правил `##+js(…)` из списков: реклама, которую сайт вставляет своим кодом, стены «отключите блокировщик», реклама YouTube. «Доверенные» скриптлеты, которые переписывают ответы сервера, — только из списков команды uBlock Origin. |
| **Процедурная косметика** | `:has-text`, `:upward`, `:matches-css`, `:xpath`, `:remove`, `:style` и другие — около 2,8 тысячи правил, которые обычный CSS не выражает. Работает в отдельном мире скриптов: страница его не видит. |
| **Отказ от cookie** | В окнах согласия (OneTrust, Cookiebot, Didomi, Quantcast, Usercentrics, Sourcepoint, Google и ещё 20 платформ) Ward нажимает «Отклонить всё» — даже если окно уже спрятано списком. Незнакомые окна — по тексту кнопки на 10 языках. |
| **Скрытые трекеры (CNAME)** | Поддомен сайта вроде `metrics.site.com`, который в DNS оказывается счётчиком Adobe или Eulerian, Ward распознаёт и дальше блокирует. |
| **Кто следил** | Щит в адресной строке: сколько остановлено на странице и кто именно — Google, Яндекс, Meta, VK, Criteo… Счётчики на новой вкладке. |
| **Отпечаток браузера** | Шум в холсте, WebGL, звуке, ширине текста и размерах элементов (`getBoundingClientRect`, `getClientRects`); доступная область экрана — как весь экран; только стандартные голоса синтеза речи. Шум свой для каждого сайта и новый при каждом запуске. По желанию — часовой пояс UTC и английский язык. Строка браузера — как у Safari этой macOS, `globalPrivacyControl = true`. |
| **Ссылки** | Метки слежки (`utm_*`, `fbclid`, `gclid`, `yclid`, `ysclid` и сотни из списка AdGuard) убираются до загрузки. Переходники `google.com/url`, `vk.com/away.php`, `l.facebook.com` и другие пропускаются. |
| **SponsorBlock** | Спонсорские вставки, самореклама и «подпишитесь» в роликах YouTube пропускаются сами, с подсказкой и кнопкой «Отменить». Отрезки — из открытой базы SponsorBlock; запрос идёт по первым 4 знакам хеша id ролика, сервер не знает, какой ролик вы смотрите. |

### Данные и изоляция

| | |
|---|---|
| **Уборка за сайтами** | Через 15 секунд после закрытия последней вкладки сайта его cookie и хранилище удаляются — вместе с cookie трекеров. При выходе — всё. Кроме сайтов, где вы включили «Помнить вход». |
| **Контейнеры** | «Личное», «Работа», «Покупки», «Банк», «Соцсети» и свои: у каждого отдельные cookie и данные. Сайт можно закрепить за контейнером. |
| **Одноразовые вкладки и частные окна** | Хранилище только в памяти: закрыли — исчезло. У частных окон свой секрет отпечатка. |
| **Прокси для окон** | Все окна или только частные — через SOCKS5, например через Veil. Через прокси идут и страницы, и DNS; если прокси выключен, сайты не откроются напрямую. В таких окнах сам выключается WebRTC — иначе он раскрыл бы настоящий IP. |
| **История** | Только на этом Mac и в зашифрованном виде (AES-256, ключ в Связке ключей). Окно «История» (⌘Y) — по желанию после Touch ID. |
| **«Стереть всё»** | ⇧⌘⌫: все окна закрываются, данные всех сайтов во всех контейнерах, история и вкладки удаляются. |

### Безопасность

| | |
|---|---|
| **Подделки** | Адреса, похожие на банки и сервисы (`sberbamk.ru`, `paypa1.com`, `gosuslugi-pay.ru`, `paypal.com.secure-login.net`), и домены из букв другого алфавита — предупреждение до открытия. Международные домены показываются буквами, если это обычное имя, и в punycode, если алфавиты смешаны. |
| **Строгий режим** | Режим блокировки Apple (Lockdown Mode) для страниц: без JIT, WebGL, WebAssembly и сложных шрифтов. Выключен, на незнакомых сайтах или везде; на отдельном сайте — в щите. |
| **HTTPS и пароли** | Сначала всегда HTTPS; если сайт не умеет — предупреждение. На странице без шифрования — предупреждение при вводе пароля. |
| **Сертификат** | В щите — кто выдал сертификат и до какого числа он действует; на незнакомом сайте со свежим сертификатом — предупреждение. |
| **Опасные сайты и загрузки** | Адреса из URLhaus и uBlock Badware проверяются на Mac до обращения к сайту; загрузки с них не начинаются. Программы без HTTPS — с предупреждением. У каждого файла — SHA-256 и пометка Gatekeeper. Плюс Safe Browsing через серверы Apple. |
| **Песочница macOS** | Ward работает в App Sandbox с hardened runtime: даже взломанная страница сможет только ходить в сеть, писать в «Загрузки» и открывать файлы, которые вы выбрали сами. |
| **Разрешения** | Камера и микрофон — по запросу, с запоминанием для сайта, или запрет без вопроса. Все особые настройки сайтов — на одном экране. |

| | |
|---|---|
| **Поиск** | DuckDuckGo по умолчанию; Startpage, Brave Search, Ecosia, Mojeek, Google, Яндекс. Подсказки — только из вашей истории и избранного. |
| **Никакой телеметрии** | Сам Ward ходит в сеть только за свежими списками фильтров (раз в сутки) и, если включён SponsorBlock, за отрезками роликов YouTube. |

## Сборка

```bash
./scripts/build.sh          # списки фильтров + Ward.app + Ward.dmg в dist/
./scripts/build.sh --no-dmg # только .app
```

Нужны macOS 26 и Xcode 26. Списки скачиваются при сборке и кладутся в приложение, так что защита работает
с первого запуска даже без сети.

## Самопроверки

- **`node Tests/js-tests.mjs`** — синтаксис всех скриптов защиты и поведение скриптлетов на заглушках браузера.
- **`--selftest-logic`** (без сети, в песочнице):
  - перевод шаблонов в регулярные выражения и разбор всех видов правил;
  - скриптлеты (домены, исключения, `youtube.*`, доверенные списки) и процедурная косметика;
  - очистка ссылок, адресная строка, домены;
  - punycode и подделки под известные сайты (и отсутствие ложных срабатываний на настоящих);
  - чтение настроек, сеанса и счётчиков прошлой версии;
  - синтаксис скриптов в JavaScriptCore и разбор всех встроенных списков.
- **`--selftest-webkit`** (настоящий WebKit, копия с правом поднять стенд на этом Mac):
  - сборка всех правил и повторный запуск из готовых;
  - реклама, трекеры, косметика, отпечаток, очистка ссылок, опасные адреса, HTTPS, частное окно;
  - скриптлеты и процедурная косметика, отказ от cookie, подделки, пароль на странице без шифрования,
    строгий режим, контейнеры и одноразовые вкладки, уборка за закрытыми сайтами, прокси (и DNS через него),
    WebRTC в окне через прокси, загрузка с SHA-256, шифрование истории, песочница;
  - по сети: скрытый трекер через DNS, SponsorBlock, сертификат, CreepJS.
- **`--demo-ui <экран>`** — скриншоты на живых сайтах.
