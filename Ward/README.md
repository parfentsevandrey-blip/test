# Ward — браузер, который не даёт следить

Седьмое приложение каталога (см. [манифест](../MANIFESTO.md)). Браузер для Mac, у которого главная задача —
безопасность и приватность: реклама, трекеры, отпечаток браузера, метки в ссылках и опасные сайты
останавливаются ещё до запроса. Swift 6, SwiftUI, Liquid Glass, русский интерфейс.

## Почему WebKit, а не Chromium

Ward построен на WebKit — движке Safari, который уже есть в каждой macOS. Это не сторонний код, а системная
библиотека, поэтому правило «всё с нуля» соблюдено. Своё в Ward:
- блокировщик;
- защита от отпечатка;
- очистка ссылок;
- проверка опасных адресов;
- интерфейс.

Почему не Chromium:
- **Лёгкость.** Ward весит несколько мегабайт вместе со списками фильтров. Chromium весит сотни мегабайт и
  собирается часами.
- **Обновления безопасности.** Движок обновляет сама macOS, вместе с Safari. Браузер на своём Chromium без
  команды из десятков человек отстаёт от исправлений уязвимостей.
- **Расширения Chrome Web Store не нужны.** uBlock Origin, Privacy Badger и подобные — это способ
  добавить защиту в чужой браузер. В Ward та же работа встроена в движок и делается правилами WebKit:
  страница не может их обойти или заметить.

## Что делает Ward

| | |
|---|---|
| **Реклама и трекеры** | Списки EasyList, EasyPrivacy, uBlock Origin (фильтры, приватность, опасные сайты, починка), RU AdList, Peter Lowe, URLhaus, AdGuard URL Tracking, EasyList Cookie (и по желанию — «Помехи»). Собственный переводчик синтаксиса Adblock/uBlock в правила блокировщика WebKit (сетевые правила, `$third-party`, `$domain`, типы ресурсов, исключения, `$document`, `$generichide`, `$badfilter`, косметика `##`/`#@#`). Правила применяет сам WebKit до запроса — как блокировщики Safari, без замедления страниц. |
| **Кто следил** | Щит в адресной строке: сколько остановлено на странице и кто именно — Google, Яндекс, Meta, VK, Criteo… Счётчики «сегодня» и «всего» на новой вкладке. |
| **Отпечаток браузера** | Шум в холсте (`toDataURL`, `getImageData`), WebGL (`readPixels`, имя видеокарты), звуке (`AudioBuffer`, `AnalyserNode`), ширине текста (по ней узнают шрифты). Шум свой для каждого сайта и новый при каждом запуске: внутри сайта отпечаток стабилен, между сайтами и сеансами — разный. Подмена выглядит как встроенная функция, защищает и пустые фреймы. Число ядер — как у большинства Mac, `navigator.globalPrivacyControl = true`, строка браузера — как у Safari этой macOS. |
| **Ссылки** | Метки слежки (`utm_*`, `fbclid`, `gclid`, `yclid`, `ysclid` и сотни из списка AdGuard) убираются до загрузки — сайт их не получает. Переходники `google.com/url`, `vk.com/away.php`, `l.facebook.com`, `youtube.com/redirect` и другие пропускаются: сайт, откуда вы ушли, не узнаёт куда. |
| **HTTPS** | Сначала всегда HTTPS. Если сайт так не умеет — предупреждение, прежде чем открыть его без шифрования. |
| **Опасные сайты** | Адреса из URLhaus и uBlock Badware проверяются на Mac до обращения к сайту. Плюс Safe Browsing через серверы Apple, как в Safari. |
| **Данные** | Cookie и данные сайтов стираются при выходе (кроме сайтов, где вы попросили «Помнить вход»). Частные окна живут только в памяти и со своим секретом отпечатка. «Забыть этот сайт» в щите. |
| **На отдельном сайте** | Выключить защиту, выключить JavaScript, помнить вход — в щите. |
| **Загрузки** | В «Загрузки», с пометкой Gatekeeper «скачано из интернета». |
| **Поиск** | DuckDuckGo по умолчанию; Startpage, Brave Search, Ecosia, Mojeek, Google, Яндекс. Подсказки — только из вашей истории и избранного: каждая набранная буква не уходит поисковику. |
| **Никакой телеметрии** | Сам Ward ходит в сеть только за свежими списками фильтров (раз в сутки). |

## Сборка

```bash
./scripts/build.sh          # списки фильтров + Ward.app + Ward.dmg в dist/
./scripts/build.sh --no-dmg # только .app
```

Нужны macOS 26 и Xcode 26. Списки скачиваются при сборке и кладутся в приложение, так что защита работает
с первого запуска даже без сети.

## Самопроверки

- **`--selftest-logic`** (без сети):
  - перевод шаблонов в регулярные выражения;
  - разбор всех видов правил;
  - части правил и исключения;
  - очистка ссылок и переходников;
  - адресная строка, домены;
  - синтаксис скриптов защиты в JavaScriptCore;
  - разбор всех встроенных списков.
- **`--selftest-webkit`** (настоящий WebKit):
  - сборка всех правил и повторный запуск из готовых;
  - стенд на этом Mac: рекламные картинки, Google Tag Manager, Яндекс Метрика и пиксель Facebook не
    загружаются, обычные ресурсы загружаются, `###ad_banner` скрыт;
  - отпечаток холста разный на разных сайтах и стабилен на одном (без защиты одинаков везде);
  - очистка ссылок до загрузки — сервер не получил `fbclid`;
  - опасный адрес даёт предупреждение без запроса;
  - HTTPS вместо HTTP;
  - защита выключена на сайте — всё грузится.
- **`--demo-ui <экран>`** — скриншоты на живых сайтах.
