# Агент ценообразования — прототип

Telegram-агент, который по клику даёт рыночный коридор цены и рекомендацию
снизить / держать / поднять по квартирам из реестра продаж.

**Пути реализации, методика, источники данных и оценка сроков — в
[`docs/IMPLEMENTATION.md`](docs/IMPLEMENTATION.md).** Здесь только как запустить.

## Главный принцип

Цену считает детерминированный код, а не языковая модель. LLM получает готовый вердикт
и пересказывает его человеческим языком, не имея возможности изменить число. Рекомендация
по лоту за сотни миллионов должна быть воспроизводимой и проверяемой построчно.

```
источники данных  →  ядро (детерминированный код)  →  LLM  →  Telegram
                     ← здесь считается ЦЕНА          ← здесь ТЕКСТ
```

## Запуск

```bash
pip install -r requirements.txt

python scripts/parse_registry.py data/reestr.xlsx data/registry.json   # xlsx → JSON
python scripts/make_demo_comps.py                                      # демо-аналоги
python -m agent.cli                                                    # вердикты по всем лотам
python -m agent.cli sky-house-6                                        # разбор одного лота
```

Бот:

```bash
cp .env.example .env      # как минимум TELEGRAM_BOT_TOKEN
python -m agent.bot
```

`ANTHROPIC_API_KEY` не обязателен: без него объяснение собирается по шаблону, вердикт
не меняется. `CIAN_API_KEY` не обязателен: провайдер вернёт пустой список, и расчёт пойдёт
по остальным источникам.

## Структура

| Файл | Назначение |
|---|---|
| `agent/models.py` | Доменные модели: объект, аналог, поправка, вердикт |
| `agent/adjustments.py` | Поправки сравнительного подхода; коэффициенты в `PricingConfig` |
| `agent/pricing.py` | Коридор, перцентили, вердикт, ограничители, сценарии |
| `agent/providers/` | Интерфейс источников: демо + каркас адаптера Циан |
| `agent/narrative.py` | Объяснение вердикта через LLM с шаблонным фолбэком |
| `agent/registry.py` | Загрузка реестра + проверки консистентности своего прайса |
| `agent/bot.py` | Telegram-бот на aiogram |
| `agent/cli.py` | Тот же расчёт в терминале |
| `scripts/` | Разбор xlsx, генератор демо-данных |

## ⚠️ О данных

`data/registry.json` разобран из настоящего реестра, но **отделка и наличие машино-места
выведены эвристикой из текста комментария** — их нужно подтвердить вручную.

`data/comps_demo.json` и `data/ops_demo.json` — **синтетические**. Они сгенерированы, чтобы
прототип запускался без платных ключей, и не являются рыночной информацией. Реальные аналоги
приходят из провайдеров (`agent/providers/`).
