# Пентхаус · ночная гроза

Одностраничное 3D-демо от первого лица: пентхаус небоскрёба во время ночной
грозы. По квартире можно ходить — и, главное, её можно обжить: зажечь камин,
включить свет, поставить пластинку, открыть дверь на террасу и сесть у огня
смотреть на дождь.

**Как открыть:** двойным кликом по `penthouse/index.html`. Всё остальное
не нужно — ни сборщика, ни сервера. Единственная внешняя зависимость —
three.js r160 с CDN (unpkg), подключённый через `<script type="importmap">`.

Ассетов нет вообще: геометрия построена кодом, все текстуры нарисованы
в `<canvas>`, весь звук синтезируется через WebAudio.

## Управление

| | |
|---|---|
| `W` `A` `S` `D` | идти |
| `Shift` | быстрый шаг |
| `C` | присесть |
| `Space` | подскок |
| `E` или ЛКМ | взаимодействие |
| `F` | фонарь телефона |
| `Esc` | пауза и настройки |
| `W` / `Esc` сидя | встать |

На телефоне — два виртуальных стика и тап по предмету вместо прицела,
качество автоматически переключается на низкое. При наличии VR-шлема
появляется кнопка входа: телепорт дугой, поворот рывками по 30°,
покачивание камеры принудительно выключено.

## Что внутри

**Планировка.** ~180 м², маршрут построен так, чтобы кадры менялись на ходу:
тёмный лифтовой холл → двусветная гостиная с утопленной на две ступени
conversation pit и камином → остекление по двум смежным сторонам с углом-стыком
→ кухня-бар → ниша-библиотека с недоигранной партией в шахматы → лестница
на мезонин с рабочим столом → дверь на террасу. Две двери-обманки заперты,
но с ручками и звуком.

**Игрок.** Капсула радиусом 0.35 м, коллизии через `Octree`, движение через
ускорение и затухание `exp(-4·dt)`, покачивание при ходьбе с креном
в противофазе, отдельное idle-дыхание, инерция взгляда с лёгким перелётом.
`delta` заклампан 0.05 с — после сворачивания вкладки игрок не улетает
сквозь стену.

**Стекло.** `MeshPhysicalMaterial` с `transmission`; поле капель считается
в шейдере и подмешивается в нормаль и толщину, поэтому город за каплей
реально преломляется, а не просто светлеет. У кухни и на террасной двери —
запотевание снизу вверх.

**Гроза.** Дождь — 5600 инстансов, падение и наклон ветра целиком в вершинном
шейдере. Молния двухфазная, гром приходит через 3–9 секунд после вспышки.
Интенсивность шторма гуляет по одной медленной кривой, из которой берут
значение и картинка, и звук.

**Звук.** Дождь у каждого витража — свой источник, с окклюзией по raycast:
в прихожей глухо, у стекла звонко, на открытой террасе фильтр распахивается
и громкость растёт втрое. Треск камина — случайные импульсы через bandpass,
шаги синтезируются с тембром по поверхности под ногами (паркет, ковёр,
камень, мокрый настил), пластинка — генеративный lo-fi.

## Производительность

120 draw calls, ~47 тыс. треугольников, три пресета качества (низкий отключает
`transmission`, AO и bloom, режет число капель и башен). Карта теней
обновляется вручную — мерцание камина меняет яркость, а не геометрию.
