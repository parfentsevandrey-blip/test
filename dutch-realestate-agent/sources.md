# Ключевые источники по рынку недвижимости Нидерландов

Расширенный список ресурсов, которые агент обходит при сборе еженедельной
аналитики. Сгруппированы по типу и по сегментам. Приоритет — у первоисточников
(статбюро, банки, кадастр, регуляторы, отраслевые консультанты), затем деловые
и отраслевые СМИ, затем пресс-релизы крупных игроков.

> Совет агенту: не ограничивайся одним-двумя сайтами. По каждому сегменту бери
> минимум: первоисточник (статистика/госорган) + банк или консультант +
> отраслевое СМИ. Делай несколько разных запросов (NL и EN).

---

## 1. Статистика, кадастр, регуляторы (первоисточники)
- **CBS** — Centraal Bureau voor de Statistiek (статбюро): индекс цен жилья, аренда, стройка, экономика. https://www.cbs.nl
- **Kadaster** — кадастр, сделки и регистрация прав, цены по регионам. https://www.kadaster.nl
- **DNB** — De Nederlandsche Bank (центробанк): ипотека, фин. стабильность, обзоры рынка. https://www.dnb.nl
- **CPB** — Centraal Planbureau (макропрогнозы). https://www.cpb.nl
- **PBL** — Planbureau voor de Leefomgeving (среда, землепользование). https://www.pbl.nl
- **EIB** — Economisch Instituut voor de Bouw (экономика стройки). https://www.eib.nl
- **ABF Research** — прогнозы по жилью и демографии. https://www.abfresearch.nl
- **Belastingdienst** — налоговая служба (box 3, overdrachtsbelasting). https://www.belastingdienst.nl
- **Waarderingskamer** — надзор за оценкой недвижимости (WOZ). https://www.waarderingskamer.nl
