# Правила работы в этом репозитории

## Проект перепродажи квартир

Документы лежат в `research/ndr/lots/`. Их источник истины — scratchpad сессии `lots/`; в репозиторий они попадают через `sync_repo.py`.

- `MANIFEST.md` — цель, рамки, принципы. Читать перед любой работой.
- `INSTRUCTION.md` — способы С1–С4 и шаги процесса П1–П6 с порогами. Работа идёт только по ним.
- `STATUS.md` — исполнение каждого пункта.
- `NOTES.md` — решения по источникам данных.
- `RUNLOG.md` — **обязательный журнал прогонов**. После каждого прогона `run_report.py` добавляет запись `R-<дата>`: полнота по ЖК, сбои, аномалии `A<n>`. Каждую аномалию разобрать под «Разбор» в тот же день.
- `LESSONS.md` — уроки `L-n`. Перед исправлением любой проблемы ищем похожий урок; после исправления добавляем новый. В коммите исправления указываем номер урока, например `[С1] … (L14)`.

## Как коммитить

- Каждый коммит по проекту начинается с пункта инструкции: `[С2] выбытие объявлений между снимками`. Если пунктов несколько — `[С1][П2] ...`.
- В том же коммите обновляется `STATUS.md`: статус, что сделано, следующий шаг.
- Автоматические снимки (`Lots snapshot ...`, `NDR ...`) идут без префикса.
- Изменения `MANIFEST.md` и порогов в `INSTRUCTION.md` — только по решению владельца, отдельным коммитом с причиной.

## Ограничения

- Сбор данных — Scrapling, бережно:
  - паузы 20–40 с;
  - капчи не решаем;
  - при 403, 429 или капче останавливаемся.
- Отступления от `robots.txt` — только по решению владельца и с записью в `NOTES.md`.
- Не используем: агентов, выгрузки сделок Росреестра, `api.cian.ru`.
- Не коммитим профили браузера, куки и сырые страницы: `raw/`, `session_*`, `profile*`.
- Ветка — `claude/clever-ride-v467su`. Pull request не создавать без просьбы.

## Автозапуск

- `.claude/hooks/session-start.sh` возобновляет скан наш.дом.рф (`research/ndr/resume_scan.sh`) и дневные снимки (`research/lots_resume.sh`): лоты ЦИАН (`collector.py`) и каталоги застройщиков [С1] (`devcat.py`).
- Сбор идёт только пока сессия активна.
