## Откуда данные

**Главная находка: у AURIX есть открытый поквартирный подбор.** Страница
`aurix-development.ru/vybor-po-parametram/kvartiry` отдаёт список лотов прямо
в HTML, размеченный микроданными `schema.org/Apartment` — то есть парсится
без JavaScript. Всего в подборе **149 лотов** по четырём проектам бренда,
из них **20 московских**: 17 в «Арбате 2» и 3 в «Резиденции Омега».

На карточке каждого лота лежат три планировки под ключами `furnlayouturl`
(с мебелью), `layouturl` (без мебели) и `planurl` (положение на этаже).
В справку взят вариант с мебелью — тот же, что показывает сайт первым.

Параметры проектов, визуализации и координаты домов — со страниц проектов
на сайте застройщика.

**Про сайты `arbat2.ru` и `omega-residence.com`.** В подвале обоих написано:
«Данный сайт не является официальным сайтом застройщика». Числовые данные
оттуда не брались, и не зря: по «Арбату 2» они дают **66 машино-мест
и 42 кладовые**, тогда как страница проекта на сайте AURIX называет
**18 машино-мест**. Расхождение принципиальное, в справке стоит официальная
цифра. Визуализации оттуда используются — это те же кадры, что в официальной
галерее, просто их больше.

## Арбат 2

| Параметр | Значение |
|---|---|
| Адрес | Москва, улица Новый Арбат, 2 |
| Класс | Deluxe |
| Готовность | 2025 год — дом построен |
| Что было на месте | «Дом связи» 1965 года постройки |
| Квартир в доме | 23, из них 2 пентхауса с видом на Кремль |
| Этажность | 12 |
| Потолки | до 3,5 м |
| Паркинг | 18 машино-мест |
| Лоты в продаже | 17 квартир на 10-м и 11-м этажах |
| Метро | «Арбатская», 174 м |

**Цены:** 17 лотов, 46,6–168,7 м², 127,2–500,6 млн ₽. Метр **2 706–2 968 тыс. ₽**,
средневзвешенный **2 822 тыс. ₽**. Сумма всех лотов — 3,42 млрд ₽ за 1 212 м².

Что видно из прайса:

- разброс цены метра всего **10 %** между самым дешёвым и самым дорогим лотом —
  для готового дома это значит, что прайс сформирован разом, а не по мере продаж;
- одиннадцатый этаж дороже десятого на **2,2 %** по метру, крупные лоты дороже
  мелких на **1,3 %** — надбавок за этаж и скидок за объём практически нет,
  цена почти линейна по площади;
- половина предложения — лоты до 55 м². Для deluxe это нетипично мелкий формат,
  и он согласуется с тем, что дом рассчитан в том числе на сдачу: управляющая
  команда берёт на себя подбор жильцов.

| Параметр | Арбат 2 | Резиденция Омега |

| Площади, м² | 46,6 – 168,7 | 89,8 – 134,1 |

| Средневзвешенный метр, ₽ | 2 821 950 | 1 974 350 |

Метр в «Арбате 2» дороже на **43 %**. Разрыв объясняется сразу двумя вещами:
готовый дом против сдачи в 2030 году и Новый Арбат против Гагаринского района.

Паркинг устроен противоположно: в готовом доме в центре мест меньше, чем
квартир, а в строящемся — больше одного на квартиру.

## Пересборка

```bash
pip install Pillow
npm install docx

python3 ax2_lots.py     # список лотов с подбора -> ax2_lots.json
python3 ax2_plans.py    # карточки лотов и планировки -> ax2_msk.json, plans/
python3 ax2_media.py    # визуализации со страниц проектов -> src/img/
python3 ax2_data.py     # таблицы и расчёты -> ax2_tables.json
python3 ax2_maps.py     # три карты -> assets/ax2_map*.png
python3 ax2_renders.py  # кропы визуализаций -> assets/*.jpg
python3 ax2_assets.py   # PNG -> JPEG в assets/
cp plans/*.png assets/
cat ax2_head.js ax2_body.js > ax2_build.js && node ax2_build.js
```

`ax2_head.js` — хелперы вёрстки из остальных справок плюс новый `flatCards`:
карточка лота с планировкой, площадью, корпусом, этажом, ценой и ценой за метр.
`ymap.py` и `markers.py` — сшивка тайлов Яндекс Карт и отрисовка пинов.
