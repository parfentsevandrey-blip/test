# Реестр торгов

`reestr_torgi.xlsx` в корне репозитория — эталон формата (утверждён 20.10.2026).
Новые лоты собираются в этом же формате: `python3 torgi/build_reestr.py` пересобирает файл из `torgi/lots.json`.

## Формат

Один лист «Реестр», «умная таблица» Excel `Reestr` (стрелки сортировки и фильтра в заголовках), без шапки
над таблицей и без текста под ней. Тема — графит + коралл (`#2B2D31` / `#E0533D`), шрифт Arial 10.

| № | Столбец | Источник / правило |
|---|---|---|
| A | № | порядковый номер, коралловый жирный |
| B | Тип объекта | |
| C | Адрес | жирный |
| D | Округ | |
| E | Район | |
| F | Метро | |
| G | Площадь, м² | `#,##0.0`; комментарий в ячейке, если площадь взята не из карточки |
| H | Участок, м² | только для зданий с ЗУ |
| I | Этаж | |
| J | Этажность | |
| K | ОКН | «Да» подсвечивается янтарным |
| L | Начальная цена, ₽ | жирный 11 pt |
| M | Цена за м², ₽ | формула `L/G`, полоса-индикатор |
| N | Задаток, ₽ | `#,##0.00` |
| O | Шаг аукциона, ₽ | `#,##0.00`, «—», если нет на странице |
| P | Приём заявок до | дата и время МСК |
| Q | Дней до конца приёма | формула от `TODAY()`: ≤14 красный, ≤30 жёлтый, >30 зелёный |
| R | Дата торгов | дата и время МСК |
| S | Карточка | «открыть ↗» → investmoscow.ru, для лотов roseltorg — страница процедуры |

Разделители блоков (коралловая вертикальная линия) — перед G, L и S. Пустые текстовые значения — серый «—».

## Где брать данные

- **investmoscow.ru** — цены, задаток, шаг, сроки и ссылки на ЭТП/torgi.gov.ru лежат в блоке «О процедуре»
  в `__NUXT_DATA__` карточки. Из облачной среды сайт открывается через `https://r.jina.ai/<url>`
  с заголовком `X-Return-Format: html`.
- **roseltorg.ru** — напрямую недоступен из-за пределов РФ; открывается через прокси Яндекс.Переводчика:
  `https://translated.turbopages.org/proxy_u/ru-ru.ru/https/www.roseltorg.ru/procedure/<номер>/1`.
- **torgi.gov.ru** — задаток и шаг по извещению; зеркало с теми же данными — torgi-ru.com.
