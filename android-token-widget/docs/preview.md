# Раскладки виджета

Glance выбирает раскладку автоматически по размеру, заданному пользователем при
ресайзе на рабочем столе.

### Compact (≈ 2×1)
Две тонкие дорожки `S` (сессия) и `W` (неделя) с процентами — помещается в одну
строку домашнего экрана.

```
┌───────────────────────────┐
│ S ▰▰▰▰▱▱▱▱▱▱  42%          │
│ W ▰▰▱▱▱▱▱▱▱▱  18%          │
└───────────────────────────┘
```

### Medium (≈ 3×2)
Заголовок «Claude · tokens» и две подписанные дорожки.

```
┌───────────────────────────┐
│ Claude · tokens            │
│ Сессия              42%    │
│ ▰▰▰▰▰▱▱▱▱▱▱▱▱▱▱▱▱▱▱▱        │
│ Неделя              18%    │
│ ▰▰▰▱▱▱▱▱▱▱▱▱▱▱▱▱▱▱▱▱        │
└───────────────────────────┘
```

### Large (≈ 4×3)
Заголовок с кнопкой обновления ↻, дорожки с числом токенов и временем до сброса.

```
┌─────────────────────────────────┐
│ Claude · tokens              ↻   │
│ Сессия                    42%    │
│ ▰▰▰▰▰▱▱▱▱▱▱▱▱▱▱▱▱▱▱▱▱▱▱▱▱▱        │
│ 84K / 200K              ↻ 3ч     │
│ Неделя                    18%    │
│ ▰▰▰▱▱▱▱▱▱▱▱▱▱▱▱▱▱▱▱▱▱▱▱▱▱▱        │
│ 1.3M / 7.0M             ↻ 5д     │
└─────────────────────────────────┘
```
