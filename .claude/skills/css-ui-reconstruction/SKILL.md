# Реконструкция интерфейса кодом

Скриншоты не используются: всё рисуется CSS и SVG. Это вопрос прав и одновременно суть работы.

## Каркас устройства
- Корпус — один `<div>` с `border-radius`, внутренним `box-shadow` для фаски и внешним для объёма. Пропорции экрана брать реальные (3.5" iPhone — 320×480 CSS-px в масштабе 1:1, iPhone X — 375×812, Nexus/Pixel — 360×640).
- Вырез, «чёлка» и Dynamic Island — не картинка, а `border-radius` + `mask-image` или SVG-путь.
- Статус-бар всегда рисуется отдельно и всегда соответствует эпохе: шрифт, набор индикаторов, положение часов.

## Скевоморфизм (2007–2012)
- Кожа, сукно, дерево, льняная текстура: `feTurbulence` в SVG-фильтре как основа шума, поверх — `background-blend-mode: multiply` и цветовой слой. Никаких растровых паттернов.
- Объём кнопки — три слоя: верхний `linear-gradient`, `inset 0 1px 0 rgba(255,255,255,.45)` для блика, внешняя тень для отрыва от фона.
- Прошитый шов — `border` в цвет нитки + `border-style: dashed` внутри `::after`.

## Плоская эпоха (2013–2016)
- Полупрозрачность iOS 7 — `backdrop-filter: saturate(180%) blur(20px)` поверх подложки. Без фолбэка не оставлять: `@supports not (backdrop-filter: blur(1px))` даёт сплошную заливку.
- Толщина линий имеет значение: у iOS 7 иконки и глифы — hairline, `stroke-width` 1–1.5 при 24px вьюбоксе.

## Material (2014–)
- Elevation — не произвольная тень, а пара теней (ambient + key) по уровням 1/2/3/4/6/8/12/16/24 dp.
- Ripple — `radial-gradient` в псевдоэлементе, анимация `transform: scale()` + `opacity`, старт из точки клика через CSS-переменные `--x`/`--y`.
- Material You: базовый цвет в CSS-переменной, остальные тона выводятся через `color-mix()` в OKLCH.

## Типографика эпох
- Apple: `-apple-system, "SF Pro Text", system-ui`. Для 2007–2014 — фолбэк на Helvetica/Arial, а не на SF.
- Google: Roboto для 2011+, для 2008–2010 — Droid Sans, при отсутствии брать ближайший гротеск и пометить это в комментарии к коду.
- Никогда не подменяй историческую гарнитуру современной молча.

## Правила
- Каждая реконструкция — самостоятельный компонент с собственным scope стилей (кастомные свойства + вложенность), чтобы стили эпох не текли друг в друга.
- Реконструкция обязана быть интерактивной хотя бы в одном месте: свайп шторки, нажатие иконки, переключение экрана.
- Проверяй результат визуально, а не «по коду»: сделай скриншот и сравни с реальным референсом по памяти и описанию.
