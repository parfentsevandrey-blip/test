# Ореол (Halo)

Частная сеть из твоих устройств: телефона, ноутбуков, домашнего компьютера.
Без серверов, подписок и аккаунтов. Каждое устройство получает постоянный адрес
вида `100.92.171.193`, и по нему его видят остальные — дома и вне дома, как
будто все в одной сети. SSH, общие папки, домашний сервер, удалённый рабочий
стол работают по этим адресам.

- **Сопряжение одним сканом.** Компьютер показывает QR-код, телефон сканирует,
  оба экрана показывают одни и те же четыре эмодзи — и устройства в сети.
  Остальные узнают о новом устройстве сами.
- **Напрямую.** Трафик идёт от устройства к устройству, зашифрованный (QUIC,
  TLS 1.3), без чужих серверов посередине. Дома устройства находят друг друга по
  Wi-Fi сами.
- **Вне дома.** Домашний компьютер сам просит у роутера открыть порт и сообщает
  остальным свой адрес. Телефон в мобильной сети дозванивается до него. Если два
  устройства вне дома не могут соединиться напрямую, связь идёт через домашнее.
- **Только свои.** Устройство не из сети отклоняется сразу после рукопожатия.
  Потерянный телефон удаляется одной командой, и его перестают пускать все.
- **Всегда включено.** На компьютере Ореол работает службой и включается вместе
  с системой. На Android — «Постоянная VPN».

## Установка

Файлы — на [странице релиза](https://github.com/parfentsevandrey-blip/test/releases/tag/halo-v1.0.0).

### macOS (Apple Silicon и Intel)

В Терминале:

```sh
curl -fsSL https://github.com/parfentsevandrey-blip/test/releases/download/halo-v1.0.0/halo-macos.tar.gz | tar -xz
sudo ./halo install
```

`install` кладёт программу в `/usr/local/bin`, регистрирует службу и включает
сеть. Если брандмауэр macOS включён, Ореол добавляется в разрешённые.

Если скачиваешь браузером, macOS пометит файл как скачанный из интернета и не
даст его запустить. Перед `install` сними пометку: `xattr -d com.apple.quarantine
halo`.

### Windows 10 и 11

1. Скачай `halo-windows-x64.zip` и распакуй. `halo.exe` и `wintun.dll` должны
   лежать в одной папке.
2. Открой PowerShell **от имени администратора** в этой папке и выполни:

```powershell
Unblock-File .\halo.exe, .\wintun.dll
.\halo.exe install
```

`install` копирует программу в `C:\Program Files\Halo`, регистрирует службу
«Halo» и добавляет правила брандмауэра. Правила пропускают трафик Ореола и
входящие подключения от твоих устройств к адресу этого компьютера в сети.

### Linux (x86-64, systemd)

```sh
curl -fsSL https://github.com/parfentsevandrey-blip/test/releases/download/halo-v1.0.0/halo-linux-x64.tar.gz | tar -xz
sudo ./halo install
```

### Android 8 и новее

Скачай на телефон `halo-android.apk` и открой его. Android попросит разрешить
установку из этого источника.

Если стояла тестовая сборка Ореола (`app-debug.apk` из Actions), сначала удали
её: релиз подписан другим ключом и поверх неё не встанет. Телефон потом нужно
будет сопрячь заново, а старую запись удалить с компьютера: `sudo halo remove
<имя>`.

## Соединить устройства

На компьютере (на Windows — в PowerShell от администратора, `.\halo.exe pair`):

```sh
sudo halo pair
```

Появится QR-код.

- **Телефон:** в приложении «Добавить устройство» → «Сканировать QR». Оба экрана
  покажут четыре эмодзи. Если совпадают, нажми «Совпадают» на телефоне и ответь
  `y` на компьютере. Потом нажми на кольцо в приложении: Android один раз спросит
  разрешение на VPN.
- **Другой компьютер:** под QR-кодом есть текстовый код `HALO/1/...`. На втором
  компьютере выполни `sudo halo pair --join HALO/1/...` и сравни эмодзи.

Третье устройство достаточно сопрячь с любым из уже соединённых: остальные
узнают о нём сами, когда окажутся в сети вместе с ним.

Проверить:

```sh
sudo halo status
```

```
service:  running, starts with the computer
device:   100.114.136.195 (e91e09516f)
network:  on (process 812)
internet: reachable at 203.0.113.7:7777
  pixel-8          100.92.171.193   direct 192.168.1.20:7777, 4 ms
  work-laptop      100.71.3.88      direct 198.51.100.23:41641, 38 ms
```

`direct` — соединение напрямую, `through <имя>` — через другое твоё устройство,
`not connected` — устройство сейчас недоступно (выключено, спит, вне сети).

Каждое устройство видно по его адресу из этого списка: `ping 100.92.171.193`,
`ssh 100.71.3.88`, `\\100.71.3.88\share` в Проводнике, `http://100.114.136.195:8080`
для домашнего сервера.

## На телефоне

- Кольцо включает и выключает сеть. Под каждым устройством видно, как оно
  соединено: «напрямую 192.168.1.20:7777 · 4 мс» или «через macbook».
- «Включать вместе с телефоном» открывает настройки VPN. Там нажми ⚙ рядом с
  «Ореол» и включи «Постоянная VPN». Тогда сеть сама включается после
  перезагрузки и обновления приложения. «Блокировать соединения без VPN» не
  включай: через Ореол идут только адреса твоих устройств, и с этой опцией у
  телефона пропадёт остальной интернет.
- Через Ореол идут только адреса твоих устройств. Остальной трафик телефона его
  не касается.

## Вне дома

Ноутбук или компьютер дома сам просит у роутера проброс порта (UPnP, NAT-PMP или
PCP). Получилось, если `sudo halo status` показывает строку
`internet: reachable at …`. Телефон узнаёт этот адрес, пока он дома, и потом
дозванивается по нему из мобильной сети или из чужого Wi-Fi.

Если строка говорит `not reachable`:

- включи UPnP в настройках роутера (обычно раздел «Сеть», «NAT» или
  «Домашняя сеть»);
- или пробрось на роутере порт 7777/UDP на этот компьютер вручную и добавь его
  адрес на остальных устройствах: `sudo halo add <ID> --name <имя> --addr
  <публичный_IP>:7777` (ID — из `sudo halo id`).

Не поможет, если провайдер выдаёт роутеру «серый» адрес (CGNAT): в настройках
роутера внешний адрес вида `100.64…`–`100.127…` или `10…`. Тогда снаружи до дома
можно достать только по IPv6, если провайдер его даёт. «Белый» адрес у
провайдера обычно можно заказать.

## Команды

| Команда | Что делает |
|---|---|
| `halo install` | включает сеть службой: сейчас и после каждой перезагрузки; повторный запуск обновляет службу |
| `halo status` | включена ли сеть и как соединено каждое устройство |
| `halo pair` | сопрягает с телефоном или другим компьютером |
| `halo members` | все устройства сети, их адреса и кто кого добавил |
| `halo remove <имя>` | удаляет устройство из сети насовсем, для всех |
| `halo uninstall` | выключает и удаляет службу; ключ и список устройств остаются |
| `halo id` | ID и адрес этого устройства |
| `halo up` | сеть в этом терминале, без службы (Ctrl+C — выключить) |

На macOS и Linux команды запускаются через `sudo`: `sudo halo status`. На
Windows — в PowerShell от администратора, из папки с `halo.exe`:
`.\halo.exe status`.

## Обновление

Скачай новую версию и выполни `sudo ./halo install` (на Windows
`.\halo.exe install`): служба заменится, ключ и устройства останутся. На
телефоне поставь новый APK поверх старого.

## Если что-то не так

- `sudo halo status` показывает, работает ли служба и что с каждым устройством.
- Лог службы: на Linux `journalctl -u halo`, на macOS
  `/Library/Application Support/Halo/halo.log`, на Windows
  `C:\ProgramData\Halo\halo.log`.
- Устройство «not connected» дома: оба должны быть в одной сети Wi-Fi, а на
  Windows — с правилами брандмауэра из `halo install`.
- Устройство «not connected» вне дома: см. «Вне дома». Ноутбук со спящей крышкой
  недоступен, поэтому домашним узлом лучше сделать то, что не спит.

## Потерял телефон

С любого своего устройства выполни `sudo halo remove <имя-телефона>`. Остальные
узнают об этом при следующем соединении и перестанут его пускать. Удаление
окончательное. Вернуть устройство в сеть можно только с новым ключом: стереть
данные приложения (или каталог Ореола на компьютере) и сопрячь заново.

Ключ устройства и список устройств хранятся в `/Library/Application Support/Halo`
(macOS), `C:\ProgramData\Halo` (Windows) и `/var/lib/halo` (Linux), доступных
только администраторам. На Android — в личных файлах приложения; облачные бэкапы
для них выключены.

## Ограничения

- Вне дома нужен хотя бы один узел, до которого можно достучаться из интернета:
  компьютер дома за роутером с UPnP и «белым» адресом, или с IPv6. Если все
  устройства за CGNAT или в мобильных сетях, связи между ними не будет: серверов,
  через которые она могла бы пойти, у Ореола нет намеренно.
- Если домашний адрес сменился, пока все устройства вне дома, они узнают новый
  только при следующей встрече с домашним.
- Связь через домашний узел упирается в скорость отдачи домашнего интернета.
  Этот узел видит IP-пакеты, которые пересылает, поэтому пересылкой занимаются
  только твои же устройства.
- Внутри сети только IPv4. Сеть занимает диапазон `100.64.0.0/10` и может
  мешать другой программе с тем же диапазоном (например, Tailscale).
- Программы для macOS и Windows не подписаны сертификатом разработчика, отсюда
  `xattr` и `Unblock-File` при установке.
- Украденное и разблокированное устройство, пока его не удалили, может само
  удалить остальные. Поэтому удали его сразу.
