# Премиум-ЖК ЦАО: Садовое кольцо, Хамовники, Сити (дома 2018+)

Итоговый файл: **`premium-zhk-cao.xlsx`**, три листа:

1. **Построено (вторичка)** — ЖК с годом дома 2018+ и активными объявлениями на Циан.
2. **Строится** — таблица заказчика (скан `pdf-table.json`), дополненная живой выдачей Циан, плюс строящиеся ЖК, найденные в выдаче по новостройкам ЦАО.
3. **Проектирование** — участки (ЗУ, КРТ, ГПЗУ) и анонсированные проекты без стройки, по открытым публикациям 2025–2026 (`planning.json`).

## Как собрано

```bash
# 20 запросов: 10 районов ЦАО × (вторичка с домом 2018+ | новостройки)
for q in tools/cian/queries/premium-cao/*.json; do
  node tools/cian/cian.js search --query $q --all --pages 15 --out lots/$(basename $q)
done
node tools/cian/aggregate-complexes.js lots/*.json --out docs/premium-cao/complexes.json
python3 tools/cian/build-premium-xlsx.py
```

Зоны: Садовое кольцо (контур из `cian.js`, по координатам лота), Хамовники (район целиком), Сити (прямоугольник вокруг ММДЦ), Пресня (жёлтый контур с карты заказчика: ТТК — Звенигородское шоссе — Пресненский Вал — Грузинский Вал — Васильевская/Красина — Садовое до Нового Арбата — набережные до Сити) и Белорусская (900 м от станции). Всё вне этих зон в файл не попадает.

Порог «премиум» — медиана ₽/м² по активным лотам не ниже 700 000; класс «делюкс» проставлен вручную в `manual.json` там же, где застройщик. Пустой застройщик — не подтверждён по открытым данным.

## Файлы

| Файл | Что |
|---|---|
| `premium-zhk-cao.xlsx` | результат |
| `complexes.json` | сводка по ЖК из выдачи Циан (дата в поле `fetched`) |
| `pdf-table.json` | таблица заказчика, перепечатана со скана |
| `planning.json` | проектируемые объекты, с источниками |
| `manual.json` | ручная разметка: застройщик, класс, зона, соответствие строк таблицы ЖК в выдаче |
