## Как собрано

```bash
python3 tools/domrf/fetch.py     # карточки лотов в *.txt/*.html
```

Три вещи, о которые спотыкается забор с торги.дом.рф:

1. **JS-челлендж ServicePipe.** `curl` и `WebFetch` получают 403 либо страницу
   со спиннером. Нужен настоящий браузер: сначала заход на корень сайта за
   куками, потом карточки лотов.
2. **TLS.** Через прокси Chromium с TLS 1.3 получает `ERR_CONNECTION_RESET` —
   ClientHello с постквантовым ключом рвётся на middlebox. Браузер запускается
   с `--ssl-version-max=tls1.2`. Ровно та же грабля, что описана в
   [`docs/cian/README.md`](../cian/README.md) — симптом не зависит от сайта,
   рвётся любой хост, включая `example.com`.
3. **API не отдаёт лот по номеру.** Ручки вида `/api/v2/land/auctions/{id}/`
   отвечают `No routes found`; карточка рендерится на сервере, поэтому данные
   берутся из HTML, а не из JSON.

## Что важно знать про цифры

* **Кржижановского, вл. 15, к. 2** — лот из 19 объектов, полный перечень ДОМ.РФ
  выдаёт только по запросу через форму. Сайт показывает площадь округлённо
  (5,3 тыс. м²), поэтому цена за м² приблизительная.
* **Беговая аллея, 7А** — незастроенный участок 0,21 га. Цена за м² считается
  по земле и с застроенными лотами напрямую не сравнима.
* **Дата торгов** — дата проведения аукциона. Приём заявок закрывается раньше:
  07.09 (Будайская, Кожевническая), 14.09 (Кржижановского), 05.10 (Беговая аллея).
* **Площади строк 5–8** — суммы по перечню объектов лота; списки раскрываются
  кнопкой «Показать все объекты», иначе в HTML видны только первые три строки.
  У Оранжерейной одно здание показано округлённо (3,5 тыс. м²), поэтому сумма
  приблизительная.
* **Статусы** приведены к формулировкам реестра: «Объявленный» на сайте →
  «Торги назначены», «В агентировании» → «Планируются».
