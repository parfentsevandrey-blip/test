# Подборка коммерческих объектов

Досье по двадцати коммерческим лотам Циан в центре Москвы: характеристики,
фотографии из объявлений, карта расположения по каждому объекту и сводная
таблица по возрастанию цены за квадратный метр.

| Файл | Что внутри |
|---|---|
| [`document.docx`](document.docx) | Документ Word, 41 страница A4 |
| [`document.html`](document.html) | Тот же документ страницей. Фотографии и карты вшиты в файл, внешних зависимостей нет |
| [`offers.json`](offers.json) | Сырая выгрузка Циан по номерам объявлений, как её отдаёт `get-offers-by-ids-desktop` |
| [`ids.txt`](ids.txt) | Исходный список номеров |

## Как пересобрать

```bash
# 1. забрать объявления (нужен реальный браузер, см. ограничения ниже)
node tools/cian/commercial.js --ids docs/commercial/ids.txt --out offers.json

# 2. скачать фотографии и карты, сжать, сложить в данные
python3 tools/cian/build-doc.py --offers offers.json --out build/ --photos 6

# 3. свёрстать документ — страницей и/или в Word
python3 tools/cian/render-doc.py  --data build/lots.json --out document.html
node    tools/cian/render-docx.js --data build/lots.json --out document.docx
```

`build-doc.py` кэширует загруженное в `build/cache/`, поэтому повторный запуск
с другими параметрами сжатия сеть не трогает.

## Что важно знать про забор данных

Коммерческие лоты берутся той же ручкой `get-offers-by-ids-desktop`, что и
квартиры в [`tools/cian/cian.js`](../../tools/cian/cian.js), но с другим
`_type`: у продажи коммерции это `commercialsale`, а не `flatsale`. За один
запрос ручка отдаёт до 28 номеров.

Три ограничения, о которые спотыкается сбор (подробно — в
[`docs/cian/README.md`](../cian/README.md)):

1. **Капча.** `curl` и обычный `fetch` получают Yandex SmartCaptcha вместо
   данных. Нужен настоящий браузер с прогревом: сначала заход на `cian.ru`
   за куками, только потом запросы к API.
2. **TLS.** Через прокси Chromium с TLS 1.3 получает `ERR_CONNECTION_RESET` —
   ClientHello с постквантовым ключом рвётся на middlebox. Браузер
   запускается с `--ssl-version-max=tls1.2`.
3. **Размер документа.** Фотографии вшиваются как `data:` URI, потому что
   при публикации страницы внешние картинки режет CSP. Двадцать объектов по
   шесть кадров плюс карты — около 10 МБ; ширина и качество регулируются
   флагами `--photo-width` и `--quality`.

## Грабли Word

Два места, где документ ломается молча — оба уже обойдены в
[`render-docx.js`](../../tools/cian/render-docx.js), но повторить их легко:

* **`w:line` без `w:lineRule`.** Межстрочный интервал, заданный без правила,
  Word и LibreOffice понимают как точную высоту строки. Абзац с картинкой
  схлопывается до высоты текста, и от снимка остаётся полоска в несколько
  миллиметров. Либо ставить `lineRule: AUTO`, либо не задавать интервал на
  абзацах с изображением.
* **Кадры разной ориентации в одном ряду.** Если тянуть миниатюру по ширине
  ячейки, портретная планировка вырастает вдвое выше соседей и ряд
  рассыпается. Изображения вписываются в габарит по обеим сторонам.

Проверять рендер нужно глазами: `soffice --headless --convert-to pdf`, затем
`pdftoppm`. Схемная валидация обе ошибки пропускает — XML в них корректный.

## Карты

Статический API Яндекса (`static-maps.yandex.ru/1.x/`) по координатам из
объявления, ключ не нужен. Координаты берутся из `geo.coordinates` — они
относятся к дому, а не к геокодированному адресу, поэтому метка стоит точнее,
чем при поиске по строке адреса.
