## Как искать

Через API, а не через разбор HTML. Запрос описывается объектом `jsonQuery` —
это исходный язык фильтров Циан, query-параметры `cat.php` лишь переводятся
в него. Подробности — в [`jsonquery.md`](jsonquery.md).

```bash
# найти id ЖК, метро или района по названию
node tools/cian/cian.js find Остров

# сколько всего найдётся
node tools/cian/cian.js count --query tools/cian/queries/zao-3room.json

# собрать лоты, отсеяв апартаменты и дома старше 2016 года
node tools/cian/cian.js search --query tools/cian/queries/zao-3room.json \
  --pages 4 --all --no-apartments --min-year 2016 --out lots.json

# просмотры и срок экспозиции по конкретным объявлениям
node tools/cian/cian.js stats 332550701 331961171

# проверить заявленный «дизайнерский ремонт»: текст, поля и фотографии
node tools/cian/cian.js verify --query q.json --limit 8 --photos 6 --dir photos

# найти квартиры, выставленные повторно, и их настоящий срок экспозиции
node tools/cian/cian.js exposure --query q.json --deep 12

# большой ЖК целиком: дробление на подзапросы + схлопывание дублей в квартиры
node tools/cian/cian.js sweep --query tools/cian/queries/zhk-ostrov.json --dedupe

# положение лота в когорте: медианы по комплектности и по уровню отделки,
# для оболочки — смета доведения и справедливая цена
node tools/cian/cian.js compare --lot 327985409 --cohort akadem.json

# записать оценку отделки по фотографиям, чтобы она пережила сессию
node tools/cian/cian.js grade --lots lots.json --marks marks.json
node tools/cian/cian.js grade --list

# снимок в архив: по одному запросу, по списку запросов или из готовых файлов
node tools/cian/cian.js snapshot --queries docs/cian/watchlist.json --all
node tools/cian/cian.js snapshot --from собранное.json

# что из архива ещё продаётся, а что ушло (двумя независимыми способами)
node tools/cian/cian.js refresh

# история цены, просмотры, оценка Циан и поля, которых нет в выдаче
node tools/cian/cian.js card 327985409 331215568

# произвольные объявления по номерам, без воспроизведения поиска
node tools/cian/cian.js verify --ids 331300080,329819607 --photos 9 --dir sheets

# пересобрать docs/cian/lots.md
node tools/cian/cian.js report
```

Про `verify`, `grade` и `exposure` — отдельно в [`quality.md`](quality.md):
галочка «дизайнерский», поле «есть мебель» и дата создания объявления
заполняются продавцом и регулярно врут. Уровень отделки решают фотографии, и
шкала из шести наблюдаемых признаков нужна, чтобы это решение повторялось.

В ответе есть `aggregatedCount` — честный потолок одного прохода. Пагинация
отдаёт ровно столько и обрывается; `offerCount` считает до схлопывания
похожих объявлений и подряд недостижим.

Разбить схлопывание умеет только дробление, и лишь по одной оси — этажу.
Замер на районном запросе: 168 лотов обычным обходом против **296**
развёрткой с осью этажа и перебором сортировок:

```bash
node tools/cian/cian.js sweep --query q.json --all --limit 120
```

`search` сам предупредит, когда перечислит меньше трёх четвертей заявленного.
Подробности замера — в [traps.md](traps.md), пункт 27.

Проверить незнакомый фильтр:

```bash
node tools/cian/cian.js probe --query q.json \
  --with '{"balconies":{"type":"range","value":{"gte":1}}}'
```

`probe` показывает не только счётчик, но и то, под каким именем Циан принял
фильтр в адресе — либо что не принял вовсе.

## Ссылка для человека

Когда подборку надо открыть в браузере, ссылку строит сам Циан:

```bash
node tools/cian/cian.js url --query tools/cian/queries/zao-3room.json
```

Собирать адрес руками не нужно — API возвращает каноническую сериализацию
запроса в `data.queryString`.

## Экспозиция и просмотры

В карточке объявления счётчик просмотров — это кнопка `[data-name="OfferStats"]`
(«849 просмотров, 69 за сегодня»). По клику раскрывается полная статистика с
датой создания:

> 216 просмотров с даты создания объявления 13.07.2026

Отсюда берутся `viewsTotal`, `created` и вычисляется `daysOnMarket` — сколько
лот висит в экспозиции. `viewsPerDay` полезен как грубый индикатор спроса:
свежий лот с высоким темпом просмотров и старый лот с тем же общим счётчиком —
разные истории.

Саму дату начала экспозиции брать из карточки не нужно: поиск отдаёт
`creationDate` для всех результатов сразу. Карточка нужна только ради счётчика
просмотров.

## Цена относительно рынка

Голая цена ничего не говорит. После сбора на руках весь корпус и вся когорта
«район + комнатность», поэтому положение лота считается по своим данным:
`pricePerM2`, `vsBuildingPct` (отклонение от медианы ₽/м² своего корпуса) и
`vsCohortPct`. Если в группе меньше четырёх лотов, оценка не выдаётся — пустое
поле честнее выдуманного процента.

Полезно в паре со сроком экспозиции: лот на 13% дешевле корпуса, который висит
второй год, — это не находка, а вопрос «что с ним не так».

## Доотбор на своей стороне

`apartment: false` и `house_year` пропускают часть несоответствующих лотов.
На проверке по ЗАО из 80 собранных объявлений 12 не прошли собственную же
заявленную планку. Поэтому `search` фильтрует результат повторно по полям
`isApartments` и `building.buildYear` — флаги `--no-apartments` и `--min-year`.

## Ограничения доступа

Три вещи, о которые спотыкается сбор данных:

1. **Капча.** Прямые запросы (curl, обычный fetch) получают Yandex SmartCaptcha
   вместо выдачи. Нужен реальный браузер; интенсивное взаимодействие с UI
   фильтров тоже вызывает капчу, а вот последовательные переходы по готовым
   URL — нет.
2. **TLS.** Через MITM-прокси Chromium с TLS 1.3 получает `ERR_CONNECTION_RESET`
   (ClientHello с постквантовым ключом рвётся на middlebox). Запускать браузер
   с `--ssl-version-max=tls1.2`.
3. **Гео-API.** `https://www.cian.ru/api/geo/get-districts-tree/?locationId=1`
   отдаёт дерево районов только same-origin из сессии браузера; прямой запрос
   возвращает страницу-заглушку.
