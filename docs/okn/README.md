Пятнадцать московских объектов культурного наследия с портала
[наследие.дом.рф](https://наследие.дом.рф) по фильтру «Решение отсутствует,
Подготовка к торгам». Собрано 22.09.2026.

## Как пересобрать

```bash
python3 tools/okn/okn_fetch.py     # карточки объектов -> okn_objects.json
python3 tools/okn/maps.py          # скриншоты Яндекс Карт по координатам
python3 tools/okn/docs_fetch.py    # 82 документа портала -> docs/, текстовый слой -> doctext/
python3 tools/okn/ocr2.py          # распознавание сканов (предмет охраны, акты)
python3 tools/okn/render2.py       # страница
python3 tools/okn/topdf.py         # печать страницы в PDF (A4)
```

## Документы

Портал отдаёт файлы без авторизации, WAF на эту ручку не срабатывает:

```
https://наследие.дом.рф/okn/api/portal/document?documentId=<uuid>
```

82 файла, 434 МБ. Текстовый слой есть только у 19 — остальное сканы, и ещё
у трёх текстовый слой оказался одним штампом регистрации поверх скана
(проверять надо после вычистки строк «Документ зарегистрирован» и
«Страница N из M», иначе документ ложно считается распознанным).

**OCR упирается не в настройки, а в загрузку машины.** На занятых ядрах
страница уходила под полторы минуты и била в таймаут; на свободных тот же
`tesseract -l rus --psm 3` при рендере 1.6 даёт страницу за 1–2 секунды.
Прежде чем крутить масштаб и psm, стоит посмотреть `uptime` и убить
осиротевшие процессы от прошлых прогонов.

PDF печатается из того же файла — отдельной вёрстки под печать нет, всё в
`@media print`. Две вещи, на которых это ломалось:

* **`loading="lazy"` убивает картинки в печати.** Кадры вне вьюпорта
  не подгружаются, и в PDF уезжают пустые рамки. Атрибута на странице нет.
* **Полоса A4 уже мобильного брейкпоинта.** 210 мм минус поля — это ~703 px,
  а брейкпоинт стоял на 720 px: карты вставали в столбик. Мобильная раскладка
  ограничена `@media screen`.

Фотографии качаются напрямую с ресайзера портала, авторизация не нужна:

```
https://наш.дом.рф/resizer/image?imageUrl=<image/uuid>&systemClientId=okn-client&config=resize:fill:1400:0
```

## Что важно знать про забор

1. **JS-челлендж.** `curl` и `WebFetch` получают 403 или страницу со спиннером.
   Нужен браузер с прогревом: сначала заход на корень портала за куками.
2. **TLS.** Chromium через прокси с TLS 1.3 рвётся с `ERR_CONNECTION_RESET` —
   лечится `--ssl-version-max=tls1.2`. Та же грабля, что в
   [`docs/cian/README.md`](../cian/README.md), симптом не зависит от сайта.
3. **Список берётся из API**, а не из разметки: `/okn/api/portal/objects`
   с `region=77&status=NO_SOLUTION,READY` отдаёт `pageInfo.totalSize = 15`
   одним запросом. В разметке лежат только первые семь, «Показать ещё» на
   странице две — вторая относится к списку регионов.
4. **Карточка server-rendered.** Ручки по ID нет; данные вынимаются из
   flight-потока Next.js. Чанки надо декодировать как строковые литералы:
   экранирование многоуровневое, и название «Александровской "полицейской"
   больницы» рвёт наивную замену кавычек.
5. **Карты рисуются самим**: на карточке объекта карты нет, скриншоты сняты
   по координатам из данных через `yandex.ru/map-widget/v1` — у виджета нет
   боковой панели, кадр целиком занят картой.

## Грабли данных

**Площади ансамблей задваиваются.** Три карточки — ансамбли, и площадь каждой
равна сумме её же строений, которые лежат в перечне отдельными карточками:

```
Нарышкина  929,6 = 376,5 + 273,2 + 272,3 + 7,6
Щапово     792,2 = 493,7 + 122,6 + 115,6 + 22,5 + 37,8
Филимонки  797,2 = 589,3 + 207,9
```

Сумма всех пятнадцати строк даёт 6 221,7 м², реальная площадь — **3 702,7 м²**
(три ансамбля плюс отдельно стоящее здание бывшей Александровской больницы).
Связь «ансамбль — строение» портал проставил не везде: у ограды со сторожкой
и у обоих объектов Филимонок поле `parentOkn` пустое, состав восстановлен по
совпадению сумм и адресов и зашит в `COVERS` в `tools/okn/build_okn.py`.

**Коммуникаций нет нигде.** У всех пятнадцати объектов электро-, водоснабжение,
водоотведение, отопление и газ проставлены как «нет».

**Цен нет.** Портал публикует кадастровую стоимость, но не стартовую цену
торгов — это не рыночная оценка. Сроки торгов указаны плановым кварталом
и двигаются.

**Один документ висит на многих объектах.** Из 82 файлов уникальных 49:
предмет охраны усадьбы Щапово прикреплён ко всем шести её объектам,
охранное обязательство Малого Казенного — к пяти. Дедуп по содержимому
экономит и трафик, и распознавание.

**Ни у одного участка нет ВРИ под гостиницу.** Льготная ставка 6% даётся
под приспособление ОКН под гостиницу от двух звёзд, а ВРИ у пятнадцати
участков — от «культурного развития» до «складов (6.9)». Плюс приказ
Мосгорнаследия от 14.03.2024 № 69 фактически закрывает апартаменты:
он запрещает «жилые ячейки» при совпадении трёх признаков, один из
которых — как раз отсутствие гостиничного, туристического или
медицинского ВРИ. Смену ВРИ надо закладывать в план заранее.
