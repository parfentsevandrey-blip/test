# Технологическое сердце Европы — промзоны Нидерландов

Аналитический отчёт (19 страниц, на русском языке) о ведущих промышленных
технологических зонах Нидерландов, где сосредоточены мировые лидеры в трёх
областях: **производство оборудования для чипов, дата-центры и искусственный
интеллект**.

## Готовый документ

- **`Технологическое_сердце_Европы_Нидерланды.docx`** — итоговый файл Word (основной результат)
- **`Технологическое_сердце_Европы_Нидерланды.pdf`** — та же версия в PDF для быстрого просмотра

## Что внутри

- Обложка, оглавление с номерами страниц, краткое резюме
- Обзорная карта страны и **реальные спутниковые снимки** каждой из 7 ключевых зон
  (ASML/Велдховен, High Tech Campus Eindhoven, Неймеген, Amsterdam Science Park,
  Google Эмсхавен, Agriport A7/Мидденмер, QuTech Делфт)
- Аналитическая инфографика (выручка ASML, мощности дата-центров, инвестиции)
- Врезки с пояснениями, сравнительная таблица зон, список источников

Все ключевые цифры перепроверены по нескольким независимым источникам
(годовые отчёты компаний, CBS, AMS-IX, правительственные материалы и др.).

## Как собран отчёт (воспроизведение)

Изображения и документ генерируются из кода в папке `src/`:

| Файл | Назначение |
|------|-----------|
| `mapgen.py`     | Спутниковые/картографические снимки локаций (тайлы Esri + OpenStreetMap/CARTO) |
| `render_zones.py` | Рендер снимков всех зон в `assets/` |
| `charts.py` / `make_charts.py` | Аналитические диаграммы |
| `build_data.py` | Текст отчёта (простой русский) и структура блоков → `report_data.json` |
| `build_docx.js` | Сборка `.docx` из `report_data.json` и `assets/` (docx-js) |
| `extract_toc.py` | Вычисление номеров страниц для оглавления |

```bash
cd src
pip install python-docx Pillow requests staticmap matplotlib
npm install docx
python3 render_zones.py && python3 make_charts.py   # изображения → ../assets
python3 build_data.py && node build_docx.js          # → report.docx
```
