# Block — Mac без сервисов Apple

Приложение каталога, см. [манифест](../MANIFESTO.md). Mac — это железо, за которое заплачено, и система, в которой
человек ставит что хочет. Сервисы Apple (App Store, iCloud, Siri, Apple Intelligence, «Музыка», TV, News, Game Center,
подписки, напоминания войти в Apple Account) удалить нельзя: они лежат на подписанном системном томе. Block делает так,
чтобы они **не запускались, не напоминали о себе, не открывались сами и не ходили в сеть**, а их место заняли
программы каталога. Написан с нуля на Swift 6 / SwiftUI с интерфейсом **Liquid Glass**, без сторонних библиотек.
Устройство и решения подробно описаны в [DESIGN.md](DESIGN.md).

> **Установка без предупреждений macOS.** Проще всего через [Harbor](../Harbor/):
> `curl -fsSL https://github.com/parfentsevandrey-blip/test/releases/download/catalog/install.sh | bash`
> и установите Block из каталога.
> Без Harbor: `curl -fsSL https://github.com/parfentsevandrey-blip/test/releases/download/catalog/install.sh | bash -s -- block`.

## Чего Block не делает — честно

| Нельзя | Почему |
|---|---|
| Удалить программы Apple | Системный том подписан (SSV). Удалить можно, только отключив SIP, — это дыра в безопасности и отказ от обновлений. |
| Отключить SIP | По той же причине Block никогда этого не предлагает. |
| Остановить защищённые службы | `launchctl` отвечает «Operation not permitted». Block проверяет результат и показывает «защищена системой». |
| Закрыть обновления, сертификаты, нотаризацию, время | Это защита самого Mac. Эти адреса неприкосновенны, и самопроверка это проверяет. |

## Пять уровней

| Уровень | Что делает | Права |
|---|---|---|
| **Настройки** | Siri и «Привет, Siri» выключены, записи голоса не отправляются; персональная реклама Apple выключена; аналитика Mac не отправляется; Spotlight без подсказок из интернета; «Фото» не открывается при подключении iPhone; Handoff (если iPhone не нужен). Где надёжного ключа нет (Apple Intelligence, выход из Apple Account), Block открывает ровно ту панель настроек и подсказывает, что нажать. | без пароля, кроме аналитики |
| **Программы по умолчанию** | Ссылки → Ward, видео и музыка → Lumen, торренты и magnet → Swarm. | без пароля |
| **Сторож запуска** | App Store → Harbor, «Музыка» и TV → Lumen; «Подкасты», News, «Акции», «Книги», «Советы», «Дом», «Игры», Siri закрываются в момент запуска (Сообщения и FaceTime — если iPhone не нужен). В углу — плашка «Block не дал открыться» с кнопкой «Один раз». Значки этих программ убираются из Dock и при возврате встают на те же места. | без пароля |
| **Фоновые службы** | `launchctl disable` агентов «Советов», Game Center, News, продвигаемого контента, подсказок поиска, медиатеки iCloud и других. | без пароля |
| **Сеть** | Группы адресов: телеметрия, реклама, App Store, iCloud, Siri, News. Через свою секцию в `/etc/hosts` (один раз пароль) или через [Veil](../Veil/) — с поддоменами и без пароля, пока Veil включён. | пароль для hosts |

Профили: **Мягко** — первые три уровня, без пароля администратора; **Полностью** — все пять. Правила, помеченные
«экспериментально» (ключи и службы, которые Apple меняет от версии к версии), и ручные шаги в профиль не входят —
только по кнопке. При первом запуске три вопроса: пользуетесь ли iCloud, нужен ли «Найти Mac», пользуетесь ли
iPhone. Пока не ответили «нет», iCloud, Handoff, Сообщения и FaceTime не трогаются.

## Каждое правило обратимо

У правила четыре шага: **проба** (текущее состояние), **применение** (прежнее значение записывается в журнал до
изменения), **проверка** (Block перечитывает и показывает, если система вернула своё) и **возврат** — ровно к тому, что
было, а не к «значению по умолчанию». «Вернуть Mac как было» снимает всё одной кнопкой. Секция `/etc/hosts` снимается
так, что файл совпадает с прежним байт в байт.

После обновления macOS (и раз в несколько часов) Block перепроверяет правила: Apple часто возвращает свои значения.
Вернувшееся видно на главном экране и в журнале; по умолчанию Block применяет его заново.

## Без помощников и без сети

Постоянного привилегированного помощника нет — нечего взламывать. Шагам с правами администратора Block показывает
системный запрос пароля один раз на всё применение. Сам Block в сеть не ходит: списки правил и адресов вшиты в
приложение и обновляются вместе с ним через Harbor. Сторож работает, пока Block запущен; включите «после входа в
систему», и он будет жить в строке меню без окна.

## Самопроверки в CI

`.github/workflows/block-macos.yml` на настоящем macOS:
- **logic** — у каждого правила есть проба, снимок и возврат; ни одна группа адресов не закрывает обновления,
  сертификаты, нотаризацию и время; секция hosts дописывается и снимается байт в байт; ссылка для Veil; профили
  и условия ответов;
- **system** — на Mac раннера применить и вернуть все правила настроек, службы и Dock, снимки до и после совпадают;
  `/etc/hosts` и аналитика через `sudo -n`: резолвер отвечает `0.0.0.0` для телеметрии и настоящим адресом для
  обновлений, после возврата файл тот же; программа по умолчанию назначается и возвращается; сторож закрывает
  безопасную программу Apple меньше чем за секунду;
- скриншоты всех экранов с выдуманным состоянием.
