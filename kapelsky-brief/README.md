# Справка по клубному дому «Капельский, 5»

Готовый документ: **`ЖК_Капельский_5_справка.docx`** (16 страниц, A4).

Клубный дом на 46 резиденций в Мещанском районе Москвы, Капельский переулок, 5.
Закрытые продажи открылись в апреле 2026 года по цене около **1,3 млн ₽ за метр**,
разрешение на строительство получено к сентябрю 2026-го. Сдача — 2029 год.

## Откуда данные

**Официальный сайт проекта — `kapelsky5.ru`.** Сайт на Next.js: пути к
визуализациям лежат прямо в разметке (`/img/home/*.webp`), поэтому галерея
скачивается без запуска браузера. Оттуда же — количество резиденций, диапазон
площадей, паркинг и формулировка о сроках открытия продаж.

Принадлежность сайта устанавливается по документам в подвале: PDF согласия на
обработку персональных данных называет оператором **АО «МАКО»** с полными
реквизитами.

**Отдельно про `kapelsky5.com`.** В подвале написано: «Данный сайт не является
официальным сайтом застройщика». Числовые данные оттуда не брались; они, впрочем,
совпадают с карточкой «Новострой-М» — обе версии, судя по всему, восходят к одному
пресс-релизу.

**Параметров, которых нет на официальном сайте** — этажность, потолки, средняя
площадь лота, срок сдачи, — взяты из карточек `whitewill.ru`, `novostroy-m.ru`,
`anwin.ru`, `buro-estate.ru` и обзора стартов продаж `novostroev.ru`. Там, где
источники расходятся, расхождение вынесено в раздел «Открытые вопросы».

**Что на участке.** Его занимал трёхэтажный кирпичный корпус советской постройки
(в OpenStreetMap здание с адресом «Капельский переулок, 5» помечено как детский сад,
3 этажа, кирпич). Сейчас корпус сносят. Брокерские карточки бизнес-центра «Капельский 5»
на этот адрес устарели — их данные в справку не пошли.

**Рынок** — данные NF Group за I квартал 2026 года.

**Конкуренты — поисковый API Циан**, клиентом из ветки
`claude/cian-apartments-cao-7iqapp` (`tools/cian/cian.js`). Четыре запроса, срез
02.09.2026: новостройки и вторичка 2010 года и новее по Мещанскому району (id 17)
и то же в пешей доступности от «Проспекта Мира» и «Рижской» (id 103, 107, 384, 517,
`foot_min ≤ 15`). Циан заявил 478 лотов — перечислены все 478.

Поле `repairType` в поисковой выдаче пустое: оно живёт только в карточке
объявления. Поэтому карточки 76 лотов вторички дочитаны отдельно командой
`card` — из них и взята отделка.

**Фотографии ремонтов.** Кадры объявлений скачивает `kp_photos.py`, контактные
листы (`kp_photos.py sheet`) нужны, чтобы выбрать интерьер: первый кадр объявления
часто отдан фасаду, плану или подъезду. Выбор зафиксирован в словаре `PICK`
в `kp_cards.py`.

**Планировки.** `kp_plans.py` выбирает по пять лотов на дом, качает их галереи
и ищет чертёж по «белизне» кадра: план — это почти белый лист с тонкими линиями.
Из 55 лотов выборки план нашёлся у 27 — у новостроек почти всегда, у вторички
редко. Ложные срабатывания (светлый интерьер вместо чертежа) перечислены
в `NOT_A_PLAN`; проверять их удобно по `kp_plans.py sheet`.

**Координаты.** Здание с адресом «Капельский переулок, 5» найдено в OpenStreetMap
(way 50834023, центр контура 55.784482 / 37.631307). Расстояния до метро и городских
объектов посчитаны по прямой от этой точки.

## Что показывает цена

Продаваемая площадь дома — около **5 060 м²** (46 лотов × 110 м²). По цене
закрытого этапа все лоты вместе стоят примерно **6,6 млрд ₽**; по средневзвешенному
метру премиум-класса Москвы — 8,1 млрд ₽. Разница около **1,5 млрд ₽** — это и есть
цена входа до получения разрешения на строительство.

| Ориентир | ₽ за м² | Разрыв с 1,3 млн |
|---|---|---|
| Капельский, 5 — закрытые продажи | 1 300 000 | — |
| Премиум-класс Москвы, NF Group | 1 600 000 | +23 % |
| Элитный сегмент Москвы, NF Group | 2 270 000 | +75 % |
| Делюкс-класс Москвы, NF Group | 3 200 000 | +146 % |
| «ФАНТОМ», крупнейший премиальный сосед | 1 650 000 – 3 580 000 | +27…+175 % |

Лоты идут без отделки. При ремонте по 400 тыс. ₽ за метр полная стоимость метра
получается 1,7 млн ₽ — то есть уровень среднего премиум-метра Москвы. Полный бюджет
средней резиденции в 110 м² — **176–198 млн ₽**.

## Сколько рынок платит за ремонт

Сравнение внутри одних и тех же домов: у квартиры с дизайнерским ремонтом и
у оболочки в соседнем подъезде совпадают локация, год постройки и класс дома.

| Дом | С ремонтом | Метр, ₽ | Оболочек | Метр, ₽ | Надбавка |
|---|---|---|---|---|---|
| Dialog | 4 | 1 103 512 | 5 | 892 857 | +24 % |
| Barkli Park | 4 | 1 076 554 | 3 | 994 819 | +8 % |
| Sole Hill | 9 | 900 000 | 7 | 780 000 | +15 % |
| Мод | 5 | 794 118 | 17 | 585 626 | +36 % |
| Медиана по 4 домам | 36 | — | 32 | — | +19 % |

Складывать дома в одну кучу нельзя: у «Мода» оболочек втрое больше, чем
отремонтированных лотов, и общая медиана поехала бы за счёт состава выборки.
Поэтому итог — медиана надбавок, посчитанных внутри домов.

**Ремонт премиум-класса стоит 300–500 тыс. ₽ за метр, рынок возвращает 164 246 ₽ —
33–55 % вложенного.** Для «Капельского», который продаёт оболочки, это означает:
ремонт при перепродаже окупается частично.

В документе этот расчёт стоит под двумя страницами карточек: 24 квартиры
с дизайнерским ремонтом в готовых домах когорты, у каждой — фото из объявления,
ЖК, площадь, этаж, цена и цена метра. Медиана этих 24 квартир — **1 076 554 ₽ за метр**,
диапазон от 677 419 до 2 321 429 ₽.

включая Аптекарский огород 1706 года в 870 метрах; реконструкция «Олимпийского»

премиального предложения в шаговой доступности.

**Против:** проспект Мира в 217 метрах и ТТК в 815; плотность 12 102 чел./км²;
офисно-институциональное окружение участка — МОНИКИ с юга, бизнес-центры вдоль
проспекта Мира; стройка «Олимпийского» до 2027 года; площадь трёх вокзалов в 1,8 км.

## Открытые вопросы

- этажность: 8 или 9 — источники расходятся, официальный сайт цифру не называет;
- срок: III или IV квартал 2029 — разные агрегаторы указывают разные кварталы;
- класс: делюкс или премиум — разница в оценке метра между этими классами двукратная;
- АО «МАКО» ведёт основной вид деятельности по ОКВЭД 64.99 (прочие финансовые услуги),
  уставный капитал 2 млн ₽, убыток за 2025 год 84,6 млн ₽, публичного портфеля жилых
  проектов нет;
- проектной декларации на 01.09.2026 в ЕИСЖС нет, поквартирного прайса и планировок
  в открытом доступе тоже нет.

## Пересборка

```bash
pip install Pillow pymupdf
npm install docx

python3 kp_media.py     # визуализации с сайта проекта -> src/img/
python3 kp_renders.py   # кропы визуализаций из src/img -> assets/*.jpg
python3 kp_cian.py      # выдача Циан -> cian/cohort.json, cian/peers.json
python3 kp_photos.py    # кадры объявлений -> photos/
python3 kp_cards.py     # карточки квартир -> assets/card_*.jpg, cian/cards.json
python3 kp_plans.py     # выборка лотов и поиск планировок -> cian/sample.json
python3 kp_plans.py assets   # планировки -> assets/plan_*.jpg
python3 kp_data.py      # таблицы и расчёты -> kp_tables.json
python3 kp_maps.py      # три карты -> assets/kp_map_*.png
python3 kp_chart.py     # график цены метра -> assets/kp_chart.png
python3 kp_assets.py    # PNG -> JPEG в assets/
cat kp_head.js kp_body.js > kp_build.js && node kp_build.js
```

Выгрузки Циан лежат в `cian/` вместе с запросами; чтобы пересобрать их с нуля,
нужен клиент из ветки `claude/cian-apartments-cao-7iqapp`:

```bash
node tools/cian/cian.js search --query cian/queries/mesh-new.json --all --out cian/mesh-new.json
node tools/cian/cian.js card   --from  cian/resale_ids.json --limit 49 --out cian/resale_cards.json
```

`ymap.py` и `markers.py` — сшивка тайлов Яндекс Карт (EPSG:3395) и отрисовка пинов
с подписями; на карте конкурентов пины нумерованные, номер совпадает с таблицей. `kp_head.js` — хелперы вёрстки: `statTiles`, `factSheet`, `dataTable`,
`imageTrio`, `imagePair`, `bullets`.

Визуализации в `src/img/` скачаны с официального сайта проекта; в репозиторий
попадают только кропы в `assets/`.
