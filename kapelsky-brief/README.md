# Справка по клубному дому «Капельский, 5»

Готовый документ: **`ЖК_Капельский_5_справка.docx`** (9 страниц, A4).

Клубный дом на 46 резиденций в Мещанском районе Москвы, Капельский переулок, 5.
Закрытые продажи открылись в апреле 2026 года по цене около **1,3 млн ₽ за метр**,
разрешение на строительство получено к сентябрю 2026-го. Сдача — 2029 год.

## Откуда данные

**Официальный сайт проекта — `kapelsky5.ru`.** Сайт на Next.js: пути к
визуализациям лежат прямо в разметке (`/img/home/*.webp`), поэтому галерея
скачивается без запуска браузера. Оттуда же — количество резиденций, диапазон
площадей, паркинг и формулировка о сроках открытия продаж.

Принадлежность сайта устанавливается по документам в подвале: PDF согласия на
обработку персональных данных называет оператором **АО «МАКО»** с полными
реквизитами.

**Отдельно про `kapelsky5.com`.** В подвале написано: «Данный сайт не является
официальным сайтом застройщика». Числовые данные оттуда не брались; они, впрочем,
совпадают с карточкой «Новострой-М» — обе версии, судя по всему, восходят к одному
пресс-релизу.

**Параметров, которых нет на официальном сайте** — этажность, потолки, средняя
площадь лота, срок сдачи, — взяты из карточек `whitewill.ru`, `novostroy-m.ru`,
`anwin.ru`, `buro-estate.ru` и обзора стартов продаж `novostroev.ru`. Там, где
источники расходятся, расхождение вынесено в раздел «Открытые вопросы».

**Что стоит на участке сегодня** — из карточки бизнес-центра на `fortexgroup.ru`:
четыре этажа, 2 430 м², класс B+, реконструкция 2014 года.

**Рынок** — данные NF Group за I квартал 2026 года. **Цены сопоставимых проектов** —
срез каталога `mskguru.ru` от 01.09.2026: там диапазоны цены метра приводятся
числом, а не «по запросу».

**Координаты.** Здание с адресом «Капельский переулок, 5» найдено в OpenStreetMap
(way 50834023, центр контура 55.784482 / 37.631307). Расстояния до метро и городских
объектов посчитаны по прямой от этой точки.

## Что показывает цена

Продаваемая площадь дома — около **5 060 м²** (46 лотов × 110 м²). По цене
закрытого этапа все лоты вместе стоят примерно **6,6 млрд ₽**; по средневзвешенному
метру премиум-класса Москвы — 8,1 млрд ₽. Разница около **1,5 млрд ₽** — это и есть
цена входа до получения разрешения на строительство.

| Ориентир | ₽ за м² | Разрыв с 1,3 млн |
|---|---|---|
| Капельский, 5 — закрытые продажи | 1 300 000 | — |
| Премиум-класс Москвы, NF Group | 1 600 000 | +23 % |
| Элитный сегмент Москвы, NF Group | 2 270 000 | +75 % |
| Делюкс-класс Москвы, NF Group | 3 200 000 | +146 % |
| «Форум», ближайший сосед с открытым прайсом | 1 786 000 – 2 376 000 | +37…+83 % |

Лоты идут без отделки. При ремонте по 400 тыс. ₽ за метр полная стоимость метра
получается 1,7 млн ₽ — то есть уровень среднего премиум-метра Москвы. Полный бюджет
средней резиденции в 110 м² — **176–198 млн ₽**.

## Открытые вопросы

- этажность: 8 или 9 — источники расходятся, официальный сайт цифру не называет;
- срок: III или IV квартал 2029 — разные агрегаторы указывают разные кварталы;
- класс: делюкс или премиум — разница в оценке метра между этими классами двукратная;
- АО «МАКО» ведёт основной вид деятельности по ОКВЭД 64.99 (прочие финансовые услуги),
  уставный капитал 2 млн ₽, убыток за 2025 год 84,6 млн ₽, публичного портфеля жилых
  проектов нет;
- проектной декларации на 01.09.2026 в ЕИСЖС нет, поквартирного прайса и планировок
  в открытом доступе тоже нет.

## Пересборка

```bash
pip install Pillow pymupdf
npm install docx

python3 kp_renders.py   # кропы визуализаций из src/img -> assets/*.jpg
python3 kp_data.py      # таблицы и расчёты -> kp_tables.json
python3 kp_maps.py      # две карты -> assets/kp_map_*.png
python3 kp_chart.py     # график цены метра -> assets/kp_chart.png
python3 kp_assets.py    # PNG -> JPEG в assets/
cat kp_head.js kp_body.js > kp_build.js && node kp_build.js
```

`ymap.py` и `markers.py` — сшивка тайлов Яндекс Карт (EPSG:3395) и отрисовка пинов
с подписями. `kp_head.js` — хелперы вёрстки: `statTiles`, `factSheet`, `dataTable`,
`imageTrio`, `imagePair`, `bullets`.

Визуализации в `src/img/` скачаны с официального сайта проекта; в репозиторий
попадают только кропы в `assets/`.
