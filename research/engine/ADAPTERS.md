# Шаг 2: API вместо страниц — 7 застройщиков

**Критерий:** весь каталог (квартиры, цена, площадь, этаж, статус) — **не больше 50 запросов** на застройщика за цикл.

**Разведка каждого сайта:**
- одно бережное посещение разрешённой страницы, через `lib/clientpolicy.py` и с облегчённой загрузкой (L30, L37);
- HAR → `lib/audit_site.py`: REA + mitmproxy2swagger (W25);
- данные берём из того, что загружает **сама страница** (как у Гранели и Soul); сами к закрытым в `robots.txt` адресам не обращаемся.
