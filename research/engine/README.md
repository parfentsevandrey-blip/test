# Движок рынка новостроек (`research/engine/`)

Задача владельца от 17.10.2026:
- ЦИАН, сайты застройщиков и прочие источники — один пакет «ЖК целиком»;
- двойная проверка каждого лота;
- непрерывное подключение новых проектов;
- только современные ЖК;
- полный цикл ≤ 3 ч.

Правила сбора MANIFEST.md не меняются. Работаем только в облаке Claude Code.

Шаги в коммитах обозначаются `[ENGINE-1]` … `[ENGINE-7]` (по разделу «Порядок и критерии» задачи).
