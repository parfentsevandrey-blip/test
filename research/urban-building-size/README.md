# Анатомия мегаполиса

Сравнительное исследование размерной структуры зданий 34 крупнейших городов мира
по спутниковым контурам застройки.

**Отчёт:** [`Анатомия_мегаполиса_исследование_застройки.docx`](Анатомия_мегаполиса_исследование_застройки.docx) — 45 страниц, 9 графиков, 16 таблиц.

## Что измерено

Каждое здание в круге радиусом 10 км вокруг центра города отнесено к одной из четырёх
категорий по площади пятна застройки: до 300 м², 300–1 000 м², 1 000–10 000 м², свыше 10 000 м².

| | |
|---|---|
| Городов в основном срезе | 28 на 6 континентах |
| Городов в контрольном срезе | 34, включая станцию Мак-Мёрдо в Антарктиде |
| Зданий обработано | 4 898 562 (основной) + 12 382 113 (контрольный) |
| Суммарное пятно застройки | 1 787 км² |

## Ключевые результаты

- 76,5% зданий мира меньше 300 м², но они дают лишь 24,1% застроенной площади;
  41,5% площади приходится на категорию 1 000–10 000 м² (6,2% объектов).
- Плотность зданий и их средний размер связаны в логарифмах с наклоном −0,82 (R² = 0,78).
  Отклонение от −1 означает: крупнозернистые города застроены плотнее.
- Коэффициент застроенности меняется втрое: 13,7% (Москва) — 42,6% (Буэнос-Айрес).
- Города делятся на два типа по контрасту ядра и периферии; разрыв достигает 57 п.п.
- Два независимых источника расходятся в 2,1 раза по числу зданий и лишь на 10% по площади.

## Воспроизведение

```bash
cd pipeline
pip install duckdb matplotlib pypdfium2
npm install docx

python3 extract.py            # основной срез  -> results.jsonl
python3 ovt_all.py            # контрольный срез -> results_ovt_all.jsonl
python3 viz.py                # графики -> fig*.png
node build.js                 # сборка .docx
```

`extract_toc.py` вычисляет номера страниц для оглавления по отрендеренному PDF;
сборка двухпроходная (собрать → отрендерить → извлечь номера → пересобрать).

## Ограничения

- Измеряется пятно застройки, а не площадь помещений.
- Нейросетевая сегментация склеивает смежные здания со сплошным периметром —
  смещение максимально в городах квартальной застройки (Буэнос-Айрес, Мадрид).
- Киншаса и Сидней исключены из основного среза: у Microsoft там пробелы покрытия.
- Данные о высоте неполны; вертикальный анализ ограничен 12 городами.
