# Информационная справка — ЖК «МАСТЕРС» (Capital Group)

Готовый документ: **`ЖК_МАСТЕРС_информационная_справка.docx`** (6 страниц, A4).

## Структура документа

| Стр. | Раздел |
|---|---|
| 1 | Титул: рендер, основная информация (срок сдачи, этажность, секции, квартиры и т. д.), карта локации |
| 2 | Архитектура проекта — 2 рендера |
| 3 | Двор и инфраструктура — 3 рендера |
| 4 | Цены: по типам квартир, по секциям, по этажам + ключевые наблюдения |
| 5 | Конкурентное окружение: таблица реализованных проектов + карта |
| 6 | Прямые конкуренты на первичном рынке, позиционирование, источники |

## Данные

Ценовой блок построен на выгрузке Циан по ЖК «Премиальный дом МАСТЕРС»
(ID 5747793) от 28.07.2026 — 169 лотов, все от застройщика, без отделки.

Характеристики проекта — с официального сайта Capital Group и профильных
порталов. Картографическая основа — тайлы Яндекс Карт (проекция EPSG:3395).

## Пересборка

```bash
pip install Pillow
npm install docx

python3 parse.py        # .xls (Excel 2003 XML) -> data.json
python3 stats.py        # проверка расчётов по лотам
python3 map_loc.py      # карта локации  -> map_location.png
python3 map_comp.py     # карта конкурентов -> map_competitors.png
node build.js           # -> ЖК_МАСТЕРС_информационная_справка.docx
```

`assets/` содержит подготовленные изображения (рендеры застройщика и карты),
которые `build.js` встраивает в документ.
