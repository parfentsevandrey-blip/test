## Данные

Ценовой блок построен на выгрузках Циан от 28.07.2026: МАСТЕРС (ID 5747793,
169 лотов, все от застройщика, без отделки) и пять конкурентов — «Прайм Парк»
(ID 45774, 341), «Царская площадь» (ID 8122, 65), «Лайнер» (ID 5641, 62),
«Династия» (ID 19800, 39), «ЛИЦА» (ID 5430, 13).

Первичный рынок сравнивается отдельно и без поправок: МАСТЕРС, «Муза»
(ID 5750446, 52 лота) и «Дом на Часовой» (ID 5732034, 51 лот) — все три
проекта продаются только застройщиком и на 100 % без отделки.

Сравнение считается на единой базе — квартиры 40–140 м² без свободных
планировок — и приводится к одному состоянию «квартира, в которую можно
заехать»: у конкурентов берутся лоты с готовым ремонтом, к цене МАСТЕРС
добавляется отделка (оценка 150 тыс. ₽/м²).

Планировки — с официального сайта проекта (`cg-projects.ru/flats`).
Ссылки на объявления МАСТЕРС и конкурентов берутся из атрибута `ss:HRef`
выгрузок Циан.

Фотографии ремонта на вторичном рынке — Яндекс Недвижимость
(`yr.py` разбирает `window.INITIAL_STATE` страницы ЖК). Циан отдаёт 403
на автоматические запросы, поэтому фото объявлений оттуда получить нельзя.

Характеристики проекта — с официального сайта Capital Group и профильных
порталов. Картографическая основа — тайлы Яндекс Карт (проекция EPSG:3395).

## Пересборка

```bash
pip install Pillow
npm install docx

python3 parse.py        # .xls МАСТЕРС (Excel 2003 XML) -> data.json
python3 stats.py        # проверка расчётов по лотам МАСТЕРС
python3 parse_all.py    # все шесть выгрузок -> all_lots.json
python3 cmp3.py         # сравнение с поправкой на отделку -> cmp.json
python3 map_comp.py     # карта конкурентов -> map_competitors.png
python3 prim.py         # сравнение с первичкой -> prim_tables.json
python3 map_loc.py      # карта локации  -> map_location.png
python3 map_prim.py     # карта первички -> map_primary.png
python3 links.py        # ссылки на лоты из ss:HRef -> ex_links.json
python3 yr.py <url>     # лоты с фото из Яндекс Недвижимости
python3 chart.py        # график «готовой квартиры» -> chart_prices.png
python3 chart_prim.py   # график цен (первичка) -> chart_primary.png
node build.js           # -> ЖК_МАСТЕРС_информационная_справка.docx
```

`assets/` содержит подготовленные изображения (рендеры застройщика и карты),
которые `build.js` встраивает в документ.
