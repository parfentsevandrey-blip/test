# Шрифты

Схема `layout: "dossier"` набирается гарнитурами еженедельного обзора
заказчика — они сняты с самого издания, а не подобраны на глаз:

| Роль | Гарнитура |
|---|---|
| Текст, заголовки, лиды, крупные числа | **Source Serif 4** (Light / Regular / SemiBold / Italic) |
| Рубрики, подписи, перечни характеристик | **Source Sans 3** (Light / Regular / SemiBold) |

Статические начертания нарезаны из переменных версий Adobe (`opsz` = 11) и
переименованы так, чтобы вес выбирался именем семейства.

Ранняя схема `layout: "editorial"` набиралась Inter и Spectral; файлы
оставлены рядом, чтобы старые отчёты собирались как прежде.

Все гарнитуры — открытые лицензии (SIL OFL 1.1), все с полной кириллицей.
Файлы лежат рядом с этим README, чтобы сборка была воспроизводимой.

## Установка

```sh
mkdir -p ~/.fonts && cp assets/fonts/*.ttf ~/.fonts/ && fc-cache -f   # Linux
```

На macOS и Windows — открыть файлы и нажать «Установить».

Начертания различаются именем семейства («Inter Light», «Spectral Medium»,
не «Inter полужирный»): в DOCX нет управления весом, кроме флага bold,
поэтому вес задаётся именем гарнитуры.

## Если шрифты не установлены

PDF собирается корректно в любом случае — LibreOffice встраивает
гарнитуры в файл. Подмена коснётся только DOCX, открытого на машине без
установленных шрифтов: вёрстка сохранится, начертание изменится.
