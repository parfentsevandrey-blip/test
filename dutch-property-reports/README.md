# Отчёты по объектам недвижимости (Нидерланды)

Генератор отчёта-подборки коммерческих объектов: из JSON-карточек объектов
собирается `.docx` в оформлении еженедельного обзора заказчика и (при наличии
LibreOffice) конвертируется в `.pdf`.

## Оформление по умолчанию — схема `dossier`

Формат снят с еженедельника заказчика: A4 210 × 297 при полях 20 мм, две
колонки по 80 мм со средником 10 мм, Source Serif 4 для текста и заголовков,
Source Sans 3 для рубрик и подписей, чернила `#16233A`, охра `#9C7C38`, бумага
`#F5F4F0`. Отчёт без поля `layout` собирается именно так.

Состав полос:

1. **Обложка** — заголовок, лид и список объектов с ценами и миниатюрами.
2. **По каждому объекту** — шмуцтитул навылет (номер, название, полоса
   ключевых цифр), полоса характеристик, описание объекта, описание локации с
   картой и разбором доступности, галерея кадров мозаикой.

Текстовые полосы добираются кадром до нижнего поля: высота блоков считается
по тем же величинам, которыми они набраны, и остаток отдаётся иллюстрации.

Ранние отчёты помечены `"layout": "classic"` и собираются в прежнем
оформлении; `"layout": "editorial"` — промежуточная журнальная схема.

## Установка

```bash
pip install -r requirements.txt
# для PDF дополнительно нужен LibreOffice (пакет libreoffice-writer)
```

## Сборка отчёта

```bash
python generate_report.py build data/report-2026-07-27.json          # DOCX + PDF
python generate_report.py build data/report-2026-07-27.json --no-pdf # только DOCX
python generate_report.py -v build data/report-2026-07-27.json       # с логом
```

Результат складывается в `output/`. Карты и фотографии кэшируются в `.cache/`,
поэтому повторная сборка проходит без сетевых запросов.

## Реестр показанных объектов

`data/registry.json` — единственный источник правды по тому, что заказчик уже
видел. Реестр пополняется автоматически при каждой успешной сборке; объекты,
ушедшие заказчику мимо генератора, добавляются вручную с заполненным полем
`source`. Перед сборкой новая подборка сверяется с реестром, и повтор
печатается предупреждением (сборка при этом не падает).

```bash
python generate_report.py registry             # что уже показывали
python generate_report.py registry --rebuild   # пересобрать по отчётам каталога
```

Разные варианты вёрстки одной подборки повтором не считаются: они связаны
полем `variant_of` и пишутся в одну запись реестра.

## Как добавить объект

1. Проверить по реестру, что объект ещё не показывали.
2. Создать `data/objects/<slug>.json` (проще всего — скопировать соседний файл).
3. Добавить ссылку на файл в массив `objects` файла отчёта `data/report-*.json`.
4. Запустить сборку.

### Формат карточки объекта

| Поле | Назначение |
|---|---|
| `slug` | идентификатор для имён файлов кэша |
| `title` / `subtitle` | заголовок объекта и строка «индекс • район • провинция» |
| `street`, `city`, `price_short` | строка объекта на обложке |
| `map` | `{ "query": "адрес", "lat": …, "lon": …, "city": { "query": "Utrecht, Netherlands", "lat": …, "lon": … } }` — координаты можно не указывать, тогда сработает геокодирование |
| `specs` | таблица характеристик: массив пар `["подпись", "значение"]` |
| `sections` | разделы отчёта, по порядку |
| `photos` | ссылки на фотографии (`cloud.funda.nl/...` в размере `1440x960`) |

Типы разделов в `sections`:

```jsonc
{ "type": "callout",    "heading": "О городе и районе", "title": "…", "paragraphs": ["…"] }
{ "type": "paragraphs", "heading": "Описание объекта",  "paragraphs": ["…", "…"] }
{ "type": "bullets",    "heading": "Планировка",        "bullets": ["…", "…"] }
```

## Карты

Обзорная карта — Google Maps. Кадр строится по двум точкам: сам объект (на нём
красная метка) и ближайший крупный город из поля `map.city`; масштаб
подбирается автоматически так, чтобы город с подписью гарантированно попал в
кадр. Явный `map.zoom` в карточке перекрывает автоподбор.

Источник изображения выбирается автоматически:

- если задан ключ `GOOGLE_MAPS_API_KEY`, используется официальный
  **Google Maps Static API** — это штатный режим для регулярной работы:

  ```bash
  export GOOGLE_MAPS_API_KEY=...
  python generate_report.py build data/report-2026-07-27.json
  ```

- без ключа карта собирается из растровых тайлов Google. Режим рабочий, но
  для постоянного использования лучше завести ключ Google Maps Platform.

## Данные с funda in business

Страницы funda закрыты Akamai Bot Manager (посетителя встречает страница
проверки с reCAPTCHA), поэтому скачать HTML скриптом нельзя — страницу нужно
сохранить из браузера («Сохранить как» → *.html или скопировать outerHTML).
Из сохранённого файла черновик карточки собирается автоматически:

```bash
python generate_report.py parse raw/steenovenweg.html \
    -o data/objects/draft.json \
    --url https://www.fundainbusiness.nl/en/belegging/montfoort/object-44425433-steenovenweg-11-13/
```

Парсер достаёт таблицу «Kenmerken», текст описания и **все** ссылки на
фотографии объекта. Дальше черновик дополняется русскими формулировками
разделов и переносится в формат карточки.

Сами изображения (`cloud.funda.nl`) отдаются без защиты, их загружает
`reportgen/media.py` — правится только список ссылок.

## Устройство пакета

| Модуль | Отвечает за |
|---|---|
| `reportgen/style_editorial.py` | оформление схемы `dossier`: цвета, гарнитуры, кегли, геометрия |
| `reportgen/dossier.py` | вёрстка схемы по умолчанию: шмуцтитулы, характеристики, две колонки, галерея |
| `reportgen/visuals.py` | полосы-изображения: обложка, шмуцтитулы, кадры со скруглением и тенью |
| `reportgen/editorial.py` | общие помощники вёрстки и промежуточная схема `editorial` |
| `reportgen/registry.py` | реестр показанных объектов и проверка на повторы |
| `reportgen/style.py` | оформление схемы `classic` |
| `reportgen/docx_render.py` | выбор схемы и вёрстка `classic` |
| `reportgen/maps.py` | геокодирование (Nominatim) и сборка карты Google Maps |
| `reportgen/media.py` | загрузка и кэширование фотографий |
| `reportgen/pdf.py` | конвертация DOCX → PDF через LibreOffice |
| `reportgen/funda_parse.py` | разбор сохранённой страницы funda в черновик карточки |

Гарнитуры лежат в `assets/fonts` — там же описано, откуда они и как их
поставить в систему.
