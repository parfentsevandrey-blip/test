ТЕЛЕФОН НА ANDROID
------------------
Для Android есть приложение (файл TheMesh-...-android-debug.apk, см. README.md):
откройте его на телефоне и разрешите установку из этого источника. Оно не
проверялось на настоящем телефоне.

Запасной путь без приложения — программа в Termux (ставьте его из F-Droid, не из
Google Play), а интерфейс — обычная страница в браузере телефона. Подробности —
в файле ANDROID.md. Коротко, в Termux (подставьте имя скачанного архива):
   termux-setup-storage
   tar xzf ~/storage/downloads/themesh-linux-arm64.tar.gz
   cd themesh-linux-arm64 && ./themesh
Если Android убивает программу в фоне, отключите для Termux экономию заряда
батареи. На реальном телефоне это ещё не проверялось.
