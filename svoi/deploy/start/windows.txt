КАК ЗАПУСТИТЬ (1 минута)
------------------------
1. Распакуйте архив в любую папку (например, в «Документы»).
2. Дважды щёлкните svoi.exe.
   • Windows может показать синее окно «Windows защитила ваш компьютер»
     (у программы пока нет цифровой подписи). Нажмите «Подробнее» →
     «Выполнить в любом случае».
   • Если Windows спросит про доступ к сети («Брандмауэр Защитника
     Windows») — нажмите «Разрешить доступ». Без этого устройства
     не увидят друг друга.
3. Откроется чёрное окно и браузер с программой. На первом устройстве
   нажмите «Создать свою сеть».
4. Не закрывайте чёрное окно: пока оно открыто, программа работает.
   Закроете — программа остановится (данные сохранятся; в следующий раз
   просто запустите svoi.exe снова).
