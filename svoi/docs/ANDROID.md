# Телефон на Android через Termux (запасной путь)

> Обычный путь — **приложение**: файл `TheMesh-0.1.0-android-debug.apk` (CI: «The Mesh Android» → `themesh-android-apk`),
> устройство и ограничения описаны в [android/README.md](../android/README.md). Здесь — запасной путь для тех, кому приложение
> не подходит (старый WebView, нет возможности ставить APK): сама программа в [Termux](https://termux.dev), а интерфейс —
> обычная страница в браузере телефона.

> **Не проверялось на реальном телефоне.** Проверена только кросс-компиляция (`linux/arm64`, `android/arm64`) и работа
> на Linux. Ниже — путь, который должен работать, и места, где вероятны сюрпризы. Если что-то не так — пришлите вывод
> `themesh up --debug`.

`themesh` — один статический файл без зависимостей, поэтому он запускается в Termux (ставьте из F-Droid, не из Google Play).

## Установка

Самый надёжный способ — собрать на компьютере и перенести файл на телефон:

```bash
# на компьютере (нужен Go 1.26+)
GOOS=linux GOARCH=arm64 CGO_ENABLED=0 go build -trimpath -ldflags "-s -w" -o themesh-arm64 ./cmd/themesh
# или возьмите themesh-linux-arm64.tar.gz из архива релиза (make dist)
```

На телефоне в Termux:

```bash
termux-setup-storage                       # один раз: доступ к «Загрузкам»
cp ~/storage/downloads/themesh-arm64 $PREFIX/bin/themesh
chmod +x $PREFIX/bin/themesh
themesh version
```

(Собирать прямо в Termux можно, но `go.mod` требует Go 1.26, а пакет `golang` в Termux может быть
старше, и автоматически скачать нужный тулчейн для Android нельзя.)

## Запуск

```bash
termux-wake-lock                           # не давать системе усыплять процессор
themesh up --no-browser                       # в выводе — одноразовая ссылка для входа (10 минут)
termux-open-url "$(themesh url)"              # новая одноразовая ссылка; или откройте её в браузере вручную
```

* **Вступить в сеть:** на другом устройстве откройте «Устройства → Добавить устройство» и в браузере
  телефона на экране приветствия вставьте код `MESH1-…` (его можно переслать себе в мессенджере).
  То же из консоли: `themesh join MESH1-…`.
* **Добавить на главный экран:** в Chrome — «Установить приложение» (интерфейс — PWA, значок и
  манифест есть). Это ярлык на страницу `127.0.0.1:8777`; сам `themesh` должен работать в Termux.
* **Папки телефона** (фото, документы) предлагайте в «Файлы → Мои папки» по пути вида
  `/data/data/com.termux/files/home/storage/shared/DCIM` (после `termux-setup-storage`).

## Чтобы телефон не «пропадал»

Android агрессивно убивает фоновые процессы — это главная причина, по которой телефон окажется
«не в сети»:

1. Отключите оптимизацию батареи для Termux (Настройки → Приложения → Termux → Батарея → «Без ограничений»).
2. Оставьте включённым `termux-wake-lock` (в уведомлении Termux — «Acquire wakelock»).
3. Для запуска при включении телефона поставьте Termux:Boot и создайте `~/.termux/boot/themesh`:
   ```bash
   #!/data/data/com.termux/files/usr/bin/sh
   termux-wake-lock
   themesh up --no-browser >> ~/themesh.log 2>&1
   ```
4. Телефон может быть в мобильной сети за **симметричным NAT** оператора — тогда прямой канал
   невозможен, и связь пойдёт через ретранслятор (любой участник с достижимым адресом, обычно домашний
   сервер). Если в сети нет ни одного такого участника, телефон из мобильной сети не найдёт остальных:
   см. «Что нужно, чтобы всё работало…» в [README](../README.md).

## Известные неопределённости

* **DNS в Termux.** Статический бинарник Go не читает настройки DNS Android. Для имён STUN-серверов
  это учтено: если системный DNS не отвечает, `themesh` спрашивает `1.1.1.1` / `8.8.8.8` напрямую (только имена
  STUN-серверов). STUN можно отключить совсем: `themesh up --no-stun` — тогда внешние адреса
  сообщают друг другу участники сети.
* **Виртуальный интерфейс (`--tun`)** на телефоне недоступен (нужен root и `/dev/net/tun`).
* **Фоновая работа** целиком зависит от прошивки (Xiaomi, Huawei, Samsung ограничивают сильнее всего).
* **iOS** не поддерживается: нет способа запускать такую программу в фоне.
