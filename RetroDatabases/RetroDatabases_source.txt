  4. The normal-forms example created the table `orders` twice. The denormalised version is now `orders_flat`.
  5. The harness expected a filename prefix from grep. grep omits it when only one file matches, so the harness check was corrected. The example itself was fine.
- Four of the five bugs were in the example text. The first and fourth are easy to miss when reading, so every executable example is now run before it is accepted.

# Ретро-базы

Android-приложение на Kotlin, Jetpack Compose и Room. Внутри — «База 1»: каталог кодинга 80-х.

## Что внутри

Каталог разбит по видам записей:

| Вид | Записей | Что это |
|---|---:|---|
| Языки | 34 | Языки 1950–80-х от массовых до почти забытых |
| Системы | 23 | ОС, варианты Unix, исследовательские среды, СУБД |
| Устройства | 27 | Мейнфреймы, отечественные машины, ПК, домашние компьютеры, процессоры |
| Инструменты | 18 | make, lint, yacc, GCC, редакторы, отладчик, TeX, sed и другие |
| Практики | 39 | Методы, проектирование, тестирование, метрики, процессы, оптимизация |
| Пояснения | 5 | Как устроены конвейеры, рекурсивный спуск, стек Forth, Makefile, эмуляторы |
| Примеры | 5 | Короткие рецепты: частоты слов, sed, grep по журналу, qsort, GROUP BY |
| Проекты | 4 | Игра «Жизнь» на awk, лабиринт на C, записная книжка на sh, калькулятор на yacc |
| Флекс | 5 | Максимум из минимума: фрактал одним оператором, квайн, Мандельброт на awk |
| Кросс-код | 5 | Эксперименты, где языки смешаны: C с awk, make с awk, Forth внутри C, bc с awk |

Всего 165 записей, 55 из них помечены как редкие. У каждой записи есть год, автор, раздел, краткое описание, подробности, инструкция (для проектов и пояснений) и пример кода.

В приложении:
- список баз с числом записей;
- поиск по названию, оригинальному названию, автору, году и разделу (без учёта регистра, в том числе кириллицы);
- фильтры по виду, избранному и редким записям;
- записи сгруппированы по разделам внутри вида;
- избранное сохраняется в базе.

## Сборка и запуск

Нужно: Android Studio (актуальная версия), JDK 17, Android SDK 35 (platform 35 и build-tools 35.0.0). Минимальная версия Android — 8.0 (API 26).

1. Откройте папку `RetroDatabases` в Android Studio и дождитесь синхронизации Gradle.
2. Нажмите Run на эмуляторе или устройстве.

Из командной строки:

```
./gradlew assembleDebug        # сборка APK
./gradlew testDebugUnitTest    # тесты
```

Файл `local.properties` с путём к SDK создаётся Android Studio автоматически.

## Структура

- `app/src/main/java/com/example/retrodatabases/data` — Room: сущности, DAO, конвертеры, сама база и заполнение при первом запуске.
- `app/src/main/java/com/example/retrodatabases/data/seed` — записи базы 1, по одному файлу на вид, и каталог баз.
- `app/src/main/java/com/example/retrodatabases/ui` — навигация, ViewModel, фильтрация, экраны и компоненты.
- `app/src/test` — тесты фильтров, данных и самой базы (Robolectric).
- `DEVLOG.md` — журнал разработки с ростом строк кода по контрольным точкам.
- `RetroDatabases_source.txt` — весь исходный код одним текстовым файлом.

## Примеры в каталоге

Код из примеров и инструкций проверен запуском: gcc, mawk, sh, make, perl, bc, bison и SQLite. Для языков, которых нет в среде сборки (Forth, Prolog, Lisp, Smalltalk, BASIC и другие), примеры проверены только чтением, и это отмечено в журнале разработки.

## Как добавить базу

1. Создайте файл в `data/seed` с записями и `databaseId` новой базы. Функция `entry()` в `SeedEntry.kt` сейчас фиксирует `databaseId = 1`: для второй базы добавьте параметр.
2. Добавьте базу в `seedDatabases` (файл `SeedCatalog.kt`).
3. Базы из seed-списков попадают в базу только при её создании. В уже установленных копиях новая база появится после увеличения версии БД в `AppDatabase` и написания `Migration`.

package com.example.retrodatabases.data

import android.content.Context
import androidx.room.Database
import androidx.room.Room
import androidx.room.RoomDatabase
import androidx.room.TypeConverters
import androidx.sqlite.db.SupportSQLiteDatabase
import com.example.retrodatabases.data.seed.db1Records
import com.example.retrodatabases.data.seed.seedDatabases

@Database(
    entities = [DatabaseEntity::class, RecordEntity::class],
    version = 1,
    exportSchema = false,
)
@TypeConverters(Converters::class)
abstract class AppDatabase : RoomDatabase() {

    abstract fun libraryDao(): LibraryDao

    companion object {
        private const val FILE_NAME = "retro_databases.db"

        @Volatile
        private var instance: AppDatabase? = null

        fun get(context: Context): AppDatabase =
            instance ?: synchronized(this) {
                instance ?: buildDatabase(context.applicationContext).also { instance = it }
            }

        private fun buildDatabase(appContext: Context): AppDatabase =
            Room.databaseBuilder(appContext, AppDatabase::class.java, FILE_NAME)
                .addCallback(SeedCallback())
                .build()
    }
}

/**
 * Заполняет базы при первом создании файла БД.
 * Вставка идёт SQL-запросами прямо в onCreate, поэтому не нужно ждать готовности экземпляра Room.
 * Базы из seed-списков добавляются только при создании файла: в уже установленных копиях
 * новая база появится после увеличения версии БД и миграции.
 */
private class SeedCallback : RoomDatabase.Callback() {

    override fun onCreate(db: SupportSQLiteDatabase) {
        super.onCreate(db)

        seedDatabases.forEach { database ->
            db.execSQL(
                "INSERT INTO databases (id, name, description, colorHex) VALUES (?, ?, ?, ?)",
                arrayOf<Any?>(database.id, database.name, database.description, database.colorHex),
            )
        }

        db1Records.forEach { record ->
            db.execSQL(
                """
                INSERT INTO records (databaseId, kind, section, title, originalTitle, author, year,
                                     summary, details, instructions, example, rare, favorite)
                VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, 0)
                """.trimIndent(),
                arrayOf<Any?>(
                    record.databaseId,
                    record.kind.name,
                    record.section,
                    record.title,
                    record.originalTitle,
                    record.author,
                    record.year.toLong(),
                    record.summary,
                    record.details,
                    record.instructions,
                    record.example,
                    if (record.rare) 1L else 0L,
                ),
            )
        }
    }
}

package com.example.retrodatabases.data

import androidx.room.Entity
import androidx.room.ForeignKey
import androidx.room.Index
import androidx.room.PrimaryKey

/** Одна база данных внутри приложения, например «База 1». */
@Entity(tableName = "databases")
data class DatabaseEntity(
    @PrimaryKey val id: Long,
    val name: String,
    val description: String,
    /** Акцентный цвет базы в формате #RRGGBB. */
    val colorHex: String,
)

/** Запись каталога: язык, система, устройство, инструмент, практика, пояснение, проект и т. д. */
@Entity(
    tableName = "records",
    foreignKeys = [
        ForeignKey(
            entity = DatabaseEntity::class,
            parentColumns = ["id"],
            childColumns = ["databaseId"],
            onDelete = ForeignKey.CASCADE,
        ),
    ],
    indices = [Index("databaseId")],
)
data class RecordEntity(
    @PrimaryKey(autoGenerate = true) val id: Long = 0,
    val databaseId: Long,
    /** Вид записи: раздел верхнего уровня каталога. */
    val kind: Kind,
    /** Подраздел внутри вида, например «Императивные и системные» или «Процессоры». */
    val section: String,
    val title: String,
    val originalTitle: String,
    val author: String,
    val year: Int,
    val summary: String,
    /** Подробности: для проектов и пояснений — как всё устроено и работает. */
    val details: String,
    /** Пошаговая инструкция: как запустить, как пользоваться. Null, если не нужна. */
    val instructions: String?,
    /** Фрагмент кода (или несколько файлов с заголовками «### имя») или null. */
    val example: String?,
    /** Редкая или малоизвестная запись; есть отдельный фильтр. */
    val rare: Boolean = false,
    val favorite: Boolean = false,
)

/** Строка экрана списка баз: сама база и число её записей. */
data class DatabaseSummary(
    val id: Long,
    val name: String,
    val description: String,
    val colorHex: String,
    val recordCount: Int,
)

package com.example.retrodatabases.data

import androidx.room.Dao
import androidx.room.Query
import kotlinx.coroutines.flow.Flow

@Dao
interface LibraryDao {

    @Query(
        """
        SELECT d.id AS id,
               d.name AS name,
               d.description AS description,
               d.colorHex AS colorHex,
               (SELECT COUNT(*) FROM records r WHERE r.databaseId = d.id) AS recordCount
        FROM databases d
        ORDER BY d.id
        """
    )
    fun observeDatabases(): Flow<List<DatabaseSummary>>

    @Query("SELECT * FROM databases WHERE id = :databaseId")
    fun observeDatabase(databaseId: Long): Flow<DatabaseEntity?>

    @Query("SELECT * FROM records WHERE databaseId = :databaseId ORDER BY year, title")
    fun observeRecords(databaseId: Long): Flow<List<RecordEntity>>

    @Query("SELECT * FROM records WHERE id = :recordId")
    fun observeRecord(recordId: Long): Flow<RecordEntity?>

    @Query("UPDATE records SET favorite = NOT favorite WHERE id = :recordId")
    suspend fun toggleFavorite(recordId: Long)
}

package com.example.retrodatabases.ui

import androidx.compose.runtime.Composable
import androidx.navigation.NavType
import androidx.navigation.compose.NavHost
import androidx.navigation.compose.composable
import androidx.navigation.compose.rememberNavController
import androidx.navigation.navArgument
import com.example.retrodatabases.ui.screens.DatabasesScreen
import com.example.retrodatabases.ui.screens.RecordDetailScreen
import com.example.retrodatabases.ui.screens.RecordsScreen

private object Route {
    const val DATABASES = "databases"
    const val RECORDS = "records/{databaseId}"
    const val RECORD = "record/{recordId}"
}

@Composable
fun AppNavHost() {
    val navController = rememberNavController()

    NavHost(navController = navController, startDestination = Route.DATABASES) {
        composable(Route.DATABASES) {
            DatabasesScreen(
                onOpenDatabase = { databaseId -> navController.navigate("records/$databaseId") },
            )
        }

        composable(
            route = Route.RECORDS,
            arguments = listOf(navArgument("databaseId") { type = NavType.LongType }),
        ) { entry ->
            RecordsScreen(
                databaseId = entry.arguments?.getLong("databaseId") ?: 0L,
                onBack = { navController.popBackStack() },
                onOpenRecord = { recordId -> navController.navigate("record/$recordId") },
            )
        }

        composable(
            route = Route.RECORD,
            arguments = listOf(navArgument("recordId") { type = NavType.LongType }),
        ) { entry ->
            RecordDetailScreen(
                recordId = entry.arguments?.getLong("recordId") ?: 0L,
                onBack = { navController.popBackStack() },
            )
        }
    }
}

package com.example.retrodatabases.ui

import android.app.Application
import androidx.lifecycle.AndroidViewModel
import androidx.lifecycle.viewModelScope
import com.example.retrodatabases.data.AppDatabase
import com.example.retrodatabases.data.DatabaseEntity
import com.example.retrodatabases.data.DatabaseSummary
import com.example.retrodatabases.data.RecordEntity
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.SharingStarted
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.map
import kotlinx.coroutines.flow.stateIn
import kotlinx.coroutines.launch

/** Источник данных для всех экранов: списки баз, записи каталога, избранное. */
class LibraryViewModel(application: Application) : AndroidViewModel(application) {

    private val dao = AppDatabase.get(application).libraryDao()

    val databases: StateFlow<List<DatabaseSummary>> = dao.observeDatabases()
        .stateIn(viewModelScope, SharingStarted.WhileSubscribed(5_000), emptyList())

    fun database(databaseId: Long): Flow<DatabaseEntity?> = dao.observeDatabase(databaseId)

    /** Записи базы в порядке каталога: вид, раздел, год, название. */
    fun records(databaseId: Long): Flow<List<RecordEntity>> =
        dao.observeRecords(databaseId).map { records -> records.sortedWith(CatalogOrder) }

    fun record(recordId: Long): Flow<RecordEntity?> = dao.observeRecord(recordId)

    fun toggleFavorite(recordId: Long) {
        viewModelScope.launch { dao.toggleFavorite(recordId) }
    }
}

private val CatalogOrder: Comparator<RecordEntity> =
    compareBy<RecordEntity> { it.kind.ordinal }
        .thenBy { it.section }
        .thenBy { it.year }
        .thenBy { it.title }

package com.example.retrodatabases.ui

import com.example.retrodatabases.data.Kind
import com.example.retrodatabases.data.RecordEntity

/**
 * Фильтрация записей на стороне приложения: вид, избранное, редкие и текстовый поиск.
 * Поиск без учёта регистра. SQLite LIKE не понимает регистр кириллицы, поэтому используем lowercase().
 */
fun filterRecords(
    records: List<RecordEntity>,
    query: String,
    kind: Kind?,
    favoritesOnly: Boolean,
    rareOnly: Boolean,
): List<RecordEntity> {
    val needle = query.trim().lowercase()
    return records.filter { record ->
        (kind == null || record.kind == kind) &&
            (!favoritesOnly || record.favorite) &&
            (!rareOnly || record.rare) &&
            (needle.isEmpty() || record.searchableText().contains(needle))
    }
}

private fun RecordEntity.searchableText(): String =
    listOf(title, originalTitle, author, section, summary, year.toString())
        .joinToString(separator = " ")
        .lowercase()

/** Ярлык вида записи («Языки», «Системы» и так далее) на фоне цвета вида. */

/**
 * Карточка записи каталога: цветная полоска вида, ярлыки, название, оригинальное название,
 * краткое описание и кнопка избранного.
 */
@Composable
fun RecordCard(
    record: RecordEntity,
    onClick: () -> Unit,
    onToggleFavorite: () -> Unit,
    modifier: Modifier = Modifier,
) {
    Card(
        onClick = onClick,
        modifier = modifier.fillMaxWidth(),
    ) {
        Row(modifier = Modifier.height(IntrinsicSize.Min)) {
            Box(
                modifier = Modifier
                    .width(6.dp)
                    .fillMaxHeight()
                    .background(record.kind.accent()),
            )
            Column(
                modifier = Modifier
                    .weight(1f)
                    .padding(start = 14.dp, top = 12.dp, bottom = 12.dp),
                verticalArrangement = Arrangement.spacedBy(4.dp),
            ) {
                Row(verticalAlignment = Alignment.CenterVertically) {
                    KindBadge(kind = record.kind)
                    if (record.rare) {
                        Spacer(modifier = Modifier.width(6.dp))
                        RareBadge()
                    }
                    Spacer(modifier = Modifier.weight(1f))
                    Text(
                        text = record.year.toString(),
                        style = MaterialTheme.typography.labelLarge,
                        color = MaterialTheme.colorScheme.onSurfaceVariant,
                    )
                }
                Text(
                    text = record.title,
                    style = MaterialTheme.typography.titleMedium,
                    fontWeight = FontWeight.SemiBold,
                )
                Text(
                    text = record.summary,
                    style = MaterialTheme.typography.bodyMedium,
                    color = MaterialTheme.colorScheme.onSurfaceVariant,
                    maxLines = 2,
                    overflow = TextOverflow.Ellipsis,
                )
            }
            IconButton(onClick = onToggleFavorite) {
                Icon(
                    imageVector = Icons.Filled.Star,
                    contentDescription = stringResource(
                        if (record.favorite) R.string.favorite_remove else R.string.favorite_add,
                    ),
                    tint = if (record.favorite) {
                        MaterialTheme.colorScheme.tertiary
                    } else {
                        MaterialTheme.colorScheme.onSurfaceVariant.copy(alpha = 0.5f)
                    },
                )
            }
        }
    }
}

                color = MaterialTheme.colorScheme.primary,
            )
            Row(horizontalArrangement = Arrangement.spacedBy(8.dp)) {

                if (record.rare) {

                }
            }
            Text(

                style = MaterialTheme.typography.headlineSmall,
                fontWeight = FontWeight.Bold,
            )
            Text(

                style = MaterialTheme.typography.titleSmall,
                color = MaterialTheme.colorScheme.onSurfaceVariant,
            )
            Text(
                text = "${stringResource(R.string.label_author)}: ${record.author}",
                style = MaterialTheme.typography.bodyMedium,
            )
        }

        InfoSection(title = stringResource(R.string.section_summary)) {

/**
 * Каталог одной базы: поиск, фильтры по виду, избранному и редким записям,
 * записи сгруппированы по разделам внутри вида.
 */
@OptIn(ExperimentalMaterial3Api::class)
@Composable
fun RecordsScreen(
    databaseId: Long,
    onBack: () -> Unit,
    onOpenRecord: (Long) -> Unit,
    viewModel: LibraryViewModel = viewModel(),
) {
    val database by remember(databaseId) { viewModel.database(databaseId) }
        .collectAsStateWithLifecycle(initialValue = null)
    val records by remember(databaseId) { viewModel.records(databaseId) }
        .collectAsStateWithLifecycle(initialValue = emptyList())

    var query by rememberSaveable { mutableStateOf("") }
    var kind by remember { mutableStateOf<Kind?>(null) }
    var favoritesOnly by remember { mutableStateOf(false) }
    var rareOnly by remember { mutableStateOf(false) }

    val countByKind = remember(records) { records.groupingBy { it.kind }.eachCount() }
    val visible = remember(records, query, kind, favoritesOnly, rareOnly) {
        filterRecords(records, query, kind, favoritesOnly, rareOnly)
    }
    // Порядок групп сохраняется: записи уже отсортированы по виду и разделу
    val groups = remember(visible) { visible.groupBy { it.kind to it.section } }

    Scaffold(
        topBar = {
            TopAppBar(
                title = {
                    Text(
                        text = database?.name.orEmpty(),
                        style = MaterialTheme.typography.titleMedium,
                        maxLines = 1,
                    )
                },
                navigationIcon = {
                    IconButton(onClick = onBack) {
                        Icon(
                            imageVector = Icons.AutoMirrored.Filled.ArrowBack,
                            contentDescription = stringResource(R.string.cd_back),
                        )
                    }
                },
            )
        },
    ) { innerPadding ->
        Column(
            modifier = Modifier
                .fillMaxSize()
                .padding(innerPadding),
        ) {
            OutlinedTextField(
                value = query,
                onValueChange = { query = it },
                modifier = Modifier
                    .fillMaxWidth()
                    .padding(horizontal = 16.dp),
                singleLine = true,
                placeholder = { Text(stringResource(R.string.search_hint)) },
                leadingIcon = { Icon(Icons.Filled.Search, contentDescription = null) },
                trailingIcon = {
                    if (query.isNotEmpty()) {
                        IconButton(onClick = { query = "" }) {
                            Icon(
                                imageVector = Icons.Filled.Close,
                                contentDescription = stringResource(R.string.cd_clear),
                            )
                        }
                    }
                },
            )

            LazyRow(
                modifier = Modifier.padding(vertical = 12.dp),
                contentPadding = PaddingValues(horizontal = 16.dp),
                horizontalArrangement = Arrangement.spacedBy(8.dp),
            ) {
                item {
                    FilterChip(
                        selected = kind == null && !favoritesOnly && !rareOnly,
                        onClick = {
                            kind = null
                            favoritesOnly = false
                            rareOnly = false
                        },
                        label = { Text("${stringResource(R.string.filter_all)} ${records.size}") },
                    )
                }
                items(Kind.entries, key = { it.name }) { option ->
                    FilterChip(
                        selected = kind == option,
                        onClick = { kind = if (kind == option) null else option },
                        label = { Text("${option.label} ${countByKind[option] ?: 0}") },
                    )
                }
                item {
                    FilterChip(
                        selected = favoritesOnly,
                        onClick = { favoritesOnly = !favoritesOnly },
                        label = { Text(stringResource(R.string.filter_favorites)) },
                        leadingIcon = { Icon(Icons.Filled.Star, contentDescription = null) },
                    )
                }
                item {
                    FilterChip(
                        selected = rareOnly,
                        onClick = { rareOnly = !rareOnly },
                        label = { Text("${stringResource(R.string.filter_rare)} ${records.count { it.rare }}") },
                    )
                }
            }

            Text(
                text = stringResource(R.string.found_count, visible.size),
                modifier = Modifier.padding(horizontal = 16.dp, vertical = 4.dp),
                style = MaterialTheme.typography.labelLarge,
                color = MaterialTheme.colorScheme.onSurfaceVariant,
            )

            if (visible.isEmpty()) {
                Text(
                    text = stringResource(R.string.nothing_found),
                    modifier = Modifier.padding(24.dp),
                    style = MaterialTheme.typography.bodyLarge,
                    color = MaterialTheme.colorScheme.onSurfaceVariant,
                )
            } else {
                LazyColumn(
                    modifier = Modifier.weight(1f),
                    contentPadding = PaddingValues(horizontal = 16.dp, vertical = 8.dp),
                    verticalArrangement = Arrangement.spacedBy(10.dp),
                ) {
                    groups.forEach { (group, sectionRecords) ->
                        val (groupKind, groupSection) = group
                        item(key = "header-${groupKind.name}-$groupSection") {
                            SectionHeader(
                                title = groupSection,
                                count = sectionRecords.size,
                                accent = groupKind.accent(),
                            )
                        }
                        items(sectionRecords, key = { it.id }) { record ->
                            RecordCard(
                                record = record,
                                onClick = { onOpenRecord(record.id) },
                                onToggleFavorite = { viewModel.toggleFavorite(record.id) },
                            )
                        }
                    }
                }
            }
        }
    }
}

/** Заголовок раздела внутри вида: цветная черта, название и число записей. */

            fontWeight = FontWeight.Bold,
            color = MaterialTheme.colorScheme.onSurface,

        Spacer(modifier = Modifier.weight(1f))
        Text(
            text = count.toString(),
            style = MaterialTheme.typography.labelLarge,
            color = MaterialTheme.colorScheme.onSurfaceVariant,
        )
    }
}

import org.junit.Assert.assertNotNull

/** Runs the real database: schema validation, the seed SQL in onCreate and the favourite toggle. */
@RunWith(RobolectricTestRunner::class)
class AppDatabaseSeedTest {

    @Test
    fun firstOpenSeedsDatabaseOneWithEveryRecord() = runBlocking {
        val context = ApplicationProvider.getApplicationContext<Context>()
        val dao = AppDatabase.get(context).libraryDao()

        val databases = dao.observeDatabases().first()
        assertEquals(1, databases.size)
        assertEquals(db1Records.size, databases.single().recordCount)

        val records = dao.observeRecords(1L).first()
        assertEquals(db1Records.size, records.size)
        assertTrue(records.any { it.kind == Kind.PROJECT && it.instructions != null })
        assertTrue(records.any { it.rare })
    }

    @Test
    fun toggleFavoriteStoresTheChange() = runBlocking {
        val context = ApplicationProvider.getApplicationContext<Context>()
        val dao = AppDatabase.get(context).libraryDao()

        val record = dao.observeRecords(1L).first().first()
        assertEquals(false, record.favorite)

        dao.toggleFavorite(record.id)
        val updated = dao.observeRecord(record.id).first()
        assertNotNull(updated)
        assertEquals(true, updated!!.favorite)
    }
}

# Attempt to set APP_HOME

# Resolve links: $0 may be a link
app_path=$0

# Need this for daisy-chained symlinks.
while
    APP_HOME=${app_path%"${app_path##*/}"}  # leaves a trailing /; empty if no leading path
    [ -h "$app_path" ]
do
    ls=$( ls -ld "$app_path" )
    link=${ls#*' -> '}
    case $link in             #(
      /*)   app_path=$link ;; #(
      *)    app_path=$APP_HOME$link ;;
    esac

Please set the JAVA_HOME variable in your environment to match the

set JAVA_EXE=%JAVA_HOME%/bin/java.exe

if exist "%JAVA_EXE%" goto execute

echo. 1>&2
echo ERROR: JAVA_HOME is set to an invalid directory: %JAVA_HOME% 1>&2
echo. 1>&2
echo Please set the JAVA_HOME variable in your environment to match the 1>&2
echo location of your Java installation. 1>&2

goto fail

:execute
@rem Setup the command line

set CLASSPATH=


@rem Execute Gradle
"%JAVA_EXE%" %DEFAULT_JVM_OPTS% %JAVA_OPTS% %GRADLE_OPTS% "-Dorg.gradle.appname=%APP_BASE_NAME%" -classpath "%CLASSPATH%" -jar "%APP_HOME%\gradle\wrapper\gradle-wrapper.jar" %*

:end
@rem End local scope for the variables with windows NT shell
if %ERRORLEVEL% equ 0 goto mainEnd

:fail
rem Set variable GRADLE_EXIT_CONSOLE if you need the _script_ return code instead of
rem the _cmd.exe /c_ return code!
set EXIT_CODE=%ERRORLEVEL%
if %EXIT_CODE% equ 0 set EXIT_CODE=1
if not ""=="%GRADLE_EXIT_CONSOLE%" exit %EXIT_CODE%
exit /b %EXIT_CODE%

:mainEnd
if "%OS%"=="Windows_NT" endlocal

:omega
