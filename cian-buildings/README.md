# Здания на Садовом кольце (ЦИАН → PDF)

**Результат:** [`Здания_на_Садовом_кольце.pdf`](Здания_на_Садовом_кольце.pdf) — 55 страниц A4 (альбомная ориентация), 9 зданий, 32 объявления от разных продавцов.

Внутри:

- обложка и обзорная карта на всю страницу с нанесённым Садовым кольцом;
- сравнительная таблица (назначение, площадь, этажность, первая линия, расстояние до кольца, метро, цена, НДС, ₽/м²) и график цены за м² с выводами, включая доходность к цене там, где продавец назвал МАП;
- по каждому зданию 4–6 страниц: главное фото, цена и параметры, метро, арендаторы; ключевые факты и оговорки; **кто продаёт** — все объявления по этому зданию с ценами и расхождениями между ними; поэтажные планы; фото и карта Яндекса с линией кольца; галерея;
- методика и итог «первая линия: да / нет / под вопросом» по всем объектам.

## Как пересобрать

```bash
.venv/bin/python scrape.py   # Scrapling; страницы из listings.txt -> build/raw/
.venv/bin/python find_duplicates.py   # другие объявления по тем же зданиям -> build/search/candidates.json
                             # (проверить вручную и записать в data/duplicates.json)
.venv/bin/python fetch_duplicates.py  # страницы подтверждённых дублей -> build/raw_dups/
python3 extract.py           # JSON объявлений + notes.json + дубли -> data/listings.json, фото -> build/img/
node maps.js                 # скриншоты Яндекс Карт -> build/maps/
python3 render.py            # HTML -> build/report.html
node pdf.js                  # PDF через Playwright
```

Окружение то же, что у `../cian-report` (Scrapling, Pillow, Jinja2, Playwright).

## Данные

- `data/listings.json` — нормализованные объявления. Если цена в долларах, рублёвая сумма берётся из `prices.rur` (это пересчёт ЦИАН).
- `data/notes.json` — то, чего нет в полях объявления, а есть только в описаниях продавцов (всех, а не только исходного): факты, арендаторы, МАП, оговорки и расхождения между объявлениями. Там же указаны номера фото, которые на самом деле поэтажные планы, выбор главного фото, фото и планы, взятые из объявлений других продавцов (`fromOthers`), и вывод о первой линии по карте.
- `data/duplicates.json` — подтверждённые вручную объявления других продавцов по каждому зданию. Кандидатов ищет `find_duplicates.py`: по номеру дома и полигоном ~250 м вокруг точки (агенты пишут адрес по-разному), с площадью ±20%. Объявление на часть здания попадает в таблицу продавцов с пометкой «часть здания», но не входит в диапазон цен.
- `data/ring.json` — геометрия Садового кольца из OpenStreetMap (relation 2094267) и расстояние от каждого объекта до ближайшей проезжей части кольца.

## Заметки

- Карты снимаются без пинов виджета. Кольцо и номерные маркеры рисуются поверх, одним SVG в пиксельных координатах снимка (проекция Яндекса EPSG:3395). У SVG стоит `preserveAspectRatio="slice"`, поэтому слой обрезается точно так же, как картинка с `object-fit: cover`.
- Первая линия подтверждается по карте у 6 из 9 объектов. №1 стоит на второй линии, №5 — в глубине квартала. №7 — на Таганской площади, примерно в 100 м от проезжей части кольца (кольцо там в тоннеле).
