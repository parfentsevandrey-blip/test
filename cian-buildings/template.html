Методика · источники и оговорки{{ date }}

Откуда данные

  • Цены, площади, характеристики и фото — из объявлений ЦИАН на {{ date }}. Ссылка на объявление есть внизу страницы каждого объекта.
  • Ключевые факты (год постройки, земля, мощность, арендаторы, МАП) — из описаний продавцов, без проверки по ЕГРН.
  • Одно здание обычно продают несколько агентов. Для каждого объекта найдены все объявления на ЦИАН — по номеру дома и по карте в радиусе 250 м с близкой площадью — и проверены вручную: {{ stats.offers }} {{ plural(stats.offers, 'объявление', 'объявления', 'объявлений') }} по {{ stats.count }} зданиям. Из них взяты недостающие факты, фото и поэтажные планы; расхождения показаны на странице «Кто продаёт».
  • Если цена выставлена в долларах, рублёвая сумма — по курсу ЦИАН на дату выгрузки и будет меняться.
  • Доходность к цене — МАП × 12 / цена; это ориентир до вычета расходов и налогов, а не расчёт окупаемости.

Как считалась близость к кольцу

  • Линия Садового кольца — {{ ring_source }}, все проезжие части и дублёры.
  • «До кольца» — расстояние от точки объекта на карте ЦИАН до ближайшей проезжей части кольца. Точка обычно стоит в центре здания, поэтому для домов, выходящих фасадом на кольцо, это 25–40 м.
  • Вывод «первая линия — да / нет / под вопросом» сделан по карте: выходит ли фасад на проезжую часть кольца. Поле «линия» в объявлении ЦИАН приведено рядом для сравнения — многие продавцы его не заполняют.
  • Оговорки (часть здания, ОКН, вторая линия, продажа юрлица) отмечены на странице каждого объекта жёлтым.
