Veil

Tor через Snowflake, meek, WebTunnel или Conjure. Без аккаунта, без подписки, без единого нашего сервера.

Установщик положит Veil в папку «Программы». Ничего больше он не меняет: ни настроек сети, ни автозапуска. Сетевые настройки приложение трогает только по нажатию «Подключить» и возвращает по нажатию «Отключить».

Приложение подписано без сертификата Apple Developer, поэтому macOS спросил разрешение на открытие пакета. Файлы, установленные пакетом, macOS в карантин не помещает, и само приложение потом открывается без вопросов.
