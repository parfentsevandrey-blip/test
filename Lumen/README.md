# Lumen — видеоплеер для macOS 26+

Нативный плеер для Apple Silicon, написанный с нуля на Swift 6 / SwiftUI, с интерфейсом **Liquid Glass**.
Первое приложение каталога — см. [манифест](../MANIFESTO.md).
Сторонних библиотек и бинарников внутри нет: только системные фреймворки (AVFoundation, VideoToolbox,
Core Image, Core Media) и собственный код. Matroska (MKV/WebM), звук DTS и субтитры Blu-ray Lumen читает сам.

> **Установка без предупреждений macOS.** Проще всего через [Harbor](../Harbor/) — каталог всех наших приложений.
> Поставьте его одной командой в Терминале
> `curl -fsSL https://github.com/parfentsevandrey-blip/test/releases/download/catalog/install.sh | bash`
> и установите Lumen из каталога: обновления будут приходить сами, данные и настройки сохранятся.
> Без Harbor: `curl -fsSL https://github.com/parfentsevandrey-blip/test/releases/download/catalog/install.sh | bash -s -- lumen`.

## Установка

1. Скачайте `Lumen.dmg` (артефакт **Lumen-dmg** последней сборки в GitHub Actions → workflow «Lumen (macOS)»).
2. Откройте образ и перетащите **Lumen** в «Программы».
3. Приложение подписано ad-hoc, без нотаризации Apple, поэтому при первом запуске:
   **Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»**
   (или в Терминале: `xattr -dr com.apple.quarantine /Applications/Lumen.app`).
4. Сделать плеером по умолчанию: «Свойства» любого видео (⌘I) → «Открывать в программе» → Lumen → «Изменить все».

## Что внутри

Лёгкий плеер в духе VLC и QuickTime: бросили файл в окно — смотрите. Без библиотеки, без «индексации», без копий
файлов на диске.

**Интерфейс**
- Компактная стеклянная панель управления (Liquid Glass), как в QuickTime: её можно **утащить в любое место окна** —
  у краёв и в углах она примагничивается и запоминает положение. Громкость, скорость и главы выезжают из неё
  каплями стекла.
- Панель «Звук и субтитры» (T или кнопка на панели): все дорожки видны сразу, переключение — один щелчок.
  Дорожки, которые macOS не воспроизводит, показаны приглушёнными — без всплывающих ошибок.
- Шкала времени рисуется в такт дисплею (до 120 Гц), метки глав, тактильный отклик трекпада на их границах.
- Живая подсветка из цветов кадра вокруг видео, окно подгоняется под пропорции кадра, интерфейс прячется вместе
  со «светофором» окна. Бейджи 4K / HDR10 / Dolby Vision / HLG.

**Воспроизведение**
- MP4, MOV, M4V и аудио играет системный AVPlayer.
- **MKV / WebM / MKA** — собственный потоковый движок: EBML-парсер читает файл прямо во время просмотра,
  кадры уходят в аппаратный декодер через `AVSampleBufferDisplayLayer`, звук — в `AVSampleBufferAudioRenderer`
  с общими часами. Открытие мгновенное при любом размере файла, перемотка — по индексу Cues к ключевому кадру,
  точная — до нужного кадра.
- Видео: H.264, HEVC (8/10 бит, HDR10, HLG, Dolby Vision), AV1, VP9 (аппаратно, VideoToolbox).
- Звук: AAC, AC-3, E-AC-3 (Atmos), MP3, FLAC, Opus, ALAC, PCM и **DTS** — собственный декодер DTS Coherent
  Acoustics по ETSI TS 102 114, написанный с нуля (у DTS-HD играет ядро; 5.1, 6.1, 96 кГц).
- Субтитры: SRT, ASS/SSA, WebVTT, встроенные текстовые и **Blu-ray (PGS)** — собственный декодер картинок,
  субтитры масштабируются вместе с кадром. Внешние файлы рядом с видео подхватываются сами (кодировка
  Windows-1251 тоже), их можно бросить в окно; сдвиг задержки.
- Скорость 0,5–2× с сохранением высоты тона, покадровый шаг, продолжение с места остановки, картинка в картинке,
  снимок кадра (PNG + буфер обмена), масштаб, поворот, отражение, «щипок» для увеличения, свайп для перемотки.
- Несколько брошенных файлов играют по порядку. «Исполняется» в Пункте управления, медиаклавиши и AirPods.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Пробел, K | Пауза |
| ← → / J L | Перемотка (⇧ — втрое дальше, ⌥ — 1 с) |
| ↑ ↓ | Громкость |
| , . | Кадр назад / вперёд |
| [ ] \ | Скорость |
| S / A | Следующие субтитры / звуковая дорожка |
| T | Панель «Звук и субтитры» |
| G H | Сдвиг субтитров на 0,1 с |
| F, ⏎ | Полный экран |
| P | Картинка в картинке |
| Z R | Масштаб, поворот |
| I | Сведения о файле |
| 0–9 | Переход к 0–90 % |
| ⌘O | Открыть |
| ⇧⌘S | Сохранить кадр |

## Сборка из исходников

Нужен Xcode 26 или новее.

```sh
cd Lumen
./scripts/build.sh          # → dist/Lumen.app и dist/Lumen.dmg
```

Проверка движка на файле (отчёт в JSON): `dist/Lumen.app/Contents/MacOS/Lumen --selftest-playback movie.mkv`.
В CI она прогоняется на наборе файлов из `scripts/make-fixtures.sh` (H.264/HEVC/VP9/AV1; AAC, AC-3, E-AC-3, DTS,
FLAC, PCM, Opus, MP3; SRT, ASS, PGS), а ещё делаются скриншоты интерфейса.

## Устройство

```
Sources/Lumen/
  App/        точка входа, модель приложения, меню, настройки, самопроверка
  Matroska/   EBML-парсер, потоковое чтение блоков, описания форматов, VP9 через VideoToolbox
  Audio/      декодер DTS, источники звука для рендерера (как есть / системный декодер / PCM)
  Playback/   PlaybackCore: AVPlayer и потоковый движок Matroska; субтитры, PGS, подсветка
  Views/      SwiftUI: плеер, перетаскиваемая панель, боковые панели, стеклянные компоненты
```

Swift 6.2+ с `defaultIsolation(MainActor)`: интерфейс живёт на главном акторе, тяжёлая работа явно уходит
в `@concurrent`-функции и отдельные очереди.
