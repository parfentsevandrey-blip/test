# Lumen — видеоплеер для macOS 26+

Нативный плеер для Apple Silicon, написанный с нуля на Swift 6 / SwiftUI, с интерфейсом **Liquid Glass**.
Первое приложение каталога — см. [манифест](../MANIFESTO.md).
Сторонних библиотек и бинарников внутри нет: только системные фреймворки (AVFoundation, VideoToolbox,
Core Image, Core Media) и собственный код. Даже Matroska (MKV/WebM) читает свой демультиплексор.

> **Установка без предупреждений macOS.** Проще всего через [Harbor](../Harbor/) — каталог всех наших приложений.
> Поставьте его одной командой в Терминале
> `curl -fsSL https://github.com/parfentsevandrey-blip/test/releases/download/catalog/install.sh | bash`
> и установите Lumen из каталога: обновления будут приходить сами, данные и настройки сохранятся.
> Без Harbor: `curl -fsSL https://github.com/parfentsevandrey-blip/test/releases/download/catalog/install.sh | bash -s -- lumen`.

## Установка

1. Скачайте `Lumen.dmg` (артефакт **Lumen-dmg** последней сборки в GitHub Actions → workflow «Lumen (macOS)»).
2. Откройте образ и перетащите **Lumen** в «Программы».
3. Приложение подписано ad-hoc, без нотаризации Apple, поэтому при первом запуске:
   **Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»**
   (или в Терминале: `xattr -dr com.apple.quarantine /Applications/Lumen.app`).
4. Сделать плеером по умолчанию: «Свойства» любого видео (⌘I) → «Открывать в программе» → Lumen → «Изменить все».

## Что внутри

**Интерфейс**
- Плавающий стеклянный остров управления (`glassEffect`, `GlassEffectContainer`). Скорость, громкость, субтитры,
  дорожки и главы выезжают из него каплями жидкого стекла и морфятся (`glassEffectID`).
- Превью кадра над шкалой времени тоже стеклянное и «вытекает» из острова. Шкала рисуется в такт дисплею (до 120 Гц).
- **Живая подсветка (ambient)**: цвета кадра снимаются через уменьшенный `AVPlayerItemVideoOutput` (64×36), сетка 3×3
  превращается в размытый `MeshGradient` вокруг видео. Этими же цветами подкрашивается стекло интерфейса и фон библиотеки.
- Режим «сцены»: видео со скруглёнными углами парит над собственным свечением, окно подгоняется под пропорции кадра.
- Библиотека: карточки с 3D-наклоном за курсором, бликом и **скиммингом** (движение мыши по обложке листает кадры фильма),
  «Продолжить просмотр», избранное, поиск, анимированный меш-фон.
- Автоскрытие интерфейса вместе со «светофором» окна, курсор прячется. Бейджи 4K / HDR10 / Dolby Vision / HLG.
- Тактильный отклик трекпада на границах глав, учёт настроек «Уменьшить движение».

**Воспроизведение**
- MP4, MOV, M4V, MKV, WebM, MKA, аудио; H.264, HEVC (8/10 бит), AV1, ProRes, VP9; AAC, AC-3, E-AC-3, MP3, FLAC, ALAC.
- HDR10, HLG и Dolby Vision выводятся через EDR-конвейер AVFoundation.
- **MKV/WebM**: свой EBML-парсер на отображённом в память файле → перепаковка в MP4 *без перекодирования*
  через `AVAssetWriter` (сохраняются B-кадры, HDR-метаданные, анаморф, несколько дорожек, главы, SRT/ASS/WebVTT).
  VP9 декодируется VideoToolbox и кодируется аппаратным HEVC-кодером. Результат кэшируется.
- Встроенные и внешние субтитры (SRT/VTT/ASS, автоподхват файлов рядом, кодировка Windows-1251) на стеклянной подложке,
  сдвиг задержки, размер.
- Цветокоррекция в реальном времени (Core Image): экспозиция, контраст, насыщенность, сочность, температура, резкость,
  виньетка и пресеты «Кино», «Нуар», «Ярко»…
- Скорость 0,25–3× с сохранением высоты тона, покадровый шаг, повтор A–B, очередь и папки, перемешивание и повтор,
  продолжение с места остановки, картинка в картинке, снимок кадра (PNG + буфер обмена), масштаб, поворот, отражение,
  жест «щипок» для увеличения, свайп трекпадом для перемотки.
- «Исполняется» в Пункте управления, медиаклавиши и AirPods.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Пробел, K | Пауза |
| ← → / J L | Перемотка (⇧ — втрое дальше, ⌥ — 1 с) |
| ↑ ↓ | Громкость |
| , . | Кадр назад / вперёд |
| [ ] \ | Скорость |
| S / A | Субтитры / звуковая дорожка |
| G H | Сдвиг субтитров на 0,1 с |
| B | Повтор A–B |
| F, ⏎ | Полный экран |
| P | Картинка в картинке |
| Z R | Масштаб, поворот |
| E Q I | Панели «Изображение», «Очередь», «Инфо» |
| 0–9 | Переход к 0–90 % |
| ⌘O / ⇧⌘O | Открыть файл / папку |
| ⇧⌘S | Сохранить кадр |
| ⌘L | Библиотека |

## Сборка из исходников

Нужен Xcode 26 или новее.

```sh
cd Lumen
./scripts/build.sh          # → dist/Lumen.app и dist/Lumen.dmg
```

Проверка демультиплексора на файле: `dist/Lumen.app/Contents/MacOS/Lumen --selftest-remux movie.mkv /tmp/out`.

## Устройство

```
Sources/Lumen/
  App/        точка входа, модель приложения, меню, самопроверка
  Matroska/   EBML-парсер, индекс блоков, перепаковка, VP9 → HEVC
  Playback/   движок AVPlayer, подсветка, цветокоррекция, субтитры, кэш
  Library/    библиотека, позиции просмотра, обложки
  Views/      SwiftUI: библиотека, плеер, остров, панели, стеклянные компоненты
```

Swift 6.2+ с `defaultIsolation(MainActor)`: интерфейс живёт на главном акторе, тяжёлая работа явно уходит
в `@concurrent`-функции и отдельные очереди.
