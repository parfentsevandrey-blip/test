# report — генератор отчёта-подборки объектов недвижимости

Воспроизводит многостраничный A4-отчёт в фирменном стиле (тёмно-синие
заголовки, золотые линейки, серая таблица характеристик) из структурированного
JSON. На вход — данные по объектам, на выход — единый PDF.

Три рендерера с **одинаковым JSON-форматом**:

```bash
pip install -r requirements.txt

# Word (.docx) — РЕДАКТИРУЕМЫЙ в MS Word / LibreOffice. Реальная Google-карта,
# полная фотогалерея. Это основной формат, если файл нужно дорабатывать.
python3 build_report_docx.py content_utrecht.json -o report.docx

# Векторный PDF: выделяемый/искомый текст, чёткий при зуме.
python3 build_report_pdf.py content_example.json -o report.pdf

# Растровый PDF (страницы-картинки) — запасной вариант.
python3 build_report.py content_example.json -o report_raster.pdf
```

Примеры рядом: `report_utrecht.docx` (Word, Google-карты, полные галереи),
`report_vector.pdf` (ReportLab) и `report_demo.pdf` (растровый).

### Карта

- **Word** по умолчанию использует **настоящую Google-карту** —
  reverse-engineered бесключевые тайлы `mt{0-3}.google.com/vt`
  (`funda_a4/make_sheet.py:google_tiles_map`), с авто-фолбэком на OSM.
- PDF-рендереры используют OSM (тоже без ключа).

## Структура отчёта

- **Обложка** — заголовок + золотые линейки + нумерованный список объектов с ценами.
- **По каждому объекту:**
  1. **Текстовые страницы** (авто-пагинация): заголовок, строка района, серая
     таблица характеристик, разделы прозой — «О ГОРОДЕ И РАЙОНЕ», «ОПИСАНИЕ
     ОБЪЕКТА», «ПЛАНИРОВКА», «ТЕХНИЧЕСКИЕ ХАРАКТЕРИСТИКИ», «УЧАСТОК И ПАРКОВКА»,
     «РАСПОЛОЖЕНИЕ И ДОСТУПНОСТЬ», «ОСОБЕННОСТИ И СТАТУС», а для инвест-объектов
     ещё «АРЕНДА» и «АРЕНДНЫЙ ДОХОД».
  2. **Страница «карта + фото»** — сверху обзорная карта OSM с маркером и зумом,
     где видны соседние города; снизу главное фото фасада.
  3. **Фото-галерея** — по 2 фото на страницу.

## Рабочий процесс (как достигается конечная цель)

> Ты присылаешь 3 ссылки Funda → получаешь готовый PDF.

По принятому решению **описательные тексты пишет ассистент в сессии**, а карта
рендерится через **OSM без ключа**. Полный конвейер на одну подборку:

1. **Сбор фактов и фото — автоматически.** `../funda_a4/funda_fetch.py` обходит
   DataDome-капчу Funda через reader-прокси `r.jina.ai` и вытягивает адрес, индекс,
   район, цену, площади, год, энергокласс, аренду, а также скачивает фото галереи
   напрямую с `cloud.funda.nl`. (Стратегия фолбэков на зеркала брокеров — там же.)
2. **Написание прозы.** Разделы «О городе и районе», «Описание» и пр. Два режима:
   - вручную ассистентом в сессии (использовано для готовых примеров), либо
   - автоматически — `../funda_a4/gen_prose.py` (Claude API): `facts.json` →
     `content.json` с прозой. Нужен `ANTHROPIC_API_KEY` (модель по умолчанию
     `claude-opus-4-8`, переопределяется `ANTHROPIC_MODEL`). Полностью автономный
     конвейер: `funda_fetch.py → gen_prose.py → build_report_docx.py`.
3. **Заполнение модели.** Данные складываются в JSON формата `content_example.json`.
4. **Координаты и карта.** `lat/lon` из JSON (или геокодинг адреса через
   Nominatim) → обзорная карта OSM с маркером.
5. **Рендер.** `build_report_pdf.py` (вектор) собирает все страницы в один PDF.

Два готовых примера, собранных этим конвейером:

- `content_example.json` → `report_vector.pdf` — воспроизведённый образец
  (Den Haag / Boesingheliede / Almere; фото извлечены из присланного PDF).
- `content_utrecht.json` → `report_utrecht.pdf` — **сквозной прогон на 3 живых
  ссылках Funda (Utrecht)**: факты и фото получены автоматически через
  `funda_fetch.py` (`assets_utrecht/`), проза написана ассистентом.

## Формат JSON

```jsonc
{
  "title": "ОБЪЕКТЫ НЕДВИЖИМОСТИ",
  "subtitle": "Нидерланды",
  "objects": [
    {
      "address": "Prinsestraat 118, Den Haag",
      "price_label": "€ 385.000",
      "district": "2513 CH • Район Kortenbos / Hofkwartier",
      "lat": 52.0799, "lon": 4.3041,   // опционально; иначе геокодинг
      "map_zoom": 13,                   // меньше = больше городов в кадре
      "source_url": "https://www.fundainbusiness.nl/.../",
      "photos": "glob:demo_assets/obj1_p*.jpg", // glob или список путей/URL
      "specs": [["Цена", "€ 385.000 k.k."], ["Общая площадь", "≈ 69 м²"]],
      "sections": [
        { "heading": "О ГОРОДЕ И РАЙОНЕ",
          "subheading": "📍 Den Haag — Hofkwartier",
          "paragraphs": ["...прозой..."] },
        { "heading": "ТЕХНИЧЕСКИЕ ХАРАКТЕРИСТИКИ",
          "bullets": ["Год постройки: 1903", "Энергокласс: A"] }
      ]
    }
  ]
}
```

- `photos`: первое фото идёт на страницу «карта + фото» как главное, остальные —
  в галерею. Можно указывать локальные пути, glob или прямые URL (например, CDN
  брокера) — URL скачиваются автоматически.
- `sections[].paragraphs` — абзацы прозы; `sections[].bullets` — маркированный
  список. Можно сочетать в одном разделе.

## Зависимости и правила

- Только `Pillow` + `requests`; карта — переиспользует `../funda_a4/make_sheet.py`.
- Тайлы © OpenStreetMap contributors (соблюдайте tile usage policy).
- Текущий рендер растрирует страницы в изображения внутри PDF (выделяемого
  текстового слоя нет). Если нужен selectable-text/векторный PDF — это делается
  переходом на ReportLab; могу добавить по запросу.
