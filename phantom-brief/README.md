Готовый документ: **`ЖК_ФАНТОМ_информационная_справка.docx`** (6 страниц, A4).

| Стр. | Раздел |

## Чего пока нет

Разделы ценового сравнения (со вторичным и первичным рынком, график
«готовой квартиры», разбор «что можно купить за те же деньги») требуют
выгрузок Циан по конкурентам — см. список в разделе ниже.

## Данные

Ценовой блок — выгрузка Циан по ЖК «ФАНТОМ» (ID 4780951) от 28.07.2026:
52 лота, все от застройщика, **100 % с авторской дизайнерской отделкой**.
Это ключевое отличие от МАСТЕРС, где вся экспозиция шла без отделки:
поправка на ремонт здесь работает в обратную сторону.

Характеристики проекта — официальный сайт `phantom.moscow`. Конкурентное
окружение собрано из `window.INITIAL_STATE` Яндекс Недвижимости
(`yrnb.py` перечисляет ЖК с классом и застройщиком по странице локации).
Картографическая основа — тайлы Яндекс Карт (проекция EPSG:3395).

Планировки Sense Development публично не публикует — ни на сайте проекта,
ни в карточках агрегаторов, поэтому раздела планировок в справке нет.

## Пересборка

```bash
pip install Pillow
npm install docx

python3 parse_all.py    # выгрузка Циан -> phantom_lots.json
python3 ph_data.py      # таблицы цен -> ph_tables.json
python3 ph_maps.py      # карты -> ph_map_loc.png, ph_map_comp.png
node ph_build.js        # -> ЖК_ФАНТОМ_информационная_справка.docx
```

`ph_head.js` — общие хелперы вёрстки (совпадают со справкой по МАСТЕРС),
`ph_body.js` — содержимое документа. `ph_build.js` собирается из них
конкатенацией.
