# Vessel — другие системы на Mac

Приложение каталога, см. [манифест](../MANIFESTO.md). Vessel запускает Linux в виртуальных машинах на
системном **Virtualization.framework**: без драйверов, расширений ядра и сторонних гипервизоров. Каталог
дистрибутивов со скриншотами и честными описаниями, загрузка с проверкой, установка в два щелчка.
Написан с нуля на Swift 6 / SwiftUI с интерфейсом **Liquid Glass**, без сторонних библиотек.

> **Установка без предупреждений macOS.** Проще всего через [Harbor](../Harbor/):
> `curl -fsSL https://github.com/parfentsevandrey-blip/test/releases/download/catalog/install.sh | bash`
> и установите Vessel из каталога.
> Без Harbor: `curl -fsSL https://github.com/parfentsevandrey-blip/test/releases/download/catalog/install.sh | bash -s -- vessel`.

**Запускаются на Apple Silicon (16):** Ubuntu (LTS, последний выпуск, Server), Debian, Fedora (Workstation, KDE,

MX Linux, Tails. Virtualization.framework на Apple Silicon запускает только системы для ARM, поэтому у них
честная плашка «не запустится» и похожие системы, которые запустятся.

### Последний выпуск находится сам

Каталог хранит не ссылку на образ (она устаревает с каждым выпуском), а **правило поиска**: на сервере проекта
Vessel проходит по папкам, берёт старшую версию и её контрольную сумму. Источники: списки файлов (Ubuntu, Debian,
Kali, Parrot, Rocky, AlmaLinux, CentOS, Void, Archboot), `releases.json` Fedora, API Pop!_OS, `latest-releases.yaml`
Alpine, `latest-iso.txt` Gentoo, каналы NixOS, постоянные ссылки openSUSE.

**Без контрольной суммы образ не ставится.** Сумма берётся с сервера проекта и считается на лету во время
загрузки: SHA-256 (CryptoKit) или BLAKE2b — его в системе нет, поэтому он написан по RFC 7693 (Archboot
публикует только такие суммы). Загрузка докачивается с места обрыва, в том числе через переадресацию на зеркало.

Скриншоты — с Wikimedia Commons (свободные лицензии; автор и лицензия — по ссылке под снимком), кэшируются
на диске. Вместо логотипов дистрибутивов (это товарные знаки) — свои обложки: цвет проекта и буквы в стекле.

## Машины

- **Мастер в одну страницу.** Вариант, ресурсы (не больше половины ядер и памяти Mac), общая папка, буфер
  обмена, звук, микрофон, Rosetta. По умолчанию всё уже выбрано — достаточно нажать «Скачать и установить».
- **Установка сама переходит в систему.** Virtualization.framework не перезагружает машину: перезагрузка
  гостя приходит как остановка. Если к этому моменту на диск записана система, Vessel извлекает установочный
  образ и запускает установленную систему. Диск машины стоит первым, поэтому EFI грузится с него, даже если
  образ ещё подключён.
- **Экран** меняет разрешение под размер окна, системные сочетания клавиш уходят в машину.
- **Общая папка** `~/Vessel/<имя>`: в Linux `sudo mount -t virtiofs vessel /mnt/vessel`.
- **Общий буфер обмена** через агент SPICE (в Linux — пакет `spice-vdagent`).
- **Rosetta** для программ x86-64 внутри Linux; macOS ставит её сама, если её ещё нет.
- **Сон вместо выключения.** «Приостановить и закрыть» сохраняет память машины на диск, и в следующий раз
  она продолжает с того же места. При выходе из Vessel работающие машины засыпают так же.
- **Диск разреженный**: 64 ГБ по размеру, на Mac занимает столько, сколько записано. Увеличивается в настройках.
- Каждая машина — папка `~/Library/Application Support/Vessel/Machines/<id>.vessel` (настройки, диск, память
  EFI, идентификатор). Общего списка нет — испортиться нечему; старые записи читаются с умолчаниями.

## Чего Vessel не делает — честно

| Нельзя | Почему |
|---|---|
| Запустить Windows и системы для Intel на Apple Silicon | Virtualization.framework виртуализирует ту же архитектуру, а не эмулирует чужую |
| Запустить машину внутри другой виртуальной машины на M1/M2 | Вложенная виртуализация есть только на M3 и новее (macOS 15+) |
| Сетевой мост с локальной сетью | Нужно право `com.apple.vm.networking`, которое Apple выдаёт по запросу; машины выходят в сеть через NAT |
| Проверить подпись PGP образа | Нужен GnuPG — сторонний инструмент. Проверяются суммы с сервера проекта по HTTPS |

## Самопроверки в CI

`.github/workflows/vessel-macos.yml` на настоящем macOS:
- **logic** — BLAKE2b по эталонам RFC и кусками любой длины; разбор всех видов файлов сумм (Ubuntu, Rocky,
  Archboot, Tumbleweed, Parrot); автоиндексы, версии, LTS Ubuntu, каналы NixOS, YAML Alpine; каталог: у каждой
  системы описание, плюсы, минусы, скриншоты; у систем «только Intel» — объяснение и замены;
- **net** — живой интернет: каждый вариант каждого дистрибутива находится на сервере проекта вместе с суммой;
  Alpine скачивается с обрывом и докачкой, сумма сходится; неверная сумма не принимается; скриншоты загружаются;
- **vm** — машина из скачанного образа: разреженный диск, увеличение, чтение с диска, конфигурация проходит
  проверку Virtualization.framework; если раннер умеет виртуализацию — машина запускается;
- скриншоты всех экранов с выдуманными машинами и загрузками.
