# Почему в Нидерландах перестали сдавать жильё

Презентация-разбор (18 слайдов, PDF 16:9, русский язык) о том, почему частные
арендодатели в Нидерландах массово продают арендное жильё через два года после
вступления в силу закона о доступной аренде (Wet betaalbare huur, 1 июля 2024).

**Готовый файл:** [`dutch-rental-margins.pdf`](dutch-rental-margins.pdf)

## Что внутри

| Слайды | Содержание |
|---|---|
| 1–4 | Картина рынка, цитата Петера Булхаувера (TU Delft), хронология регулирования 2021→2027 |
| 5–9 | Четыре причины по отдельности: цена актива, потолок аренды WWS, ипотека, налоги — и сводка в евро |
| 10–14 | Кейс: квартира 72 м² в Утрехте. Полная экономика 2015→2026, разложение по факторам, сценарии |
| 15–17 | Последствия для рынка, два предложенных решения, выводы |
| 18 | Методология и источники |

## Главный вывод

Денежный поток по типовой квартире обнулился **в 2021 году** — за три года до закона
об аренде. К 2026 году он составляет **−17 948 € в год**. Потолок аренды — лишь
четвёртый по величине фактор (−4 703 €/год) после роста цены жилья (−8 910 €),
налога box 3 (−5 875 €) и роста ипотечной ставки (−5 723 €).

## Файлы

| Файл | Назначение |
|---|---|
| `dutch-rental-margins.pdf` | Готовая презентация |

| `model.py` | Финансовая модель квартиры: все цифры кейса считаются здесь |

## Пересборка

```bash
python3 model.py     # пересчитать модель и вывести все таблицы
./build.sh           # пересобрать PDF из deck.html
```

Модель печатает полный P&L по годам, сценарии 2026 года, «мост» 2015→2026
с разложением по факторам и позицию когорты 2015 года. Числа в `deck.html`
проставлены вручную по её выводу — после изменения параметров модели
их нужно синхронизировать.

Kadaster, CBS, Pararius Huurmonitor, Utrecht Monitor, Belastingdienst,

Vastgoedinsider, Wieringa Advocaten. Полный список — на слайде 18.

Данные собраны в августе 2026 года. Расчёты — иллюстративная модель типового
объекта, а не инвестиционная рекомендация и не налоговая консультация.
