# Уютная погода (CozyWeather)

Погодное приложение + виджет для Android (оптимизировано под Google Pixel 10 Pro XL, API 36).
Концепция — «маленький тёплый мир»: погода показывается через уютные игровые сцены.

## Что внутри

- **Material 3 Expressive** — `MaterialExpressiveTheme` + `MotionScheme.expressive()`,
  полностью динамическая палитра Material You (цвета приложения и виджета берутся из обоев
  и обновляются системой автоматически).
- **Игровой вход** — парящий остров с домиком, светлячки, дым из трубы; тап «влетает»
  в светящееся окно (масштаб-реveal + композиционная вибрация QUICK_RISE→THUD).
- **Тематические сцены погоды** (Canvas, покадровая анимация без рекомпозиций):
  - дождь → камин с живым пламенем, искрами и тёплым свечением;
  - гроза → молнии со вспышками + камин;
  - жара/солнце → комнатный вентилятор с вращающимися лопастями и потоками воздуха;
  - снег → свеча и кружка какао с паром, три слоя снега с параллаксом;
  - облачно → плывущие облака и чай; туман → волны дымки и фонарь;
  - ясная ночь → звёзды, месяц и светлячки.
- **Летающие интерактивные карточки** — все блоки парят в воздухе (фазовый sin-дрейф),
  их можно схватить долгим нажатием, перетащить и отпустить — пружинный возврат
  с тактильной отдачей (EFFECT_HEAVY_CLICK / EFFECT_CLICK / EFFECT_TICK).
- **Виджет на Glance** — адаптивные размеры (SizeMode.Responsive), скруглённые формы,
  `GlanceTheme` с динамическими цветами; автообновление каждые 30 минут через WorkManager
  (+ обновление при каждом рефреше в приложении).
- **Данные** — Open-Meteo (без API-ключа): текущая погода, 24 часа, 7 дней;
  поиск городов (геокодинг с русскими названиями), определение по геолокации
  (coarse location + системный Geocoder), кэш в DataStore — виджет и офлайн-старт
  читают один и тот же снапшот.

## Стек

Kotlin 2.2 · Jetpack Compose (material3 1.5 alpha, Expressive) · Glance 1.1 ·
WorkManager · DataStore · Retrofit 3 + kotlinx.serialization · SplashScreen API ·
edge-to-edge · MVVM (StateFlow) · version catalog.

## Сборка

```bash
# нужен Android SDK 36 (укажите путь в local.properties: sdk.dir=...)
./gradlew :app:assembleRelease   # минифицированный APK ~3.6 МБ
./gradlew :app:assembleDebug
```

APK появится в `app/build/outputs/apk/`.
