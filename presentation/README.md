# Кто сядет в юнит

Презентация аналитического отдела METR PLUS по отчёту «Растущие направления
бизнеса в Нидерландах как потенциальные арендаторы стрит-ритейла»
(Утрехт · Гаага · Роттердам, 31 августа 2026).

18 слайдов, HTML, один самодостаточный файл: все фотографии встроены как
data-URI, внешне подгружаются только шрифты. Открывается двойным кликом,
без сервера и без интернета (без сети подставятся системные шрифты).

## Собрать

```bash
python3 build.py          # deck.template.html + assets/ → deck.html
```

`build.py` кадрирует каждое изображение под нужный слайду размер, жмёт в WebP
и подставляет data-URI на место плейсхолдеров `{{IMG:имя}}` в шаблоне.
Размер можно задать прямо в плейсхолдере: `{{IMG:имя@230x155}}` или
`{{IMG:имя@230x155x80}}` (ширина × высота × качество) — иначе берётся
значение из словаря `SPEC`. Один и тот же файл в разных размерах кэшируется
отдельно, так что мелкие превью не тянут за собой вес крупной версии.

Сборка выводит итоговый размер и список самых тяжёлых изображений — потолок
для артефакта 16 МБ, сейчас занято около 2,3 МБ.

## Структура

```
deck.template.html   Вёрстка, стили, скрипт, весь текст. Единственный файл, который правят
build.py             Обработка изображений и подстановка data-URI
assets/              36 исходных фотографий (WebP, до 1400 px)
sources.json         Происхождение, автор и лицензия по каждому снимку
deck.html            Результат сборки — не редактировать вручную
```

## Навигация

`←` `→`, пробел, колесо или свайп — листать · `O` — содержание ·
`P` — печать · клик по мерной рейке слева — переход к слайду ·
`#s7` в адресе — прямая ссылка на слайд.

На узких экранах (до 900 px) слайды разворачиваются в непрерывный документ:
рейка и статус-бар скрываются, колонки схлопываются в одну, а таблица
шорт-листа и карта направлений прокручиваются внутри своих контейнеров.

## Художественное направление

«Полевой обмер». Стержень отчёта — счёт: прохожие, точки, м², проценты.
Поэтому документ оформлен как измерительный инструмент: мерная рейка с
делениями вдоль левого края, фотографии подписаны как полевые наблюдения,
все числа набраны моноширинным с табличными цифрами.

- **Бумага** `#E4E1D6` — вторичная, с серо-зелёным уклоном; тёмная тема `#15181A`
- **Сигнальный цвет** `#1B3A8F` — плоттерный ультрамарин, только измеренные величины
- **Оксид** `#9E3018` — только отрицательные значения и флаги риска
- **Шрифты** IBM Plex Sans Condensed (заголовки) · IBM Plex Sans (текст) ·
  IBM Plex Mono (числа, подписи, рейка)
- Нулевые радиусы скруглений по всему документу

Токены светлой темы объявлены в `:root`, тёмная переопределяет только их —
в `@media (prefers-color-scheme: dark)` под защитой `:root:not([data-theme="light"])`
и отдельно в `:root[data-theme="dark"]`, чтобы явный выбор темы выигрывал в обе стороны.

## Оговорки по данным

Все числовые показатели приведены по состоянию на дату публикации
соответствующего источника. Данные по CoCo Bubble Tea относятся к середине
2025 года и требуют актуализации перед контактом. Положение направлений на
карте (слайд 05) и колонка «Очередь» в шорт-листе — оценка аналитического
отдела, а не цифры из источников; в самом документе это оговорено.
