# Как получить отчёт по ЖК

Три способа — по уровню «ручной работы»:

- **Способ 0 — расширение браузера (рекомендую).** Поставить один раз, дальше один
  клик на странице ЖК. Без терминала, без консоли, без копирования. → папка
  [`extension/`](extension/README.md).
- **Способ 1 — код в консоль браузера.** Ничего не ставить, но каждый раз вставлять
  скрипт в консоль (F12).
- **Способ 2 — Python в терминале.** Полный контроль/автоматизация, но нужен Python.

> Важно и честно: полностью «без вашего участия» данные получить нельзя — Циан
> отдаёт их только живой сессии в реальном браузере (антибот + капча + бан серверных
> IP). Любой способ опирается на ваш браузер хотя бы раз. Способ 0 сводит это к
> одному клику.

Пример — ЖК **«Среда на Кутузовском»** (ID `4927817`).

---

# Способ 0 (рекомендую) — расширение, один клик

1. Скачайте репозиторий: **Code → Download ZIP**, распакуйте.
2. Откройте `chrome://extensions` (или `edge://extensions`) → включите
   **«Режим разработчика»** → **«Загрузить распакованное расширение»** → выберите
   папку `extension`.
3. Откройте на cian.ru страницу ЖК → внизу справа кнопка **«📊 Выгрузить в Excel»**
   → клик → файл скачается сам.

Подробно — в [`extension/README.md`](extension/README.md).

---

# Способ 1 (рекомендую) — без терминала, прямо в браузере

Ничего не устанавливать. Данные собираются в вашей же вкладке Циан (с вашей
сессией — поэтому антибот не мешает), и браузер сам скачивает готовый Excel.

1. Откройте на **cian.ru** страницу нужного ЖК (по желанию — войдите в аккаунт;
   если показана капча — пройдите её).
2. Нажмите **F12** → вкладка **Console** (Консоль).
3. Откройте файл **`cian_browser.js`** из этого репозитория, скопируйте его
   **целиком** и вставьте в консоль.
   - Chrome при первой вставке просит набрать `allow pasting` (или
     «разрешить вставку») — наберите и снова вставьте.
4. Нажмите **Enter**. Пойдёт сбор (видно прогресс), затем браузер **сам скачает**
   файл `cian_<жк>_<дата>.xls`.
5. Откройте его в Excel: листы **Сводка** + по комнатности + **Все_лоты**,
   сортировка по ₽/м², жирная шапка, числовые форматы, кликабельные ссылки «Циан →».

> ЖК не в Москве? В начале `cian_browser.js` поменяйте `region` (Москва=1, МО=4593,
> СПб=2). ID ЖК скрипт берёт из адресной строки сам.

Если консоль написала «Не собрано ни одного лота» — обновите страницу ЖК, войдите
в аккаунт, пройдите капчу и запустите снова.

# Способ 2 — через Python (терминал)

Скрипт собирает данные с Циан **на вашей машине** (под вашей сессией). Из облака/
сервера Циан блокирует по IP — поэтому запускать нужно у себя на компьютере.

Ниже — на примере ЖК **«Среда на Кутузовском»** (ID `4927817`). Для другого ЖК
поменяйте `--jk` и `--jk-name`.

---

## Шаг 0. Установка (один раз)

Нужен Python 3.9+.

```bash
git clone <этот репозиторий>
cd test
git checkout claude/cian-apartment-scraper-4ns6ql
pip install -r requirements.txt
```

Проверка, что всё на месте (офлайн, без сети):
```bash
python cian_scraper.py --self-test
```
Должен записаться тестовый xlsx и напечататься 5 строк. Если так — скрипт рабочий.

---

## Шаг 1. Узнать ID ЖК (newobject)

ID — это число в ссылке Циан на ЖК:
`https://www.cian.ru/...-zhiloy-kompleks-sreda-na-kutuzovskom-`**`4927817`**`/`

Для «Среды на Кутузовском» это **4927817** (уже известно).
Скрипт также сам вытащит ID, если передать всю ссылку в `--jk`.

---

## Шаг 2. Снять запрос из браузера («Copy as cURL»)

Это даёт скрипту вашу сессию (cookie) — с ней он проходит антибот.

1. Откройте в **Chrome** страницу ЖК на cian.ru (по желанию — войдите в аккаунт).
2. Нажмите **F12** → вкладка **Network** (Сеть).
3. В строке фильтра наберите `search-offers` (или нажмите **Fetch/XHR**).
4. Прокрутите список квартир или смените любой фильтр — пойдёт запрос.
5. Найдите запрос **`search-offers-desktop`**, ПКМ по нему →
   **Copy → Copy as cURL (bash)**. (На Windows выберите именно **bash**, не cmd.)
6. Вставьте в файл **`req.txt`** рядом со скриптом и сохраните.

---

## Шаг 3. Запустить

```bash
python cian_scraper.py --jk 4927817 --jk-name "Среда на Кутузовском" --curl-file req.txt
```

В консоли пойдёт прогресс и в конце — диагностика:
```
Всего активных лотов в ЖК по Циан: 139
Охват: собрано 139 из 139 (100%); прямых ссылок на лот: 139/139
Заполненность полей: ...
========== ИТОГИ ==========
Собрано лотов: 139
Цена за м², ₽: мин ... | средн ... | макс ...
```

---

## Шаг 4. Результат

Файл рядом со скриптом:
```
cian_среда_на_кутузовском_2026-06-26.xlsx
```
Внутри: листы **Сводка** + по комнатности + **Все_лоты**, сортировка по ₽/м²,
прямые гиперссылки «Циан →» на каждый лот, срок экспозиции, живые формулы.

## Если что-то пошло не так

| Симптом | Причина и решение |
|---|---|
| `403` / «Собрано 0 лотов» | Cookie устарел или нет в cURL. Заново снимите «Copy as cURL» (Шаг 2), желательно сразу после захода на сайт. |
| Капча в браузере | Используйте режим реального браузера (ниже) с `--headful` и пройдите капчу один раз руками. |
| Колонки «Отделка»/«Дата обновления» пустые | Это нормально — этих полей нет в списочном API (есть только на карточке объявления). Диагностика помечает их как опциональные. |
| Критичное поле (цена/площадь/ссылка) пусто | Циан сменил схему. Сделайте `--dump-json resp.json`, пришлите — поправлю маппинг. |
| Лотов собралось меньше, чем «всего в ЖК» | Добавьте `--split-price` (вкл. по умолчанию) и/или `--max-pages 28`; проверьте свежесть cookie. |

## Альтернатива А — без cURL, реальный браузер

Если не хочется снимать cURL — пусть скрипт сам откроет браузер «как человек»:

```bash
pip install playwright && playwright install chromium

# первый раз с окном — пройти капчу один раз:
python cian_scraper.py --jk 4927817 --jk-name "Среда на Кутузовском" \
    --browser --headful --browser-profile ./cian_profile

# дальше профиль помнит сессию, можно без окна:
python cian_scraper.py --jk 4927817 --jk-name "Среда на Кутузовском" \
    --browser --browser-profile ./cian_profile
```

## Альтернатива Б — быстро, только cookie

Скопируйте из DevTools (Шаг 2, тот же запрос) значение заголовка **Cookie** и:

```bash
python cian_scraper.py --jk 4927817 --jk-name "Среда на Кутузовском" \
    --cookie "вставьте_строку_Cookie" --user-agent "ваш_User-Agent_из_браузера"
```

## Полезные опции

| Опция | Назначение |
|---|---|
| `--jk` | Ссылка на ЖК или его ID |
| `--jk-name` | Имя ЖК для заголовков/имени файла |
| `--curl-file req.txt` | Запрос из DevTools (cookie + заголовки + тело) |
| `--browser` / `--headful` | Реальный браузер / с окном (для капчи) |
| `--cookie` / `--user-agent` | Быстрая передача сессии без cURL |
| `--output FILE` | Своё имя выходного xlsx |
| `--dump-json FILE` | Сохранить сырой ответ (для сверки полей) |
| `-v` | Подробный лог |
| `--help` | Все опции |
