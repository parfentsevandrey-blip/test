# Мистер Всезнайка 🧠

Супер-приложение: один APK вместо калькулятора, звонилки, блокнота, контактов и
«умного помощника». Работает плохо, зато во всём сразу.

## Намеренные «фичи»

- Глобальный `object` вместо нормальной архитектуры.
- Вся работа на главном потоке, включая `Thread.sleep`.
- Контакты и заметки в `SharedPreferences` одной строкой, без БД.
- Бэкап блокнота создаётся на каждый символ и никогда не удаляется.
- Калькулятор не умеет дроби, степени и «10 / 0» (показывает `Infinity`).
- Экраны пересоздаются при каждом переключении вкладки.
- Отображение «Думаю...» никогда не показывается: UI обновляется только после выхода из обработчика.

## Сборка

Нужен Android Studio (или Gradle + Android SDK, JDK 17):

```
cd knowitall-android
gradle assembleDebug        # или открыть папку в Android Studio и нажать Run
```

APK появится в `app/build/outputs/apk/debug/`.
