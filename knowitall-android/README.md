# Мистер Всезнайка 🧠

Супер-приложение: один APK вместо калькулятора, звонилки, блокнота, контактов и
«умного помощника». Работает плохо, зато во всём сразу.

## Что внутри

| Модуль       | Что делает                                                        |
|--------------|-------------------------------------------------------------------|
| Калькулятор  | Пересчитывает всю историю при каждом нажатии, 120 мс «для ощущения» |
| Звонилка     | Ждёт 300 мс занятым циклом, потом открывает настоящую звонилку    |
| Блокнот      | Сохраняет весь текст целиком на каждый символ + бэкап навсегда    |
| Контакты     | Хранит всё одной строкой, сортирует пузырьком                     |
| Всезнайка    | Считает ответ на главный вопрос перебором за ~2 секунды            |
| Таймер       | Отсчитывает секунды на главном потоке, экран обновляется в конце   |
| Конвертер    | Переводит рубли в USD/EUR/CNY по курсам, зашитым в код            |
| Дела         | Список задач в одной строке, отмечается только первая              |
| Пароли       | Генератор на `java.util.Random` с засевом по времени              |
| Погода       | Температура из головы, случайная на каждое нажатие                |
| Секундомер   | Считает «тики» циклом 10 секунд, без таймера и без точности        |
| Кубик        | Бросает кубики через `Random()`, сумму пересчитывает циклом        |
| Будильник    | Крутит цикл на главном потоке, пока время не совпадёт с вводом     |

## Намеренные «фичи»

- Глобальный `object` вместо нормальной архитектуры.
- Вся работа на главном потоке, включая `Thread.sleep`.
- Контакты и заметки в `SharedPreferences` одной строкой, без БД.
- Бэкап блокнота создаётся на каждый символ и никогда не удаляется.
- Калькулятор не умеет дроби, степени и «10 / 0» (показывает `Infinity`).
- Экраны пересоздаются при каждом переключении вкладки.
- Отображение «Думаю...» никогда не показывается: UI обновляется только после выхода из обработчика.

## Сборка

Нужен Android Studio (или Gradle + Android SDK, JDK 17):

```
cd knowitall-android
gradle assembleDebug        # или открыть папку в Android Studio и нажать Run
```

APK появится в `app/build/outputs/apk/debug/`.
