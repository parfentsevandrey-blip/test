# Забытая обитель — Dark Fantasy Tray

Мини-приложение для трея Windows. Клик по иконке в трее открывает всплывающее окно
с интерактивной 3D pixel-art комнатой в стиле dark fantasy: тёмный каменный зал,
горящий камин, обитатели (закутанная в плащ фигура, ворон, чёрный кот), реквизит
(котёл с зельем, гримуар, напольные часы с маятником) и несколько пасхалок.
Всё в сцене постоянно анимировано — огонь в камине, пламя факелов, лунный свет
в окне, дыхание фигуры, хвост кота, маятник часов, пылинки в воздухе и т.д.

## Технологии

- **Electron** — иконка в трее, всплывающее окно без рамки рядом с треем.
- **Three.js** (vendored локально, `renderer/vendor/three.min.js`) — сцена рендерится
  в низком внутреннем разрешении и растягивается с `image-rendering: pixelated`,
  а материалы используют `MeshToonMaterial` с общим 4-ступенчатым градиентом —
  это и даёт эффект «3D pixel art» при настоящей 3D-геометрии.
- Всё оформление (текстуры, иконка трея, огонь, привидение и т.д.) сгенерировано
  процедурно прямо в коде — никаких внешних картинок/аудио не подгружается,
  приложение полностью автономно и работает офлайн.

## Установка и запуск (на Windows)

```bash
npm install
npm start
```

`npm start` сначала генерирует иконку (`npm run icons`, чистый Node без внешних
зависимостей), затем запускает Electron. После запуска в трее появится иконка
со свечой — кликните по ней, чтобы открыть/закрыть окно комнаты. Правый клик —
контекстное меню («Открыть» / «Выход»).

## Сборка установщика/portable-exe

```bash
npm run dist
```

Использует `electron-builder` (конфиг — в `package.json`), собирает portable `.exe`
и NSIS-инсталлятор для Windows (`x64`) с иконкой `assets/icon.ico`.

> Скачивание самого рантайма Electron (`npm install`) и сборка `.exe` должны
> выполняться на реальной машине с доступом в интернет — в песочнице, где
> готовился этот проект, скачивание бинарника Electron с GitHub Releases
> заблокировано политикой сети, поэтому Electron-часть собрана «вслепую» и не
> запускалась там живьём. Сама 3D pixel-art сцена (то, что происходит внутри
> всплывающего окна) проверена независимо в headless Chromium — открывается
> без ошибок в консоли, все 5 модулей сцены загружаются, наведение/клики по
> объектам работают, анимации (в т.ч. огонь) меняются кадр к кадру.

## Управление

- **Клик по иконке в трее** — открыть/закрыть окно.
- **Esc** или крестик в заголовке окна — закрыть (окно не завершает процесс,
  оно просто прячется; полностью выйти — через меню трея → «Выход»).
- **Наведение/клик** по объектам сцены — камин, ворон, кот, фигура у камина,
  котёл, гримуар и т.д. реагируют на курсор (подсказки внизу окна) и на клик.
- **Перетаскивание** внутри сцены слегка поворачивает камеру (ограниченный
  «кукольный домик»-обзор), лёгкий параллакс от курсора и покачивание камеры —
  тоже часть анимации.

## Пасхалки

Несколько секретов специально спрятаны — часть из них раскрывать в описании
не будем, чтобы не портить открытие, но подсказки: приглядитесь к тёмным углам
комнаты, попробуйте кликнуть по одному и тому же подозрительному предмету
несколько раз подряд, и не забудьте классический код Konami
(`↑ ↑ ↓ ↓ ← → ← → B A`) прямо во время просмотра сцены.

## Структура проекта

```
main.js                    Electron main-процесс: трей, позиционирование окна, IPC
preload.js                 contextBridge: window.dfHost.hide()/quit()
build/make-icons.js        Генератор иконки (чистый Node: zlib → PNG/ICO, без зависимостей)
assets/icon.png, icon.ico  Сгенерированная pixel-art иконка (свеча с пламенем)
renderer/index.html        Разметка всплывающего окна
renderer/style.css         Оформление окна и pixel-рамки
renderer/vendor/three.min.js  Three.js r160 (UMD-сборка, локально)
renderer/src/pixelArt.js   Общие хелперы: палитра, pixel-текстуры, toon-материалы, flicker()
renderer/src/app.js        Рендер-луп, камера, обработка кликов/наведения, банneры/пасхалки-хелперы
renderer/src/room.js       Стены, пол, окно с лунным светом, факелы, паутина
renderer/src/fireplace.js  Камин с анимированным огнём и угольками
renderer/src/characters.js Фигура у камина, ворон, чёрный кот
renderer/src/props.js      Котёл, гримуар, часы с маятником, пылинки
renderer/src/easterEggs.js Скрытые предметы, код Konami, привидение
```

## Кастомизация

- Палитра и общий toon-градиент — в `renderer/src/pixelArt.js` (`PA.PALETTE`).
- Скорость/размер пикселизации — константа `PIXEL_SCALE` в `renderer/src/app.js`.
- Размер и позиционирование всплывающего окна относительно иконки в трее —
  `POPUP_W`/`POPUP_H` и `positionPopupNearTray()` в `main.js`.
- Иконку в трее можно перерисовать, отредактировав пиксельную сетку в
  `build/make-icons.js` (функция `drawIcon16`) и перезапустив `npm run icons`.
