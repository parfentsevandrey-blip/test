# Методика: сбор с ЦИАН без антибота (Scrapling)

Проверено 13.10.2026 из облачного контейнера (один исходящий IP), Scrapling 0.4.15.
Блокировка ЦИАН выглядит как редирект на `127.0.0.1` (Scrapling отклоняет его как SSRF) или страница капчи.

### 4. API вместо HTML

`POST https://api.cian.ru/search-offers/v2/search-offers-desktop/` с `{"jsonQuery": …}` отдаёт ту же выдачу,
что HTML-страница, со всеми полями объявлений и `offerCount`, и работал даже тогда, когда HTML `www.cian.ru` был заблокирован.
История домов и просмотры — тоже `api.cian.ru`.

### 5. Разметка фильтрами вместо карточек

Ремонт и год постройки есть в фильтрах поиска. Запрос выдачи района с фильтром `repair` = 1…4 и `house_year` по диапазонам

## Почему раньше ловили блокировки

Ни один одиночный поток с профилем `chrome` блокировку не вызвал (до 194 запросов/мин).
Блокировки случались, когда с одного IP одновременно работали несколько процессов (сбор, отладка, загрузка фото).
Остаётся неуправляемый фактор: исходящий IP облака общий, его репутацию могут портить чужие запросы, —
поэтому клиент обязан переживать блокировку, а не только не провоцировать её.

## Правила (реализованы в `cian_client.py`)

1. **API first**: выдача, история домов, просмотры — `api.cian.ru`; HTML карточки — только для статуса ушедших
   и данных новых объявлений (несколько в день).
2. **Только десктопные `chrome`/`safari`**; никогда firefox, edge, мобильные.
3. **Один стабильный отпечаток и одна сессия** на весь запуск, без ротации.
4. **Один процесс на IP** — файловый замок `/tmp/cian-client.lock`.
5. **Темп с запасом**: www — 1 запрос в ~1,2 с, API — в ~0,3 с (джиттер ±20%).
6. **Блокировка**: пауза, пробный запрос раз в 30 с, продолжение после снятия; не снялась за 15 мин — запуск
   завершается, собранное уже в базе, следующий запуск продолжит.
7. **Фото** — только браузером (`AsyncStealthySession`, 4 вкладки): хранилище картинок ЦИАН не отдаёт их HTTP-клиенту.

## Страницы бизнес-центров (14.10.2026)

Страницы БЦ (`/biznes-centr-…/`) сначала собирались браузером (`AsyncStealthySession`): каждая загрузка тянет десятки
фоновых запросов к ЦИАН, и после ~60–70 страниц за 7–8 минут сайт отвечал 429 «Обнаружен подозрительный трафик» —
в том числе при одной вкладке. Решение — в инструментах самого Scrapling:

1. **Браузер не нужен**: все данные БЦ (класс, год, площадь, инженерия, координаты, фото, `buildingClassType`,
   `conditioningType` …) есть в серверном HTML. Достаточно одного запроса `FetcherSession(impersonate='chrome')`.
2. **Паук Scrapling** (`scrapling.spiders.Spider`, `bc_pages.py`): один поток, `download_delay` 2 с,
   `autothrottle_enabled` — пауза растёт при медленных ответах и удваивается (или берётся из `Retry-After`) при блокировке,
   `is_blocked` распознаёт 429/403 и страницу капчи, `max_blocked_retries` — повтор заблокированного запроса позже.

Результат: 46 недостающих страниц за 2,5 минуты; три ответа 429 обработаны автоматически (пауза и успешный повтор),
все 146 БЦ выборки загружены.

## Блокировка 19.10.2026: Yandex SmartCaptcha на весь IP

**Как выглядит.** ЦИАН отвечает `302 → /cian-captcha/?redirect_url=…` (сервер `ycalb` — балансировщик Yandex Cloud
с Smart Web Security, cookie `_yasc`). На странице — виджет `smartcaptcha.cloud.yandex.ru/captcha.js` («Я не робот»).
Редирект на `127.0.0.1` — та же блокировка, увиденная HTTP-клиентом, который отказывается идти по редиректу.

**Масштаб.** Блок на IP, а не на отпечаток: в капчу уходят и карточки, и главная, и `api.cian.ru` (поиск отвечает тем же 302).
Браузеры Scrapling — `StealthyFetcher` (Camoufox) и `DynamicFetcher` (Chromium) — открывают ту же страницу капчи,
любые профили `impersonate` тоже.

**Почему.** За час с одного IP ушло ~800 запросов к API (выдача ЦАО и вторички с несколькими сортировками) и ~60 карточек,
были короткие блоки по 30–90 с. Затем клиент при блоке пробовал запрос каждые 30 с на протяжении 8+ минут, плюс
параллельно висел зависший отладочный процесс. Частые пробы во время блока не дают ему сняться — SmartCaptcha
продлевает и ужесточает блок.

**Что сделано.**
1. `cian_client.py`: пробы при блоке с растущей паузой 30 → 60 → 120 → 240 → 300 с, предел 30 мин; ответ API с редиректом
   на капчу больше не принимается за данные (раньше падал на разборе JSON).
2. Карточки «Кло 17» и «Люче» собираются пауком Scrapling (`clos17_history.py`): один поток, пауза 3 с, AutoThrottle до 300 с,
   `is_blocked` распознаёт `/cian-captcha/` и `smartcaptcha`, повтор заблокированного запроса позже.
3. Капчу не решаем автоматически — ждём снятия блока, проверяя одним запросом раз в 5 минут.
4. Перед запуском убедиться, что с ЦИАН не работает другой процесс (`pgrep -af python3`): зависший отладочный скрипт
   держит замок и продолжает слать пробы.
