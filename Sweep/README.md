# Sweep — очистка и обслуживание Mac

Третье приложение каталога, см. [манифест](../MANIFESTO.md). Это аналог CleanMyMac и CCleaner, написанный с нуля
на Swift 6 / SwiftUI с интерфейсом **Liquid Glass**. Сторонних библиотек нет. Используются только системные фреймворки:
Foundation, Security, CoreServices, CryptoKit, QuickLookThumbnailing и SQLite из состава macOS.

## Главное — ничего нужного не удалить

Сначала мы разобрали, на что жалуются пользователи CleanMyMac, CCleaner и бесплатных деинсталляторов.
- **Слишком агрессивная чистка кэшей.** После чистки CloudKit зависает синхронизация iCloud,
  у Adobe начинаются глюки со шрифтами, у Office сбрасываются настройки.
- **Поиск остатков по похожему имени.** Удаляя Chrome, такие программы цепляют файлы Google Drive, Google Updater
  и даже скриншоты со словом «Chrome» в названии.
- **Удаление без возможности вернуть** и без понятного объяснения, что вообще удаляется.

Из этого выросли правила Sweep:

| Правило | Как устроено |
|---|---|
| Единая политика безопасности | `Safety.verdict` проверяет каждую находку при сканировании и ещё раз прямо перед удалением. |
| Запрещённые зоны | Связка ключей, iCloud Drive, Почта, Сообщения, Фото, Календари, `~/.ssh`, `~/.aws`, настройки macOS, данные программ Apple. Сами корневые папки (`~/Library/Caches`, `~/Documents`…) не удаляются никогда — только их содержимое. |
| Только по явному выбору | Резервные копии iPhone, история Safari, хранилища паролей и криптокошельки. Такое никогда не отмечается заранее. |
| Неприкасаемые кэши | iCloud и CloudKit, облачные диски (Dropbox, OneDrive, Google Drive, Яндекс Диск), шрифты, фоновые загрузки, анализ фото. |
| Живые данные | Кэши запущенных программ не отмечаются. Журналы — только старше недели. Системные кэши, изменённые за последние сутки, не трогаются. |
| Остатки удалённых программ | Имя должно быть идентификатором программы, ни одна установленная программа и Launch Services не должны его знать, данные не должны меняться 30 дней. |
| Следы программы | Главный признак — идентификатор программы и её помощников, группы из подписи и задания launchd, которые указывают внутрь программы. Совпадение по имени помечается «проверьте». Общие папки производителя пропускаются. |
| Символические ссылки | Путь проверяется после разрешения ссылок, поэтому ссылка из кэша наружу удаление не уведёт. |
| Корзина и журнал | Программы, данные и пользовательские файлы уходят в Корзину. Сразу удаляются только кэши и журналы (это можно отключить). Каждое удаление записывается в «Журнал», откуда объект можно вернуть на прежнее место. |
| «Никогда не трогать» | Любую находку можно исключить навсегда из контекстного меню. |
| Минимум прав | Привилегированный помощник не ставится. Пароль администратора запрашивается системным окном только для конкретных системных файлов и команд обслуживания. |

Чего Sweep сознательно **не делает**, хотя другие делают:
- **Не удаляет языковые файлы и «лишние» архитектуры из программ.** Это ломает подпись кода.
- **Не чистит память по расписанию.** macOS сама управляет памятью, поэтому это делается только по кнопке.

## Модули

- **Умная проверка.** Одна кнопка — и найдено всё безопасное. Жидкая стеклянная сфера наполняется найденным мусором,
  вокруг собирается кольцо категорий. При очистке жидкость уходит воронкой.
- **Очистка.** 13 категорий, у каждой находки есть пояснение и пометка «Безопасно / Проверьте / Осторожно».
  - Кэши программ и программ из App Store, журналы, отчёты о сбоях.
  - Кэши браузеров: Chrome, Яндекс Браузер, Edge, Brave, Arc, Opera, Vivaldi, Firefox.
  - Мусор разработчика: DerivedData, симуляторы, Homebrew, npm, pip, Cargo, Go, символы старых iOS.
  - Сборочные папки проектов, остатки удалённых программ, забытые установщики, прошивки и резервные копии
    iPhone и iPad, вложения Почты, Корзина.
- **Приватность.** История и cookie браузеров, списки недавних файлов. Ничего не отмечено заранее.
  Пароли, закладки и автозаполнение не трогаются.
- **Программы.**
  - Удаление вместе со всеми следами: настройки, кэши, контейнеры, группы, состояние окон, службы автозапуска,
    привилегированные помощники, квитанции установщика.
  - «Сброс» удаляет данные, оставляя саму программу.
  - Фильтры: не используются 90 дней, крупные, App Store, только Intel.
  - Отдельный режим «Остатки» для уже удалённых программ. Программу можно просто перетащить в окно.
- **Крупные файлы.** Крупные, давно не открытые и дубликаты в личных папках.
  - Дубликаты сравниваются по содержимому SHA-256. Жёсткие ссылки дубликатами не считаются.
  - Одна копия всегда остаётся.
  - Есть быстрый просмотр и миниатюры.
- **Карта диска.** Интерактивная солнечная диаграмма с подсказками и проваливанием в папки.
- **Скорость.** Память с давлением, диск с «очищаемым» местом, самые тяжёлые процессы.
  - Автозапуск (launchd) включается и выключается обратимо.
  - Обслуживание: сброс DNS, освобождение памяти, переиндексация Spotlight, перестройка базы «Открыть с помощью»,
    миниатюры Quick Look, снимки Time Machine, кэш шрифтов.
- **Журнал.** Всё удалённое с кнопкой «Вернуть» и список исключений.
- **Строка меню.** Память, диск, Корзина и быстрые действия.

## Проверка качества

CI (`.github/workflows/sweep-macos.yml`) запускает собранный бинарник:
- `--selftest-safety` строит выдуманный «дом» с мусором, следами программы, приманками с похожими именами и ценными файлами.
  - Затем проверяется, что мусор и следы найдены и удалены.
  - Каждый ценный файл — связка ключей, iCloud, документы, почта, хранилища паролей, свежие журналы, чужие настройки —
    должен пережить очистку и удаление программы.
  - Отдельно проверяются дубликаты и возврат из Корзины.
- `--selftest-real` сканирует настоящий дом раннера, только чтение. Печатает сводку и проверяет инварианты безопасности
  на живых данных.
- Скриншоты окна в нескольких модулях и рендеры визуализаций.

## Установка

1. Скачайте `Sweep.dmg`: это артефакт **Sweep-dmg** последней сборки, workflow «Sweep (macOS)».
2. Перетащите Sweep в «Программы». При первом запуске откройте
   «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».
3. Для полной очистки дайте **полный доступ к диску**: кнопка есть внизу боковой панели.
   Без него не видны Корзина, Почта и кэши программ из App Store.

Сборка: `./scripts/build.sh`. Нужны macOS 26+ и Xcode 26.
