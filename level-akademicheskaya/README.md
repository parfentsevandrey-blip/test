# Аналитика по лоту — ЖК «Левел Академическая», 3-комн. 79,5 м²

Готовый документ: **`Левел_Академическая_аналитика_по_лоту.docx`** (11 страниц, A4).

Объект анализа — конкретная квартира, а не комплекс целиком:
79,5 м², 3 комнаты, этаж 15/19, **без отделки (бетон)**, **56 999 999 ₽**
(716 981 ₽/м²), продаёт агентство, дом сдан.
Объявление: https://www.cian.ru/sale/flat/331215568/

Формат повторяет справку по ЖК «Кутузовский XII» (`../kutuzovsky-lot`),
но диагноз получился обратный: **внутри своего дома лот оценён корректно**,
и проблема лежит в сравнении бетона с готовыми квартирами локации.

## Ключевой вывод

Цена внутри дома выставлена точно. Соседняя трёшка 70,8 м² на 13-м этаже
стоит 706 215 ₽/м²; с поправкой на два этажа по прайсу застройщика
(+0,78 % за этаж, R² = 0,59) это **717 290 ₽/м²**, а лот просит
**716 981 ₽/м²** — паритет с точностью до 0,04 %.

Проблема в другом: лот в бетоне, и покупатель считает бюджет «под ключ» —
57,0 + 79,5 × 150 тыс. = **68,9 млн ₽** и полгода-год работ. По этой цене
метр стоит 866 981 ₽, дороже всей вторички локации на 33–81 %. Готовые
квартиры той же площади в районе: 81,6 м² с евроремонтом за 45,0 млн ₽,
78,7 м² за 42,4 млн ₽, 95,3 м² с дизайнерским за 63,0 млн ₽.

Отсюда рекомендация: главный рычаг — не цена, а определённость ремонта
(дизайн-проект с фиксированной сметой либо продажа с готовым ремонтом).
Если торговаться — коридор 53–55 млн ₽ (667–692 тыс. ₽/м²).

## Данные

Выгрузки Циан от 30.07.2026, восемь проектов:
«Левел Академическая» (ID 4117148) 30 лотов, «Файв Тауэрс» (ID 4676364) 114,
Lunar (ID 3220424) 36, «Новочеремушкинская 17» (ID 43098) 7,
«Вавилова 52» (ID 1352) 6, «Новые Черемушки» (ID 138182) 6,
VAVILOVE (ID 8691) 4, «Вавилов ДОМ» (ID 1389) 2.

**Дубли схлопываются по (площадь, этаж, цена)** — одну квартиру выставляют
несколько агентств. Совпадение только по этажу и цене дублем НЕ считается:
у застройщика «Левел Академической» это разные лоты, часть с террасами,
часть в двух уровнях.

Сопоставимая база — квартиры 65–95 м². **Отделка оценивается в 150 тыс. ₽/м²**
(бизнес-класс). Наш лот в бетоне, поэтому приведение к «квартире, в которую
можно заехать» работает в обратную сторону, чем на Кутузовском: отделка
добавляется к нашей цене, а у соседей берутся лоты, которые уже продаются
с ремонтом.

**Надбавка за этаж измерена по прайсу застройщика внутри самого дома**
(`lv_floor.py`): 15 лотов, единый прайс-лист, этажи 2–19, **+0,78 % за этаж**
(R² = 0,59). Вся экспозиция дома для замера не годится — там смешаны
продавцы и получается шум (−0,95 %, R² = 0,22). «Файв Тауэрс» (75 этажей)
даёт +0,34 % за этаж: это градиент башни, к 19-этажному дому он не применим.

Класс, сроки и инфраструктура проектов — сайты застройщиков Level Group,
Hutton Development, СЗ «5 Донской», КП УГС и профильные порталы.
Координаты для карты — геокодер OSM. Время до метро — медиана поля
«До метро» из выгрузок Циан (у нашего дома 1 минута — лучший показатель
в подборке).

**Фотографии ремонта — Яндекс Недвижимость** (`k12_srch.py` разбирает
`window.INITIAL_STATE` страницы поиска). Циан отдаёт 403 на автоматические
запросы. Выборка — готовые квартиры 62–100 м² за 38–75 млн ₽ по метро
«Профсоюзная» и «Академическая».

## Пересборка

```bash
pip install Pillow numpy
npm install docx

python3 lv_links.py     # выгрузки Циан + ссылки, дедупликация -> lv_linked.json
python3 lv_loc.py       # сравнение с локацией     -> lv_tables.json (loc, ready, fit, our)
python3 lv_floor.py     # надбавка за этаж         -> lv_tables.json (floor, floorRows)
python3 lv_own.py       # экспозиция своего дома   -> lv_tables.json (own, ownCmp, ownStats)
python3 lv_proj.py      # таблица проектов         -> lv_tables.json (proj, power)
python3 lv_alt.py       # «за те же деньги» + фото -> lv_tables.json (alt, photos, city)
python3 lv_infra.py     # тир-лист инфраструктуры  -> lv_tables.json (tiers, infra)
python3 k12_srch.py URL # лоты с фото из Яндекс Недвижимости
python3 lv_map.py       # карта   -> lv_map.png
python3 lv_chart.py     # график  -> lv_chart.png
node lv_build.js        # -> Левел_Академическая_аналитика_по_лоту.docx
```

Порядок важен: `lv_own.py` берёт градиент этажа из `lv_floor.py`, а тот —
базу из `lv_loc.py`.

`lv_head.js` — хелперы вёрстки (общие со справкой по Кутузовскому),
`lv_body.js` — содержимое документа, `lv_build.js` собирается из них
конкатенацией. `assets/` содержит карту, график и шесть фотографий ремонта.
