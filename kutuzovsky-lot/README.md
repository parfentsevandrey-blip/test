# Аналитика по лоту — ЖК «Кутузовский XII», 3-комн. 95 м²

Готовый документ: **`Кутузовский_XII_аналитика_по_лоту.docx`** (9 страниц, A4).

Объект анализа — конкретная квартира, а не комплекс целиком:
95,0 м², 3 комнаты, этаж 6/11, дизайнерский ремонт, **162 500 000 ₽**
(1 710 526 ₽/м²), продаёт агентство, вторичный рынок.
Объявление: https://www.cian.ru/sale/flat/331300080/

## Структура документа

| 1 | Карточка лота + карта локации с ближайшими конкурентами |
| 2 | Конкурентные проекты локации: класс, срок сдачи, отделка, объём экспозиции; сколько метров даёт бюджет 162,5 млн ₽ в каждом проекте |
| 3 | Позиция лота внутри своего дома — 12 квартир ЖК со ссылками на Циан |

| 9 | Что с этим делать: коридор цены и порядок действий, источники |

## Данные

Выгрузки Циан от 30.07.2026, лотов после схлопывания дублей:
«Кутузовский XII» (ID 44404) 12, «Дом Дау» (ID 4296442) 286,
«Бадаевский» (ID 1900321) 144, Capital Towers (ID 45865) 124,
«Веспер Кутузовский» 88, выборка по Москва-Сити 131.

**Дубли объявлений схлопнуты** (`dedupe()` в `k12_links.py`): одну и ту же
квартиру выставляют несколько агентств, и в выгрузке она идёт отдельными
строками. Ключ — площадь + этаж + цена; остаётся объявление с указанной
отделкой. В «Кутузовском XII» это 14 объявлений на 12 квартир (одна
158,3 м² выставлена трижды), в Capital Towers — 129 на 124.

Сопоставимая база — квартиры 85–115 м². Где отделки нет («Дом Дау»,
«Бадаевский», «Веспер»), к цене добавлено 250 тыс. ₽/м².

**Апартаменты исключены из расчёта средних.** В выгрузке по Москва-Сити
120 из 131 лота описаны продавцами как апартаменты — другой юридический
статус и структурно другая цена (688 748 ₽/м²). В таблице сравнения они
приведены справочно, со звёздочкой, и не участвуют ни в графике, ни в
рекомендации по цене. Остальные пять проектов проверены: везде квартиры.

**Надбавка за этаж измерена, а не предположена** (`k12_floor.py`).
Регрессия ln(цена за м²) по этажу с поправкой на площадь. Наш дом (12 лотов)
для этого мал, поэтому градиент берётся у соседей — «Веспера Кутузовского»
и «Бадаевского»: 232 лота, один застройщик, все без отделки, дома до
19 этажей. Получается **+2,1…+3,1 % за этаж** (R² = 0,33–0,40). Башни для
замера не годятся: у «Дома Дау» (85 этажей) прирост 0,15 % на этаж —
структурно другая величина.

В документе этот расчёт показан не в процентах и не графиком, а строкой
плиток: 133,0 → + 11,5–17,0 → 144,5–150,0 → 162,5. Так его читают без
подготовки.

Отсюда главный вывод справки: квартира-близнец в том же доме (те же 95,0 м²,
тот же ремонт, второй этаж) стоит 133,0 млн ₽; четыре этажа по рынку стоят
+8,7…+12,8 %, то есть справедливая цена нашего лота относительно неё —
144,5–150,0 млн ₽, а не 162,5 млн ₽.

Класс и сроки сдачи проектов — сайты застройщиков (Capital Group,
Vesper, «Сумма Элементов»). «Веспер Кутузовский» — Кутузовский пр-т, 12с5,
I кв. 2028; «Бадаевский» — IV кв. 2026 — IV кв. 2027.

**Фотографии ремонта и часть цен — Яндекс Недвижимость** (`k12_srch.py`
разбирает `window.INITIAL_STATE` страницы поиска). Циан отдаёт 403 на
автоматические запросы, поэтому фотографии объявлений оттуда получить
нельзя. В подборку берутся только объекты, которые участвуют в самой
аналитике: Capital Towers (квартиры) и Neva Towers в Москва-Сити
(апартаменты, помечены звёздочкой) — устоявшаяся вторичка тех же лет
постройки, что и наш дом.

## Пересборка

```bash
pip install Pillow
npm install docx

python3 k12_links.py    # выгрузки Циан + ссылки, дедупликация -> k12_linked.json
python3 k12_own.py      # экспозиция своего дома  -> k12_tables.json (own, ownStats)
python3 k12_loc.py      # сравнение с локацией    -> k12_tables.json (loc, ready, apart)
python3 k12_proj.py     # таблица проектов        -> k12_proj.json
python3 k12_alt.py      # «за те же деньги» + фото -> k12_tables.json (alt, photos)
python3 k12_cmp.py      # контрольный пересчёт    -> k12_cmp.json
python3 k12_srch.py URL # лоты с фото из Яндекс Недвижимости
python3 k12_floor.py    # надбавка за этаж        -> k12_tables.json (floor, floorRows)
python3 k12_map.py      # карта   -> k12_map.png
python3 k12_chart.py    # график «готовой квартиры» -> k12_chart.png
node k12_build.js       # -> Кутузовский_XII_аналитика_по_лоту.docx
```

`k12_head.js` — хелперы вёрстки, `k12_body.js` — содержимое документа,
`k12_build.js` собирается из них конкатенацией. `assets/` содержит
подготовленные изображения: карта, график и шесть фотографий ремонта.
