# Аналитика по лоту — ЖК «Кутузовский XII», 3-комн. 95 м²

Готовый документ: **`Кутузовский_XII_аналитика_по_лоту.docx`** (4 страницы, A4).

Объект анализа — конкретная квартира, а не комплекс целиком:
95,0 м², 3 комнаты, этаж 6/11, дизайнерский ремонт, **162 500 000 ₽**
(1 710 526 ₽/м²), продаёт агентство, вторичный рынок.
Объявление: https://www.cian.ru/sale/flat/331300080/

## Структура документа

| Стр. | Раздел |
|---|---|
| 1 | Карточка лота + карта локации с ближайшими конкурентами |
| 2 | Позиция лота внутри своего дома — все 14 лотов ЖК |
| 3 | Сравнение с локацией + график «метр готовой квартиры» |
| 4 | Что можно купить за те же деньги + выводы |

## Данные

Выгрузки Циан от 30.07.2026: «Кутузовский XII» (ID 44404) 14 лотов,
«Дом Дау» (ID 4296442) 286, «Бадаевский» (ID 1900321) 144,
Capital Towers (ID 45865) 129, выборка по Москва-Сити 133.

Сопоставимая база — квартиры 85–115 м². Где отделки нет («Дом Дау»,
«Бадаевский»), к цене добавлено 250 тыс. ₽/м².

**Апартаменты исключены из сравнения.** В выгрузке по Москва-Сити
122 из 133 лотов описаны продавцами как апартаменты — другой юридический
статус и структурно другая цена (684 115 ₽/м²). Они приведены в таблице
справочно, со звёздочкой, и не участвуют ни в графике, ни в выводах.
Остальные четыре проекта проверены: везде квартиры.
