# Аналитика по лоту — ЖК «Кутузовский XII», 3-комн. 95 м²

Готовый документ: **`Кутузовский_XII_аналитика_по_лоту.docx`** (7 страниц, A4).

Объект анализа — конкретная квартира, а не комплекс целиком:
95,0 м², 3 комнаты, этаж 6/11, дизайнерский ремонт, **162 500 000 ₽**
(1 710 526 ₽/м²), продаёт агентство, вторичный рынок.
Объявление: https://www.cian.ru/sale/flat/331300080/

## Структура документа

| Стр. | Раздел |
|---|---|
| 1 | Карточка лота + карта локации с ближайшими конкурентами |
| 2 | Конкурентные проекты локации: класс, срок сдачи, отделка, объём экспозиции; сколько метров даёт бюджет 162,5 млн ₽ в каждом проекте |
| 3 | Позиция лота внутри своего дома — все 14 лотов ЖК |
| 4 | Сравнение с локацией + график «метр готовой квартиры» |
| 5 | Какой ремонт продаётся в локации за те же деньги — 6 лотов с фото |
| 6 | Что можно купить за те же деньги — 11 реальных лотов со ссылками |
| 7 | Выводы и рекомендация по цене, источники |

## Данные

Выгрузки Циан от 30.07.2026: «Кутузовский XII» (ID 44404) 14 лотов,
«Дом Дау» (ID 4296442) 286, «Бадаевский» (ID 1900321) 144,
Capital Towers (ID 45865) 129, «Веспер Кутузовский» 88,
выборка по Москва-Сити 133.

Сопоставимая база — квартиры 85–115 м². Где отделки нет («Дом Дау»,
«Бадаевский», «Веспер»), к цене добавлено 250 тыс. ₽/м².

**Апартаменты исключены из сравнения.** В выгрузке по Москва-Сити
122 из 133 лотов описаны продавцами как апартаменты — другой юридический
статус и структурно другая цена (684 115 ₽/м²). Они приведены в таблице
справочно, со звёздочкой, и не участвуют ни в графике, ни в выводах.
Остальные пять проектов проверены: везде квартиры.

Класс и сроки сдачи проектов — сайты застройщиков (Capital Group,
Vesper, «Сумма Элементов»). «Веспер Кутузовский» — Кутузовский пр-т, 12с5,
I кв. 2028; «Бадаевский» — IV кв. 2026 — IV кв. 2027.

**Фотографии ремонта и часть цен — Яндекс Недвижимость** (`k12_srch.py`
разбирает `window.INITIAL_STATE` страницы поиска). Циан отдаёт 403 на
автоматические запросы, поэтому фотографии объявлений оттуда получить
нельзя. Выборка — лоты с готовым ремонтом в бюджете 128–185 млн ₽
по метро «Киевская».

## Пересборка

```bash
pip install Pillow
npm install docx

python3 k12_links.py    # выгрузки Циан + ссылки -> k12_linked.json
python3 k12_loc.py      # сравнение с локацией   -> k12_tables.json (loc, ready, apart)
python3 k12_proj.py     # таблица проектов       -> k12_proj.json
python3 k12_alt.py      # «за те же деньги»      -> k12_tables.json (alt)
python3 k12_cmp.py      # контрольный пересчёт   -> k12_cmp.json
python3 k12_srch.py URL # лоты с фото из Яндекс Недвижимости
python3 k12_map.py      # карта  -> k12_map.png
python3 k12_chart.py    # график -> k12_chart.png
node k12_build.js       # -> Кутузовский_XII_аналитика_по_лоту.docx
```

`k12_head.js` — хелперы вёрстки, `k12_body.js` — содержимое документа,
`k12_build.js` собирается из них конкатенацией. `assets/` содержит
подготовленные изображения: карта, график и шесть фотографий ремонта.
