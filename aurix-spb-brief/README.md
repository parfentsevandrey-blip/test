# Выгрузка по двум петербургским проектам AURIX

Готовый документ: **`AURIX_ЛДМ_и_Мариинка_выгрузка.docx`** (18 страниц, A4).

Проекты: **«ЛДМ»** (Аптекарский остров, Песочная набережная) и
**«Мариинка Делюкс»** (Матисов остров, берег Пряжки). Оба премиум-класса,
оба сдаются в 2027 году, оба ведёт AURIX Development — премиальный бренд
Группы «Эталон».

## Откуда данные

Тот же источник, что и в московской выгрузке: поквартирный подбор
`aurix-development.ru/vybor-po-parametram/kvartiry`. Список лотов отдаётся
прямо в HTML с микроданными `schema.org/Apartment`, планировки лежат
на карточках лотов под ключами `furnlayouturl` (с мебелью), `layouturl`
(без мебели) и `planurl` (положение на этаже). В справку взят вариант
с мебелью.

**Петербург — это почти весь объём открытого предложения бренда.** Из 149
лотов в подборе 129 приходится на два петербургских проекта: 110 в «ЛДМ»
и 19 в «Мариинке Делюкс». На два московских остаётся 20.

Отдельных лендингов у петербургских проектов нет, поэтому и параметры,
и визуализации взяты только с сайта застройщика. Файлы изображений отдаются
с хоста `api.aurix-development.ru`.

**Цены:** 110 лотов, 45,0–428,5 м², 45,5–436,1 млн ₽. Метр **775–2 223 тыс. ₽**,
средневзвешенный **1 208 тыс. ₽**. Сумма всех лотов — 13,62 млрд ₽ за 11 275 м².

Что видно из прайса:

- **метр различается между корпусами в полтора раза** — 1 553 тыс. ₽ в седьмом
  против 974 тыс. в четвёртом. Разница в 60 % внутри одного проекта означает,
  что корпуса продаются как разные продукты;
- **53 лота из 110 — двухкомнатные**, ядро предложения 60–90 м². Ещё 24
  трёхкомнатных, 16 однокомнатных, 13 четырёхкомнатных и 4 пятикомнатных;
- **одна сити-вилла в открытой продаже:** 428,5 м² за 436,1 млн ₽. Самый дорогой
  лот проекта и одновременно один из самых дешёвых по метру — 1 018 тыс. ₽,
  то есть за объём дают скидку около 19 % к среднему.

## Мариинка Делюкс

| Параметр | Значение |
|---|---|
| Адрес | Санкт-Петербург, Матисов остров, берег реки Пряжки |
| Класс | Премиум |
| Готовность | 2027 год |
| Квартир в доме | 94, из них 6 пентхаусов с террасами |
| Этажность | 9 |
| Потолки | до 3,2 м |
| Паркинг | 63 места: зарядки и подъёмники на два автомобиля |
| Двор | Английский сад, только гипоаллергенные растения |
| Лоты в продаже | 19 квартир, этажи с 1-го по 8-й |
| Ближайшее метро | «Спасская», 2,11 км |

**Цены:** 19 лотов, 47,8–122,1 м², 52,6–128,2 млн ₽. Метр **956–1 191 тыс. ₽**,
средневзвешенный **1 057 тыс. ₽**. Сумма — 1,59 млрд ₽ за 1 504 м².

Разброс цены метра всего 25 % — для дома со сдачей через год с небольшим это
узкий коридор: прайс сформирован единой сеткой, без сильных надбавок за этаж
или вид. Пентхаусы и квартиры девятого этажа с террасами в открытую продажу
не выведены — верхний этаж в подборе восьмой.

| Параметр | ЛДМ | Мариинка Делюкс |
|---|---|---|
| Расположение | Аптекарский остров | Матисов остров |

| Готовность | 2027 | 2027 |
| Лотов в продаже | 110 | 19 |
| Площади, м² | 45,0 – 428,5 | 47,8 – 122,1 |
| Цены, млн ₽ | 45,5 – 436,1 | 52,6 – 128,2 |
| Средневзвешенный метр, ₽ | 1 208 115 | 1 057 247 |
| Сумма лотов, млрд ₽ | 13,6 | 1,6 |
| Ближайшее метро | 1,37 км | 2,11 км |

Метр в «ЛДМ» дороже на **14 %**. Оба дома сдаются в 2027 году, поэтому срок
в разрыв не играет — разница в локации и продукте.

Оба проекта далеко от метро: 1,37 км и 2,11 км. Для петербургского премиума
это обычная история — оба острова застраивались как тихие анклавы.

## Пересборка

```bash
pip install Pillow
npm install docx

python3 spb_lots.py     # список лотов с подбора -> spb_lots.json
python3 spb_plans.py    # карточки лотов и планировки -> spb_flats.json, plans/
python3 spb_media.py    # визуализации со страниц проектов -> src/img/
python3 spb_data.py     # таблицы и расчёты -> spb_tables.json
python3 spb_maps.py     # три карты -> assets/spb_map*.png
python3 spb_renders.py  # кропы визуализаций -> assets/*.jpg
python3 spb_assets.py   # PNG -> JPEG в assets/
cat spb_head.js spb_body.js > spb_build.js && node spb_build.js
```

Планировки перед вёрсткой уменьшаются с 1000 до 420 px и переводятся
в 64-цветную палитру: в документе они стоят шириной 146 px, а вес всех 129
файлов падает с 11 до 3,5 МБ.

`spb_head.js` — те же хелперы вёрстки, что в московской выгрузке, включая
`flatCards`. В петербургской версии карточки идут по четыре в ряд: лотов
в шесть раз больше, и при трёх колонках блок занимал бы двенадцать страниц
вместо восьми.
