# Swarm — торрент/magnet-клиент для macOS 26+

Второе приложение каталога, см. [манифест](../MANIFESTO.md). Нативный клиент BitTorrent для Apple Silicon на
Swift 6 / SwiftUI с интерфейсом **Liquid Glass**. **Весь протокол BitTorrent написан с нуля**: никаких libtorrent,
сторонних библиотек и бинарников. Используются только системные фреймворки Network.framework, CryptoKit, SwiftUI
и Swift Charts; uTP, DHT, шифрование, v2 и проброс порта тоже свои.

> **Установка без предупреждений macOS.** Проще всего через [Harbor](../Harbor/) — каталог всех наших приложений.
> Поставьте его одной командой в Терминале
> `curl -fsSL https://github.com/parfentsevandrey-blip/test/releases/download/catalog/install.sh | bash`
> и установите Swarm из каталога: обновления будут приходить сами, данные и настройки сохранятся.
> Без Harbor: `curl -fsSL https://github.com/parfentsevandrey-blip/test/releases/download/catalog/install.sh | bash -s -- swarm`.

## Установка

1. Скачайте `Swarm.dmg`: это артефакт **Swarm-dmg** последней сборки в GitHub Actions, workflow «Swarm (macOS)».
2. Откройте образ и перетащите **Swarm** в «Программы».
3. Приложение подписано ad-hoc и не нотаризовано, поэтому при первом запуске откройте
   **Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»**.
   Другой способ — выполнить в Терминале `xattr -dr com.apple.quarantine /Applications/Swarm.app`.
4. Чтобы magnet-ссылки из браузера открывались в Swarm, нажмите в Настройках (⌘,) кнопку «Открывать magnet-ссылки в Swarm».
   Файлы `.torrent` Swarm открывает сам.

## Что внутри

**Интерфейс**
- **Созвездие роя.** Вы в центре с кольцом прогресса, пиры на орбитах: сиды снаружи, остальные ближе
  по мере своего прогресса. По лучам летят частицы, их скорость и число зависят от реального трафика с каждым пиром.
- **Мозаика кусков** нарисована на `Canvas`. Только что проверенные по SHA-1 куски вспыхивают,
  куски в работе пульсируют.
- **Фоновое сияние** (`MeshGradient`) становится ярче и быстрее, когда растёт суммарная скорость.
- **«Жидкие» полосы прогресса** с бегущими бликами, графики скорости на Swift Charts.
- Стеклянная шапка: поле magnet, кнопки и капсула скорости объединены в `GlassEffectContainer`.
  У фильтров стеклянные чипы, кнопки действий всплывают на карточке при наведении.
- Можно перетащить в окно `.torrent` или ссылку. В строке меню есть мини-панель со скоростью и активными загрузками.
  Окно можно закрыть, загрузки продолжатся.
- Видео из готовых файлов открываются в [Lumen](../Lumen/), если он установлен.
- Учитываются настройки «Уменьшить движение», есть уведомления о завершении и счётчик на иконке в Dock.

**Протокол**
| | |
|---|---|
| Bencode, `.torrent` | свой разбор, info-хеш по исходным байтам словаря |
| **BitTorrent v2 (BEP 52)** | чистые v2 и гибриды v1+v2: деревья Меркла на SHA-256, `file tree`, `piece layers`, выравнивание файлов по кускам; у гибрида два роя и обе проверки кусков |
| Запросы хешей v2 | `hash request` / `hashes` / `hash reject`: v2-magnet получает слои кусков от пиров и проверяет их доказательством до корня файла; Swarm отвечает на такие запросы сам |
| Magnet (BEP 9) | `urn:btih` (hex и base32) и `urn:btmh` (v2), `dn`, `tr`, `ws`, `x.pe` |
| Трекеры | HTTP/HTTPS (BEP 3, compact BEP 23, IPv6) и UDP (BEP 15) |
| **DHT (BEP 5) — полноценный узел** | таблица маршрутизации из k-корзин с запасными узлами, ответы на `ping`, `find_node`, `get_peers`, `announce_peer` с токенами (секрет меняется каждые 5 минут), хранение чужих анонсов, анонс своих раздач, сообщение PORT, узлы сохраняются между запусками |
| **uTP (BEP 29)** | свой транспорт поверх UDP с контролем перегрузки LEDBAT (цель 100 мс задержки очереди, медленный старт), выборочные подтверждения, быстрый повтор, таймауты по RTT. Общий порт с DHT |
| **Шифрование MSE/PE** | Диффи — Хеллман на 768 бит (своя длинная арифметика, умножение Монтгомери) и RC4. Режимы «предпочитать» (откат на открытое соединение), «только шифрованные», «не использовать» |
| Протокол пиров (BEP 3) | рукопожатие, choke/interest, конвейер запросов по 16 КиБ |
| **Fast extension (BEP 6)** | have all / have none, reject, allowed fast (в обе стороны), запросы не теряются при choke |
| Расширения (BEP 10) | `ut_metadata` (magnet без .torrent), `ut_pex` (обмен пирами, флаги uTP) |
| **Веб-сиды (BEP 19)** | докачка с HTTP-серверов из `url-list` запросами Range, куски через несколько файлов, отступ при ошибках |
| **Локальная сеть (BEP 14)** | анонсы раздач мультикастом 239.192.152.143:6771, пиры в той же сети находятся без интернета |
| **Проброс порта** | PCP (RFC 6887) → NAT-PMP (RFC 6886) → UPnP IGD (SSDP, описание устройства, SOAP). TCP и UDP, продление аренды, удаление правил при выходе, внешний порт сообщается трекерам и DHT |
| **Чёрный список адресов** | форматы PeerGuardian `.p2p`, eMule `.dat`, CIDR, по адресу в строке; файл или ссылка, сжатие gzip |
| **Анонимный режим** | случайный peer id без названия программы, без версии в рукопожатии, нейтральный User-Agent, без анонсов в локальную сеть |
| Выбор кусков | сначала редкие, последовательный режим, endgame |
| Хранение | `pwrite`/`pread` прямо в файлы, проверка SHA-1 или Меркла, данные для возобновления |
| Раздача | choke/unchoke по скорости, оптимистичный unchoke, лимиты скорости (корзина жетонов) |
| Создание торрентов | v1, v2 или гибрид (по умолчанию), потоковое хеширование, magnet сразу в буфере обмена |

Настройки (⌘,) разбиты на вкладки «Основные», «Сеть» (uTP, проброс порта с состоянием роутера, DHT-узел, LSD)
и «Приватность» (шифрование, анонимный режим, чёрный список). В инспекторе у пиров видно транспорт и замок
шифрования, в сводке — сколько соединений шли по TCP и uTP и сколько из них зашифровано, во вкладке трекеров — веб-сиды.

Анонимный режим и шифрование не скрывают ваш IP-адрес от участников раздачи: для этого нужен VPN.

## Проверка качества

В CI (`.github/workflows/swarm-macos.yml`) после сборки запускается сам бинарник приложения.
- `--selftest-core` — bencode, magnet, битовые поля, создание и разбор `.torrent`, защита путей и эталоны протоколов:
  RC4 (известный вектор), Диффи — Хеллман (сверка с Python `pow`), MSE между двумя соединениями в памяти
  (в канале не видно «BitTorrent protocol»), uTP на модели сети с потерями 0/5/15% и перемешиванием пакетов
  (данные доходят побайтно), сеть из 60 узлов DHT (таблицы, анонс с токеном, поиск), набор allowed fast
  из примера BEP 6, info-хеши v2 — побайтно как у эталонного генератора из BEP 52, доказательства для запросов хешей,
  чёрный список, формат LSD.
- `--selftest-loopback` — десяток движков на одной машине: TCP + MSE (с Fast extension), только uTP с обязательным
  шифрованием, открытое соединение в анонимном режиме (сидер видит «Неизвестный» вместо Swarm), magnet через
  `ut_metadata`, v2 и гибрид по `.torrent`, v2-magnet с получением слоёв хешей от пира, чёрный список (соединений нет),
  DHT (узел-роутер, анонс сидера, поиск и загрузка без трекеров), LSD, веб-сид с локального HTTP-сервера.
  Файлы каждый раз сравниваются побайтно.
- `--selftest-internet` — настоящий рой Debian netinst: куски с проверкой SHA-1, шифрование и Fast extension
  с настоящими клиентами, отдельная загрузка **только по uTP**, состояние проброса порта и DHT-узла,
  затем описание раздачи по magnet **только через DHT**, без трекеров.

Последний прогон с настоящими клиентами (Deluge, qBittorrent, Transmission): шифрование MSE согласовано
с 4 из 5 пиров, Fast extension — с 5 из 5, загрузка только по uTP — 4 соединения, все зашифрованы;
DHT-узел отвечал на чужие запросы. На машине CI роутера с пробросом нет, поэтому PCP/NAT-PMP/UPnP там честно
сообщают «не поддерживает»; v2 проверен на эталонах BEP 52 и между копиями Swarm, но не с чужим v2-клиентом.
